# Teaching audit: four readers (5 November 2026)

An independent read of the site at commit 611d4c9 as four people: someone who has never programmed, a student cramming for an exam, someone who must write code by hand, and a working engineer. Sampled: opening, chapter 1, one mid and one late chapter of each course, in both languages where it mattered.

## What was kept

- Handbook unit 00's setup per OS, its auto-checked exercises, and "understanding the answer is not the same as writing it".
- COMP2123's prose and prerequisites, the model for the other courses.
- COMP2017's six passes and its three complete projects.
- Worked problems with "choose the method" and "check the reasoning", and every program's exact verified output.
- Honest limits throughout, such as analogy limits and "a clean run does not prove".
