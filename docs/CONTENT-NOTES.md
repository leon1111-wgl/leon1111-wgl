# About the learning notes

These are original topical study companions organized by Guoliang. Each explanation builds intuition with an analogy, describes the underlying mechanism, explains formal notation, and walks through a new example.

The five paths correspond to Java and object-oriented programming, C and systems programming, data structures and algorithms, computation and logic, and artificial intelligence. The notes consolidate repeated topics into connected learning paths. They do not reproduce every slide or assessment from a particular semester. Each course's scope statement describes the available coverage.

The four additional AI field guides cover machine learning, deep learning, computer vision and multimodal AI. Each includes 16 complete English/Chinese topics, linked official tutorials or original papers, and a 16-item review. Stories and numerical examples are independently written; these guides are not official translations or endorsed courses. The five course PDFs remain English.

The clickable knowledge frameworks are reading routes, not claims that there is only one valid sequence for learning. Cheatsheets are compact reminders; the full notes provide the assumptions and derivations that a one-page reference cannot hold.

The biography was prepared from Guoliang Wang's supplied CV. The publication year is 2026, confirmed against the official AAAI proceedings record: https://ojs.aaai.org/index.php/AAAI/article/view/38031. Education, internship details, and the co-first-author designation are based on the supplied CV.

The beginner primer adds eight bilingual lessons in Python, vectors, matrices, probability, logarithms and gradients. The four AI guides add progressively harder applications. Each topic includes defined terms, answered guiding questions, small runnable Python, expected output, a step-by-step explanation and application cases. COMP2123 includes 36 Python examples across its 26 topics. These examples demonstrate mechanisms with small fixed inputs; they are not full production implementations.
