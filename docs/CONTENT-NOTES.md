# About the learning notes

These are original topical study companions organized by Guoliang. Each explanation builds intuition with an analogy, describes the underlying mechanism, explains formal notation, and walks through a new example.

The five paths correspond to Java and object-oriented programming, C and systems programming, algorithm design and analysis, computation and logic, and artificial intelligence. The notes consolidate repeated topics into connected learning paths. They do not reproduce every slide or assessment from a particular semester. Each course's scope statement describes the available coverage.

The four additional AI field guides cover machine learning, deep learning, computer vision and multimodal AI. Each includes 16 complete English/Chinese topics, linked official tutorials or original papers, and a 16-item review. Stories and numerical examples are independently written; these guides are not official translations or endorsed courses. The five course PDFs remain English.

The clickable knowledge frameworks are reading routes, not claims that there is only one valid sequence for learning. Cheatsheets are compact reminders; the full notes provide the assumptions and derivations that a one-page reference cannot hold.

The biography was prepared from Guoliang Wang's supplied CV. Education and internship wording follow the supplied CV and the author's later corrections. The beginner primer adds eight bilingual lessons in Python, vectors, matrices, probability, logarithms and gradients. The four AI guides add progressively harder applications. Each topic includes defined terms, answered guiding questions, small runnable Python, expected output, a step-by-step explanation and application cases. COMP2123 develops algorithm design, correctness and complexity across 26 topics, with Python implementations. Java and C courses add standalone programs and execution traces. Theory and AI courses add original worked problems. Each foundational course has a complete Chinese companion and topic-specific instructor insights. These examples demonstrate mechanisms with small fixed inputs; they are not full production implementations.

COMP2017 adds a six-pass route that separates the first working program, memory, files, processes, threads and later improvement. Each of its 24 chapters has a short mental model, an engineering decision and a checkpoint. Six additional bridge programs explain value versus address, string terminators, status versus output, ownership, callbacks and a ring queue before threading.

Three original workshops connect these ideas: a streaming log analyzer, a bounded process-output runner and a threaded file-statistics pipeline. Each has five learning milestones, a starting route, requirements, an ownership model, complete multi-file source, actual runs, failure analysis, tests and explained design limits. Both language editions and source ZIP downloads are complete. All sample data are fabricated. These are worked teaching projects, not uploaded university assignments or assessment solutions.
