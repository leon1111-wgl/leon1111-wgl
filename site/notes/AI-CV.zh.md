## 像素是带有约定的测量值

### 01 / 从一个完整故事开始

Maya 在社区档案馆做志愿者，协助把手绘剧院海报数字化。一天早晨，新目录里的蓝色戏服全部变成了红色。扫描仪似乎正常，文件也能打开，大家最初怀疑显示器。Maya 没有更换设备，而是沿着处理流程追踪一小块已知的蓝色区域。她发现，读取组件把蓝色放在第一个通道，下一组件却把第一个通道当成红色。她逐一记录接口处的通道顺序、数组形状与数值范围，修正转换，再检查同一色块。戏服终于恢复了蓝色。从此，团队在讨论模型是否理解图片之前，先确认各组件接收到的是同一幅图片。像素数组也需要约定，就像包裹标签必须让每个经手人得到相同的含义。

### 02 / 理解核心概念

图像张量是一种数值表示，包含空间轴、通道、数据类型和强度约定。高×宽排列的 RGB 图像与通道优先的批次张量可以表达相近的信息，但布局不同。交换轴的顺序不等于交换颜色通道；把无符号字节转换成浮点数，也不会自动缩放数值。预处理必须符合模型所要求的通道顺序、取值范围和归一化统计量。数组索引通常先写行、再写列，而几何坐标常写成先水平 x、再垂直 y。数据跨越接口时，都应明确这些约定。

### 03 / 如何运用这个概念

搭建视觉流程时，可以先使用一张颜色与位置都已知的小型诊断图片。每次转换后，检查形状、类型、最小值、最大值，以及某个指定像素。采用预训练权重要求的归一化统计量；若自己设计流程，就只用训练数据估计。保留未修改的输入，以免可视化时误把标准化数值当成普通颜色。

### 04 / 官方教程与研究中的应用

OpenCV 的 Basic Operations on Images 官方教程直接展示像素访问、数组属性与通道操作，而不是把图像当作不透明文件。TorchVision 的变换文档介绍了图像与结构化目标的处理。两者共同体现档案馆故事中的实际问题：表示方式本身就是计算的一部分，在模型推理开始之前必须保持一致。

### 05 / 公式与逐项解析

```text
z = (v / 255 − μ) / σ
HWC → CHW: (H, W, C) → (C, H, W)
```

v 是取值为 0 到 255 的八位通道数值。除以 255 后，它被映射到单位区间；μ 和正数 σ 是在相同尺度下使用的均值与标准差。z 是标准化后的数值，可以为负。H、W、C 分别表示高度、宽度与通道数。HWC 和 CHW 只说明轴的顺序，并不说明哪个通道代表红、绿或蓝。公式假设输入确实使用上述字节尺度；已经位于单位区间的浮点图像不应再次除以 255。

### 06 / 一步步算出结果

设自拟通道值 v = 153，μ = 0.5，σ = 0.25。先缩放：153 / 255 = 0.6。再中心化：0.6 − 0.5 = 0.1。最后除以标准差，得到 z = 0.4。如果输入的 0.6 已经完成缩放，却再次除以 255，标准化结果将约为 −1.9906。形状需要单独检查：一张 4×6 的 RGB 图像形状为 (4, 6, 3)，把通道轴移到前面后得到 (3, 4, 6)，两者都包含 72 个数值。这两种操作本身都不会把 BGR 变成 RGB。只有同时检查数值和通道含义，才能判断输入是否正确。

**类比的边界与注意事项:** 包裹标签的类比解释的是接口一致性，并不能代替色彩科学。相机响应、伽马编码与光照也会影响像素。形状和范围正确，不能证明不同拍摄条件下的图像对应相同的物理测量；它只是排除了一类本可避免的错误。

**记住这一点:** 在让模型学习像素之前，先明确每个接口的轴顺序、颜色含义、数值尺度与归一化约定。

## 局部滤波提出局部问题

### 01 / 从一个完整故事开始

Jon 正在为一间小型天文台修复扫描星图。扫描仪里的灰尘留下了亮点，但微弱的铅笔线又标记着星座。他第一次尝试把每个像素替换成邻域平均值。亮点确实变淡，一些重要的铅笔线却也消失了。Jon 没有因为图像更平滑就宣布成功，而是对照几条已知线段和空白区域检查。他在合适位置使用更小的平滑窗口，并把边缘响应与原图并列查看。修复之所以有用，是因为他选择了具体的局部问题，而不是套用万能的美化规则。邻域滤波就像让附近证人组成评议组：平均意见能减弱孤立噪声，也可能抹去一个少见却重要的观察。

### 02 / 理解核心概念

线性图像滤波器在每个位置计算附近数值的加权和。归一化的平均核可以平滑变化，而带正负系数的核会对变化作出响应。在全图重复使用同一个核，就在空间上共享了一种局部运算。邻域超出图像边界时，结果取决于填充方式。许多日常被称为“卷积”的软件操作，实际计算的是不翻转核的互相关。对称平均核下，两者结果相同；但方向性滤波器在翻转后可能改变符号或方向。

### 03 / 如何运用这个概念

选择滤波器前，先说明目标：抑制孤立噪声、估计梯度，还是为后续任务准备输入。既要查看平坦区域，也要查看代表性边界，记录填充规则；若负响应有意义，应保留浮点输出。要比较后续识别效果或标注质量，而不是把视觉上的平滑自动等同于改进。

### 04 / 官方教程与研究中的应用

OpenCV 的 Smoothing Images 教程展示多种邻域滤波方法，而 filter2D 接口参考明确了该操作使用的互相关约定。两类来源可以互补：教程说明流程，接口参考澄清实现细节。学习型卷积网络会从数据中拟合许多核，扩展了共享局部运算的思想；但训练过程与非线性层使它远不止固定平滑滤波器。

### 05 / 公式与逐项解析

```text
y[r,c] = Σ_i Σ_j K[i,j] x[r+i,c+j]
Mean kernel: K[i,j] = 1 / (k²)
```

x 是输入强度数组，y 是输出；r 与 c 表示输出位置。i 和 j 遍历核的邻域偏移，K 给出每个偏移对应的权重。这里写的是互相关约定。对于 k×k 的平均滤波器，k² 个权重都等于 1/k²，总和为 1。该公式没有规定越界位置如何取值，因此必须另外说明填充方式。多通道情况下，可以逐通道独立滤波，也可以在通道之间求和，具体取决于运算层。

### 06 / 一步步算出结果

考虑一个 3×3 图像块：其中八个值为 10，中心值为 19。均值滤波后的中心值为 (8 × 10 + 19) / 9 = 11。亮点被减弱了，但并非没有代价：真正孤立的星点也会变暗。另看一维边缘探测，把互相关核 [−1, 0, 1] 作用于 [2, 5, 8]，响应为 −2 + 0 + 8 = 6。若输入顺序反转，结果就是 −6。粗心地使用无符号输出，可能掩盖负响应。这两项计算回答的是不同问题，应根据需要保留的信息选择和评估它们。

**类比的边界与注意事项:** 邻近证人也可能犯同一种错误。平均无法恢复原本就没有被测到的细节，过强平滑还会损伤边界。边缘响应表示局部强度变化，并不等于语义对象边界；阴影、纹理和传感器噪声都可能产生响应。

**记住这一点:** 滤波器是用权重表达的局部问题；既要检查它去掉了什么，也要检查它保留了什么。

## 让图像与标注一起移动

### 01 / 从一个完整故事开始

Lina 为工作间做了一套小型相机系统，识别挂在墙上的工具。它原本表现不错，直到相机被安装到更高的位置，工具出现在陌生坐标上。她于是使用平移和缩放后的图像训练。起初，她只移动图片，却没有移动标注框；新数据反而教模型把锤子定位到别处。把框叠加在图上检查，错误立刻显现。Lina 让每次变换同时作用于图像和标注，并排除完全裁掉对象的样本。系统在未参与训练的新相机位置上取得了改善。这个故事说明几何关系必须共享：如果移动了剧院舞台，却把演员的地面定位标记留在原处，即便舞台和标记本身都制作精良，也仍会引起混乱。

### 02 / 理解核心概念

几何变换把一个参考系中的坐标映射到另一个参考系。平移改变位置，缩放改变尺寸，仿射映射可以组合线性变换和平移。生成变换后的图像时，通常通过逆映射从源图像采样，并对非整数坐标插值。数据增强使用选定的变换来表达“目标含义应保持不变”的变化。但这一假设取决于任务：水平翻转可能不改变工具类别，却会改变向左箭头的标签。标注框、掩码和关键点需要协同变换，不能只保证输出图像尺寸相同。

### 03 / 如何运用这个概念

先写下目标相机环境中哪些变化是合理的，以及哪些标注必须随之改变。预览增强样本时应叠加框与掩码，还要包含极端裁剪和边界情况。随机增强通常只用于训练流程，评估采用明确的固定处理。相关视频帧应放在同一数据划分中，避免增强掩盖训练与评估之间的泄漏。

### 04 / 官方教程与研究中的应用

OpenCV 的 Geometric Transformations 教程把坐标映射与图像重采样联系起来。TorchVision 的变换文档说明图像、框、掩码和视频为何需要兼容操作。在官方目标检测教程中，图像与目标的变换也是训练数据准备的一部分。这些资料支持工作间案例的流程，但并不意味着所有变换都适合每一种检测任务或标签体系。

### 05 / 公式与逐项解析

```text
[x′, y′, 1]ᵀ = [[sₓ, 0, tₓ], [0, sᵧ, tᵧ], [0, 0, 1]] [x, y, 1]ᵀ
x′ = sₓx + tₓ; y′ = sᵧy + tᵧ
```

x、y 是原参考系中的水平与垂直坐标，带撇的坐标属于变换后的参考系。sₓ、sᵧ 是缩放系数；tₓ、tᵧ 是以输出坐标单位计量的平移量。补上的 1 让平移能够写进矩阵乘法，上标 T 表示列向量。这个受限的仿射变换只含缩放和平移，不含旋转或透视。缩放系数为正时，可变换轴对齐框的两个对角；更一般的变换需要考虑所有顶点及所需的输出表示。

### 06 / 一步步算出结果

一个自拟工具框的两个对角为 (10, 20) 与 (30, 50)。设 sₓ = sᵧ = 2，tₓ = 5，tᵧ = −3。第一个顶点变为 (2 × 10 + 5, 2 × 20 − 3) = (25, 37)，第二个变为 (65, 97)。宽从 20 变成 40，高从 30 变成 60，因此面积从 600 变成 2400 个平方坐标单位。平移不会改变宽或面积。如果输出画布只到 y = 80，框就超出画布，需要一致地执行裁剪与对象保留规则。若只更新像素，原标注框就会留在不相关的位置。

**类比的边界与注意事项:** 移动舞台的类比不能保证对象含义在变换后保持不变。裁剪可能移除关键证据，插值也可能改变细小图案。增强只对有用且标签一致的变化有帮助，不能代替来自目标环境的代表性真实图像。

**记住这一点:** 几何变化必须带着标注一起变化；每项增强都要说明，为什么标签含义仍然成立。

## 借用视觉词汇，再学习新的判断

### 01 / 从一个完整故事开始

社区花园请 Noor 把相机图片分成三类植物。她手头的已标注图片不多，从随机权重训练大型识别模型时，结果很不稳定。于是她使用一个已经从其他图像中学到可复用视觉模式的网络，冻结特征提取部分，只训练一个新的小型决策层。初步结果有所改善，但仔细检查后发现，花园特殊的傍晚光线仍会导致错误。她随后用较低学习率谨慎微调部分层，并把若干独立采集日留作评估。这像请一位经验丰富的插画师学习新的植物手册：绘画经验可以迁移，但插画师仍需要当地样本、清晰类别，以及对陌生页面的诚实检验。

### 02 / 理解核心概念

分类器把图像映射成一组已定义类别的分数。特征提取器把像素变成表示，预测头再把表示变成类别 logits。迁移学习复用预训练参数，无须所有特征都从头学习。冻结主干时，主干参数不更新；微调则会按新目标更新其中一部分或全部参数。Softmax 把 logits 转换成针对已给定类别的归一化分布。最大数值并不保证预测正确，尤其当输入不同于训练分布时。

### 03 / 如何运用这个概念

先建立冻结特征的简单基线，使预处理符合预训练模型要求，再把预测头替换成自己的类别集合。相邻图像存在关联时，应按采集批次或来源划分数据。微调与基线要使用相同的留出组比较。按光照和视角查看错误，并保留足够评估数据，以便发现所谓更好的模型是否只是记住了局部模式。

### 04 / 官方教程与研究中的应用

PyTorch 的官方 Transfer Learning for Computer Vision 教程对比了调整预训练网络与把它作为固定特征提取器的做法。Stanford 的 CS231n 教学则提供了学习型视觉表示与识别的更广背景。Noor 的三类植物案例是原创例子；它与这些资料的联系，在于复用已学表示，并检验调整后是否能推广到新图像的工作流程。

### 05 / 公式与逐项解析

```text
h = fθ(x); z = Wh + b
pₖ = exp(zₖ) / Σⱼ exp(zⱼ)
L = −log(pᵧ)
```

x 是输入图像，fθ 是参数为 θ 的特征提取器，h 是特征向量。W、b 是新预测头的权重矩阵与偏置。z 为每个类别提供一个未归一化 logit，k、j 是类别索引，pₖ 为对应的 softmax 值。y 表示正确类别，L 是单张已标注图片的负对数似然，这里的对数为自然对数。主干冻结时，优化只改变 W、b，θ 不变；微调则允许 θ 的选定部分也发生变化。

### 06 / 一步步算出结果

为了让计算透明，设 h = [1, 2]，W 的三行为 [1, 0]、[0, 1]、[0, 0]，偏置全为 0。得到 logits 为 [1, 2, 0]。取指数后约为 [2.7183, 7.3891, 1]，总和为 11.1073。因此类别概率约为 [0.2447, 0.6652, 0.0900]。若第二类正确，损失为 −log(0.6652)，约等于 0.4076。模型虽然预测正确，仍然有损失，因为它还给其他类别分配了概率。这个例子演示的是预测头的计算，而不是生成真实图像表示所需的大量运算。在把较低训练损失解释成有效识别之前，还必须检验新图像。

**类比的边界与注意事项:** 经验丰富的插画师类比，可能夸大能够迁移的能力。预训练可能包含无关捷径，较大的 softmax 值也可能对应错误类别。冻结特征是有用的基线，却不是通用答案；如何调整应依据数据量、相似性与评估证据决定。

**记住这一点:** 迁移表示，仔细定义新的判断任务，再用真正独立的图像组衡量改进。

## 框定位候选对象，重叠度帮助消除重复

### 01 / 从一个完整故事开始

Eli 在海岸观鸟屋记录海鸟。检测器在一张他能辨认出四只海鸥的照片中报告了七只。叠加预测框后，他发现同一只鸟周围有几个略有不同的矩形，因此直接数预测结果会夸大数量。Eli 按分数排列候选框，在海鸥类别内部移除高度重叠的替代框。这张照片的计数于是与人工观察一致。然而，第二张照片中有两只靠得很近的鸟，过于激进的重叠阈值反而删掉了一只真实邻鸟。他在另行标注的图像上比较多个阈值，并在错误复查中保留拥挤场景。最终得到的是一套规则明确、失败情况已知的计数流程。矩形只是候选位置，就像围绕同一地标画出的几个铅笔圈；合并这些圈需要规则，但规则本身看不见地标。

### 02 / 理解核心概念

目标检测为各个候选对象预测类别、分数与位置。交并比 IoU 衡量两个区域的交集相对于并集的比例；它是几何比值，并非分类准确率。贪心非极大值抑制先保留剩余框中分数最高的一个，再移除与它的 IoU 超过阈值的低分框，随后重复此过程。这里按类别分别执行抑制。TorchVision 的基础 NMS 操作不接收类别标签，因此需要调用方安排类别隔离。抑制阈值和评估时的匹配阈值用途不同，即使两者都使用 IoU。

### 03 / 如何运用这个概念

比较检测结果之前，先定义框坐标和类别处理方式。检查包含孤立对象、拥挤邻居与部分遮挡的叠加图。用验证数据选择分数阈值和抑制阈值，在最终评估时保持固定。记录预测与标注的匹配方法，包括防止多个预测重复认领同一对象的规则。看起来合理的框是需要检查的证据，并不能证明计数正确。

### 04 / 官方教程与研究中的应用

TorchVision 官方检测教程在 Penn-Fudan 行人图像上微调 Mask R-CNN，并把框、类别与对象掩码作为结构化目标。NMS 参考文档则单独说明分数排序，以及重叠度严格大于给定阈值时的移除规则。结合阅读两份资料，可以区分完整检测示例与单个后处理操作，也能精确定义海鸟故事中的去重决策。

### 05 / 公式与逐项解析

```text
IoU(A, B) = |A ∩ B| / (|A| + |B| − |A ∩ B|)
|A| = (x₂ − x₁)(y₂ − y₁)
score(B) < score(A) ∧ IoU(A, B) > τ ⇒ B ∉ K
```

A 是已保留的框，B 是同一类别中分数较低的候选框。竖线表示连续面积，∩ 表示交集。(x₁, y₁) 和 (x₂, y₂) 是 A 的两个对角，水平与垂直坐标均递增。面积使用坐标差计算，不采用包含端点的像素计数加一规则。两个框的面积都为正。score 给出排序分数，τ 是选定的 IoU 抑制阈值。所示规则假设分数不相同；分数相同时，需要按具体实现的规则选择。IoU 的取值范围为 0 到 1。 K 是保留框集合；∧ 表示两个条件同时成立，⇒ 表示由此推出 B 不属于 K。

### 06 / 一步步算出结果

考虑三个自拟海鸥框：A = (0, 0, 4, 4)、B = (1, 1, 5, 5)、C = (6, 0, 8, 2)，分数分别为 0.9、0.8、0.7。A 与 B 的面积均为 16。它们的交集宽为 3、高为 3，因此面积为 9。并集面积为 16 + 16 − 9 = 23，所以 IoU = 9 / 23，约为 0.3913。当 τ = 0.3 时，保留 A、抑制 B。C 与 A 没有重叠，因此保留 C，最终剩下两个框。当 τ = 0.5 时，B 也被保留，共有三个框。这些结果说明阈值的作用；没有标注，仍无法判断 A 与 B 指向同一只海鸥，还是两只相互遮挡的海鸥。

**类比的边界与注意事项:** 铅笔圈的类比解释了重复候选，但高重叠度不能证明它们对应同一对象。贪心抑制可能移除真实邻居，高分框也可能定位不准。不同检测器可能采用其他去重设计；这里介绍的是常见操作，并非所有检测架构都使用的规则。

**记住这一点:** 把框视为候选，精确定义重叠，并把去重规则与检测质量的判定规则分别验证。

## 从一个矩形走向真正属于对象的像素

### 01 / 从一个完整故事开始

Priya 帮助河流观察小组比较浅观察盘中漂浮叶片的照片。标注框可以定位每片叶子，却也包含水面，因此把框面积相加会夸大叶片覆盖率。她改用标记叶片像素的掩码，测量合并后的前景区域。这回答了覆盖率问题，直到另一位志愿者询问叶片数量。两片相接的叶子形成一个连通区域，说明共享类别掩码不能保留个体身份。Priya 为计数准备逐实例标注，同时保留用于覆盖率的语义掩码。由于观察盘的大多数像素都是水，她还用前景重叠指标替代总体像素准确率。小组于是拥有两个明确问题和两种适当输出，而不是一个看似出色、却悄悄回答了错误问题的数字。

### 02 / 理解核心概念

语义分割为每个像素赋予类别；所有叶片都可以共享一个类别，而不区分个体。实例分割除了判断对象像素，还区分不同对象。二值前景掩码可以通过 IoU 或 Dice 重叠度与参考掩码比较。这两个指标都不会直接奖励正确预测的背景像素，因此在背景占主导时，前景比较尤其有信息量。Dice 把共同前景计数两次，再除以两个掩码大小之和。这些硬掩码指标不同于可微训练损失，后者可能使用概率、平滑项或其他汇总方式。报告结果时，需要说明使用的版本与平均规则。

### 03 / 如何运用这个概念

问题涉及某种材料的覆盖范围时，选择语义标签；需要区分不同对象时，选择实例标签。把掩码叠加在原图上，检查边界与小区域。报告前景重叠度时，同时保留类别频率和代表性错误，并说明是在图像、对象还是类别之间取平均。评估前先定义空掩码处理规则，避免没有前景的图片悄悄改变平均分数的含义。

### 04 / 官方教程与研究中的应用

TorchVision 文档提供了用于语义分割、采用 ResNet-50 主干的 FCN 模型。其检测教程则使用 Mask R-CNN 与 Penn-Fudan 标注，区分不同行人及其掩码。这是两类输出的具体实例。scikit-learn 指标指南给出了相关的 Jaccard 与 F 度量定义；在明确前景约定后，可以把这些定义用于展平的二值像素标签。

### 05 / 公式与逐项解析

```text
IoU = |P ∩ G| / |P ∪ G|
Dice = 2|P ∩ G| / (|P| + |G|)
Dice = 2IoU / (1 + IoU)  (|P ∪ G| > 0)
```

P 是被预测为前景的像素集合，G 是参考前景集合。竖线表示像素数量；∩ 选取同时属于两个集合的像素，∪ 选取属于任一集合的像素。IoU 表示交并比，Dice 是上式定义的重叠系数。分母为正时，两者均介于 0 与 1 之间。如果两个掩码都为空，原始分式没有定义；必须选择并报告一种约定，例如把这种一致情况计为 1，或在指定的平均方式中排除这种情况。

### 06 / 一步步算出结果

设一张自拟图像包含 1000 个像素，参考标注中有 40 个叶片像素。全部预测为背景时，像素准确率达到 960 / 1000 = 96%，但由于没有找到任何叶片像素，前景 IoU 与 Dice 均为 0。第二个预测把 50 个像素标为叶片，其中 30 个与参考前景重合。并集包含 50 + 40 − 30 = 60 个像素，所以 IoU = 30 / 60 = 0.5。Dice = 60 / 90，约为 0.6667，也等于 2 × 0.5 / 1.5。该预测有 20 个误报前景像素，漏掉 10 个叶片像素。两个重叠分数用不同尺度描述相同掩码；不能把它们与像素准确率直接作数值比较，仿佛三者衡量的是同一种量。

**类比的边界与注意事项:** 一个着色区域的含义取决于标注规则。模糊边界、透明对象和相互重叠的实例可能需要细致约定。较高的平均重叠度仍可能掩盖小对象漏检或重要边界错误，而仅凭前景面积无法确定个体数量。

**记住这一点:** 让掩码类型对应实际问题，检查占少数的前景，并明确重叠度与空掩码情况的评分方式。

## 让图像块交换信息

### 01 / 从一个完整故事开始

Mateo 正在制作一个教学展示，按整体图案给手工风筝照片分类。角落附近的一条纹路，只有结合尾部才能体现意义，因此他想理解模型如何联系图像中相距较远的区域。他在每张照片上画出网格，把每个方块看成一段简短的数值描述。Transformer 可以让这些描述在最终判断前交换信息。Mateo 最初以为，把方块宽度减半只会使工作量翻倍。数清网格后，他改变了看法：图像块数量变成四倍，可以相互作用的成对组合更多。他让第一版展示保持较小规模，并在每张图片旁显示词元数量。这样，展示既解释了模型如何跨区域联系图像，也解释了视觉单元变细所带来的计算代价。

### 02 / 理解核心概念

原始 Vision Transformer 把图像划分为不重叠的图像块，将每块展平，再使用共享的可学习线性投影。位置嵌入保留词元所处位置的信息。一个可学习的类别词元加入序列，其最终表示用于图像分类。自注意力让词元结合其他词元的信息。对于全注意力，词元对的数量随序列长度呈平方增长。这描述的是注意力中的一部分，并非总运行时间的通用缩放规律：投影、其他层、硬件与实现细节同样会产生开销。图像块是数值单元，不一定对应可辨认的对象。

### 03 / 如何运用这个概念

选择图像分辨率与图像块大小之前，先计算图像块数量，以及包括特殊词元在内的序列长度。检查图像尺寸能否整除，还是需要明确的缩放或填充规则。比较细节保留程度与实际资源消耗，并遵循预训练模型的位置处理方式。对于新任务，先检查缩放是否丢失有用证据，再分析注意力是否造成了错误。

### 04 / 官方教程与研究中的应用

原始 ViT 论文通过投影后的图像块与 Transformer 编码器完成图像分类，并研究大规模预训练后的迁移。TorchVision 的 VisionTransformer 实现使图像块投影和额外类别词元可以直接检查。原始 Transformer 论文解释了这种信息交换背后的注意力运算。这些资料支持这里介绍的设计；手工风筝展示及其小型数值例子是原创教学情景。

### 05 / 公式与逐项解析

```text
N = (H / P)(W / P); L = N + 1
xᵢ ∈ ℝ^(P²C); E ∈ ℝ^(D × P²C); tᵢ = Exᵢ + eᵢ
S = L²
```

H、W 分别是图像高度与宽度；P 是正方形图像块的边长，假设它能整除这两个尺寸。C 是通道数，N 是图像块数量，L 还包括一个类别词元。xᵢ 是将第 i 个图像块展平后得到的列向量。ℝ 表示元素为实数。E 把它投影到 D 维嵌入空间；eᵢ 是位置向量，tᵢ 是由此得到的图像块词元。这个简化表达式省略了投影偏置。S 统计每个全注意力头的词元对分数条目数，并非总运算次数，也不保证实现会分配相应大小的内存。

### 06 / 一步步算出结果

取一张自拟的 32×32 RGB 图像，正方形图像块边长为 8。图像块共有 (32 / 8)² = 16 个，每块包含 8² × 3 = 192 个数值。嵌入宽度 D = 64 时，投影矩阵形状为 64×192，为每个图像块产生一个含 64 个数的向量。加入一个类别词元后，L = 17，每个注意力头的词元对分数条目数 S = 17² = 289。把块边长减半到 4 后，有 64 个图像块，L = 65，S = 4225。分数条目数增加到原来的 4225 / 289，约为 14.62 倍；由于包含类别词元，并非恰好十六倍。这里固定了图像尺寸与嵌入宽度，并不能据此预测完整模型的运行时间也增加相同比例。

**类比的边界与注意事项:** 交换描述的类比，并不意味着词元像人一样推理，也不意味着注意力权重可以解释每次判断。简化计算针对嵌入宽度固定的普通全注意力。其他架构可以使用窗口、池化或不同词元设计，而更细的图像块本身也不保证识别更好。

**记住这一点:** 明确计算图像块与特殊词元：更细的视觉单元会增加可能的交互，而有用细节与实际运行时间仍需测量。

## 用下一次采集检验，而非只看熟悉的邻帧

### 01 / 从一个完整故事开始

Hana 在野生动物观察小组做志愿者，相机会连拍出几乎相同的照片。随机打乱后的评估表现很好，但相机移到阴暗小径后，预测明显变差。她发现，同一连拍中的相邻帧同时出现在训练集与评估集中，让熟悉的背景和动物跨过了数据边界。Hana 按采集组重新划分，并留出一个相机地点，单独检查环境偏移。分数下降了，错误却更有用途：较暗的空场景会触发错误的动物提示，而远处小动物容易漏掉。她报告精确率、召回率以及评估样本数量，再为下一轮开发采集有代表性的阴暗小径图片。这个较低的分数，让小组更清楚地了解，当下一张照片确实陌生时，模型能做到什么。

### 02 / 理解核心概念

评估估计的是特定抽样过程下的表现。相关帧、重复个体或共同采集时段如果被独立划分，可能造成信息泄漏。把它们分组，可以将所选的相关性来源限制在一个数据分区内；分组定义应符合希望检验的泛化问题。部署图像与开发数据不同时，例如相机地点或光照改变，就会发生领域偏移。精确率衡量预测为正的样本中有多少正确，召回率衡量实际正例中有多少被找到。两者都不能代替对分组、标签质量、样本数量与实际决策阈值的检查。

### 03 / 如何运用这个概念

划分数据前，先写清未来使用问题：熟悉相机的新帧、新采集时段，或全新地点，需要不同证据。据此对相关采集记录分组，并保留最终测试集。用验证数据选择阈值，按相关条件检查错误，同时报告总体与各组的计数。应明确测量新环境中的表现，而不是假设一个汇总分数能够原样迁移。

### 04 / 官方教程与研究中的应用

WILDS 研究基准包含野生动物监测中跨野外自动相机的分布偏移，提供了图像来源为何重要的具体记录。scikit-learn 的 GroupKFold 文档展示如何在训练折与测试折之间保持组身份分离，其评估指南则定义了精确率与召回率。这些资料支持考虑采集来源的评估方式；单凭分组划分，仍不能证明模型能适应未来每一台相机或每一个季节。

### 05 / 公式与逐项解析

```text
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F₁ = 2TP / (2TP + FP + FN)
```

TP 统计正确预测为正的正例，FP 统计被错误预测为正的负例，FN 统计被错误预测为负的正例。这里每个样本是一张图像，正例表示存在野生动物；这些计数不是像素数，也不是匹配后的检测框数。精确率与召回率分别使用所示分母；定义成立时，F₁ 通过调和平均结合两者。分数假设决策阈值固定。如果某个分母为零，应报告所采用的未定义情况处理约定及原始计数，而不是默默填入一个数值。

### 06 / 一步步算出结果

假设一个自拟留出组包含 100 张图片，其中 20 张有野生动物，80 张为空场景。在选定阈值下，模型对 25 张图片发出提示，其中 15 张确有动物，因此 TP = 15、FP = 10。它漏掉了 5 张有动物的图片，所以 FN = 5。精确率为 15 / 25 = 0.60，召回率为 15 / 20 = 0.75，F₁ 为 30 / 45，约为 0.6667。其余 70 张空场景被正确排除。因此总体准确率为 85 / 100 = 85%，但单看这个数字，会掩盖十次误报与五次漏报。这些计数描述的是该抽样组在该阈值下的表现，不能保证模型在未见过的相机地点上也有同样表现。

**类比的边界与注意事项:** 陌生照片的类比有助于发现泄漏，但陌生程度有多个维度。不同采集时段仍可能共享同一相机背景，新地点也可能改变类别频率。小评估组的估计具有不确定性；应始终保留样本数量，避免把一次划分当成通用性能证明。

**记住这一点:** 可信的视觉分数应明确目标总体，隔离相关采集记录，并揭示平均值背后的误报与漏报。

## 知识速查

### [追踪一个像素](#pixels-contracts)

追踪一个已知颜色在通道顺序、轴布局、缩放和归一化中的变化。形状合法，并不保证颜色解释正确。

### [明确局部问题](#filters-neighborhoods)

说明滤波器要抑制或揭示哪种变化。判断平滑是否保留有用证据之前，先检查核的方向与边界处理。

### [让标注一起移动](#geometry-augmentation)

让图像与目标一起变换。重新计算框的顶点，再检查裁剪，以及变换后的图像是否仍支持原标签。

### [区分特征与决策](#recognition-transfer)

识别被复用的主干与新的预测头。说明哪些参数可以改变，并在独立采集组上比较调整效果。

### [先算重叠，再做抑制](#detection-overlap)

两个面积为 16 的框，交集为 9，因此 IoU 为 9/23。阈值为 0.3 时抑制同类别低分框，为 0.5 时保留。

### [质疑背景主导的准确率](#segmentation-regions)

全背景掩码即使找不到任何前景，也可能获得 96% 准确率。解释语义与实例输出的区别，再说明重叠度平均方式和空掩码约定。

### [别漏掉额外词元](#visual-tokens)

十六个图像块加一个类别词元，共有 17 个词元，每个全注意力头产生 289 个成对分数。仅凭词元对数量无法确定运行时间。

### [说明下一批图像来自哪里](#evaluation-shift)

选择符合未来使用问题的分组方式。报告精确率与召回率背后的评估计数，并检查相机条件改变后的表现。
