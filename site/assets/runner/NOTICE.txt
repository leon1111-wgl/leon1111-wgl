Third-party software behind the Run buttons on this site.

C compiler: wcc from xcc by tyfkda. MIT License (c/LICENSE.xcc.txt). https://github.com/tyfkda/xcc
  Built from commit d7bb34e. stdio.h gains two small macros; see scripts/build_browser_c.py.

Java compiler: teavm-javac by Alexey Andreev, https://github.com/konsoletyper/teavm-javac
  Built from commit 76b5b53 with TeaVM 0.17.0-dev-3. Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0).
  It contains the Java compiler from OpenJDK, GPL version 2 with the Classpath Exception
  (https://openjdk.org/legal/gplv2+ce.html). Source: https://github.com/openjdk/jdk and the repository above.
  The archives add three small original classes (scripts/java_shims); see scripts/build_browser_java.py.

Python: Pyodide 0.27.7, Mozilla Public License 2.0, loaded from jsDelivr when you first press Run. https://pyodide.org

.github/workflows/build-runtimes.yml rebuilds the C and Java compilers from those commits.
