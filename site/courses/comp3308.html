COMP3308 / 01Guoliang

Model a problem, then choose a frontier

01 / The story

Imagine a delivery robot inside a museum. A state might record only its room, but that description fails if some doors require a key: two visits to the same room can have different futures. Recording the room and key status repairs the model. The robot then keeps a tray of unfinished routes.

A queue explores nearby rooms first; a stack follows one corridor deeply; a priority tray follows the cheapest journey so far. The analogy separates two decisions: describe enough of the world to predict legal moves, then choose which unfinished route deserves attention.

02 / The principle

A search problem specifies an initial state, actions, a transition model, a goal test and path costs. Search nodes also store parent links and accumulated cost; multiple nodes may represent the same state. Breadth-first search uses a FIFO frontier and finds a shallowest goal with finite branching, giving minimum cost when steps have equal cost.

Depth-first search uses a stack, needs little frontier memory, but can follow an infinite branch and is not generally optimal. Depth-limited search can miss deeper goals.

Iterative deepening repeats increasing limits, retaining depth-first memory with shallowest-goal completeness under finite branching. Uniform-cost search removes the smallest accumulated cost and tests goals on removal; on infinite spaces its usual completeness guarantee needs costs bounded below by a positive number.

Words to know

State
Information sufficient to determine legal future actions.
Frontier
Generated routes waiting to be explored.
Path cost
The sum of step costs on one route.

03 / The formula, unpacked

g(n) = Σ edge costs along the route to n
BFS: minimum depth; DFS: maximum current depth; UCS: minimum g(n)
BFS tree frontier: O(bᵈ); DFS tree frontier: O(bm); IDS: O(bd)

The symbol g(n) is the cost already paid to reach search node n. The summation adds every edge on that route, not just the last edge. Here b is the finite branching factor, d the shallowest solution depth, and m the maximum search depth.

The memory bounds describe conventional tree-search frontiers; a graph-search visited set adds storage. Frontier order describes which node is expanded next, not the final path itself.

04 / A first worked example

A robot has routes S→A costing 1, A→G costing 9, S→B costing 4 and B→G costing 2. Both goals lie two edges away. If A is generated first, breadth-first search can return S→A→G, costing 10.

Uniform-cost search removes S, then A with cost 1, then B with cost 4. Its goal candidates have costs 10 and 6, so it removes the cost-6 candidate and returns S→B→G. Parent links reconstruct that route. The expansion list S,A,B,G is not itself a legal route.

Let us work through it

  1. Why include a key in the state?

    It changes which doors can be opened.

  2. Why test UCS goals on removal?

    An earlier generated goal may be more expensive than another unfinished route.

  3. Is an expansion list a path?

    Usually not; use parent links to reconstruct one connected route.

Work through a problem · 01

Two equal-depth routes

Directed edges are S→A:2,A→G:8,S→B:3,B→G:2. No other edges exist. A is generated before B. Compare BFS and UCS.

Choose the method

Separate the number of edges from the sum of their costs.

  1. Both routes have two edges, so BFS can select A’s route by the stated order.

  2. Add costs: S-A-G costs 2+8=10; S-B-G costs 3+2=5.

  3. UCS removes A at 2, B at 3, then the goal at 5 before the goal at 10.

Interpret the answer

BFS can return cost 10; UCS returns S-B-G with cost 5.

Check the reasoning

The graph has only these two complete routes, and 5 is the smaller total.

Work through a problem · 02

A depth limit misses a solution

A chain S→A→B→G has unit costs. Root depth is zero. Try depth limit 2, then iterative deepening limits 0,1,2,3.

Choose the method

Label depths before deciding which nodes are reachable within a limit.

  1. S,A,B,G have depths 0,1,2,3 respectively.

  2. Limit 2 reaches B but cannot generate a permitted goal at depth 3.

  3. Limits 0,1,2 fail; limit 3 reaches G and reconstructs all three edges.

Interpret the answer

The depth-2 search terminates without a solution; iterative deepening finds cost 3 at limit 3.

Check the reasoning

Three edges are unavoidable because the graph is a single chain.

Guoliang's further thinking

Cost changes the algorithm choice

Counting edges solves cheapest travel only when every edge has equal cost. With differing costs, compare accumulated sums.

State merging needs justification

Merging two room visits is safe only if their future legal actions and costs match. A remaining battery budget can matter just as a key does.

Watch out. Calling depth-limited search complete merely because it terminates confuses termination with finding an existing goal. Its limit must reach a solution, and cycle handling must match the chosen state representation.
Check your understanding: When does breadth-first search behave like uniform-cost search?

When every step has the same positive cost and tie handling is aligned: accumulated cost is a constant times depth, so both expand layers in the same order.

A* and trustworthy lower bounds

01 / The story

Suppose a courier chooses between partly completed journeys. Looking only at money already spent rewards cheap starts that may have expensive endings. Looking only at a map estimate rewards routes that appear close to the destination despite costly detours already taken. A* writes both numbers on each route card.

Its remaining-cost estimate must behave like a defensible lower quote, not an optimistic marketing promise with arbitrary values. A relaxed map, where some obstacles disappear, supplies such a quote. Better lower quotes save exploration, although calculating them can itself be expensive.

02 / The principle

A* expands the frontier node minimizing accumulated cost plus estimated remaining cost. Admissibility means the estimate never exceeds the true cheapest remaining cost. Consistency additionally bounds each estimate by one step plus the successor estimate; with zero goal estimates it implies admissibility and nondecreasing f along paths. Tree-search A* is optimal with an admissible heuristic under the usual termination assumptions.

Graph search can safely close nodes permanently with a consistent heuristic; an admissible but inconsistent heuristic can require reopening a state when a cheaper route appears. Test the goal when selected for expansion. Finite branching and a positive lower step-cost bound support completeness in infinite spaces. Memory is often the practical bottleneck; IDA* trades repeated work for bounded depth-first storage.

Words to know

Heuristic
An estimate of remaining cost used to order exploration.
Admissible
Never larger than the true cheapest remaining cost.
Consistent
No estimate drops by more than the cost of one transition.

03 / The formula, unpacked

f(n) = g(n) + h(n)
Admissible: 0 ≤ h(n) ≤ h*(n)
Consistent: h(n) ≤ c(n,n′) + h(n′)
hmax(n) = max(h₁(n), …, hₖ(n))

Here h(n) estimates the remaining cost and h*(n) is the true minimum remaining cost. The edge from n to n′ costs c(n,n′). Thus f is a lower bound on a solution through n when h is admissible.

Taking the maximum of several admissible heuristics preserves admissibility; summing them generally does not. A dominating heuristic is at least as large everywhere, but total runtime also depends on its computation cost and tie handling.

04 / A first worked example

Consider S→A of cost 2, A→G of cost 3, S→B of cost 1 and B→G of cost 8. Set h(A)=3, h(B)=1, h(S)=2 and h(G)=0. After expanding S, A has f=5 while B has f=2. Expanding B generates a goal with g=9, but A remains at f=5.

A is expanded next and creates a better goal with g=5. Only when this goal is removed does search finish. All heuristic values are admissible and consistent; stopping at the first generated goal would return the wrong answer.

Let us work through it

  1. What is f when g=4,h=3?

    Seven: add paid and estimated remaining cost.

  2. Is zero heuristic admissible for nonnegative costs?

    Yes; A* then orders nodes like UCS.

  3. May two lower bounds be added?

    Not generally; they may count the same necessary work twice.

Work through a problem · 01

Choose the next frontier node

Frontier entries A:(g=3,h=4), B:(5,1), C:(2,6). Assume these are admissible estimates and expand smallest f.

Choose the method

Compute each total before comparing.

  1. A has f=3+4=7.

  2. B has f=5+1=6, while C has f=2+6=8.

  3. The minimum is 6 at B, despite B having the greatest cost already paid.

Interpret the answer

Expand B first. The ordering is B,A,C if no new nodes appear.

Check the reasoning

Choosing only the smallest g would pick C, confirming that A* uses both terms.

Work through a problem · 02

Admissible but inconsistent

Edges are A→B:1,B→G:4,A→G:7. Let h(A)=5,h(B)=2,h(G)=0. Check admissibility and consistency.

Choose the method

First find true cheapest remaining distances, then test every edge inequality.

  1. True distances are h*(B)=4 and h*(A)=min(7,1+4)=5.

  2. Estimates 5≤5, 2≤4 and 0≤0 are nonnegative and admissible.

  3. On A→B, consistency needs 5≤1+2=3, which is false. The other two edge tests pass.

Interpret the answer

The heuristic is admissible but inconsistent, so permanent closing needs additional care.

Check the reasoning

Along A→B, g rises by 1 but h falls by 3, so f falls by 2, exposing inconsistency.

Guoliang's further thinking

Check edges as well as goals

A table can underestimate every true remaining distance and still violate consistency on an edge. Reopening addresses that distinction.

A better estimate has a price

If computing h takes longer than expanding the nodes it saves, a tighter bound can slow the whole search. Count both costs.

Watch out. Admissibility alone does not justify discarding every later route to a closed state. Use consistency or implement cheaper-path reopening correctly.
Check your understanding: For a sliding-tile puzzle, why is Manhattan distance admissible when the blank is excluded?

Each move shifts one numbered tile by one grid step. Every tile must cover at least its Manhattan displacement, so the sum cannot exceed the number of required moves. Counting the blank as well can double-count progress.

Hill climbing, restarts and beam search

01 / The story

A venue planner adjusts a seating arrangement to reduce awkward pairings. The route taken through previous arrangements is irrelevant; only the final arrangement matters. Hill climbing resembles keeping one layout on the desk and accepting the best nearby improvement.

A local beam keeps several candidate layouts, but if they all look almost identical, the extra desks provide little exploration. Random restarts resemble beginning with a fresh seating plan rather than endlessly rearranging a stubborn one. This analogy fits optimization of complete configurations, but it does not establish that nearby layouts reveal the quality of distant arrangements.

02 / The principle

Local search evaluates complete candidate states with an objective and a neighborhood relation. For minimization, steepest descent chooses the neighbor with smallest objective, moving only when improvement is allowed.

It can stop at a local minimum, stall on a plateau or struggle on a ridge whose useful direction is absent from the allowed moves. Sideways moves, richer neighborhoods, limited lookahead and random restarts alter this behavior. Local beam search expands successors of k current states and retains the best k globally; it is not simply k independent hill climbers.

A levelwise beam search similarly discards candidates outside its beam. Permanent pruning saves memory but can remove every route to a goal, so neither ordinary beam search nor ordinary hill climbing is generally complete or optimal.

Words to know

Neighborhood
The candidate configurations reachable by one allowed change.
Local minimum
No allowed neighbor has a smaller objective.
Beam width
The number of candidates retained after global selection.

03 / The formula, unpacked

snext ∈ argmin{V(u) : u ∈ N(s)}
Restart success probability after r independent runs = 1 − (1 − p)ʳ

V(s) is the objective value of configuration s, with smaller values preferred here. N(s) is the set of allowed neighboring configurations. The argmin notation means a state attaining the lowest score, with a separate tie rule.

In the restart expression, p is one run’s probability of reaching a desired solution and r counts independent runs with the same success probability. The expression does not apply unchanged to correlated restarts or changing budgets.

04 / A first worked example

A current timetable scores 12 conflicts. Its neighbors score 9, 10 and 14, so steepest descent chooses the score-9 timetable. Its next neighbors score 11, 12 and 9. A strict-improvement rule stops, although another distant timetable scores 0.

A beam of width 2 would initially retain scores 9 and 10, potentially exploring an escape through the second candidate. Suppose independent random restarts each find a zero-conflict timetable with probability 0.2. Five runs succeed with probability 1−0.8⁵=0.67232, about 67.2%. This quantifies improvement in chances without claiming certainty after five runs.

Let us work through it

  1. Does a local minimum prove global optimality?

    No; better states may lie beyond a worse intermediate step.

  2. What does a strict descent rule do on ties?

    It does not move to an equal-score neighbor.

  3. Why can beams lose diversity?

    Several retained candidates may come from the same region.

Work through a problem · 01

Select a beam globally

Beam width is 2. Candidate X has successor scores 4,8; Y has scores 3,5. Scores are minimized, and all successors are distinct.

Choose the method

Pool successors before selecting.

  1. The pooled scores are 4,8,3,5.

  2. Sort ascending to obtain 3,4,5,8.

  3. Keep the first two: score 3 from Y and score 4 from X.

Interpret the answer

The next beam has scores 3 and 4, exactly two states.

Check the reasoning

Keeping one best child per parent happens to agree here, but with X:(1,2),Y:(3,4), global selection would keep both from X.

Work through a problem · 02

Three independent restarts

A run succeeds with probability 1/4. Assume three independent runs with identical budgets. Find the probability of at least one success.

Choose the method

It is easier to count the complementary event: all fail.

  1. One run fails with probability 1−1/4=3/4.

  2. Independence makes all-fail probability (3/4)³=27/64.

  3. Subtract from one: 1−27/64=37/64=0.578125.

Interpret the answer

Success probability is 57.8125%, greater than 25% but below certainty.

Check the reasoning

The two complementary probabilities 37/64 and 27/64 sum to 1.

Guoliang's further thinking

Change the neighborhood

A swap of two items may be necessary even when moving either item alone makes the objective worse. A richer move set can remove a local trap.

State the independence assumption

Repeatedly restarting from the same seed can reproduce the same failure. The formula 1−(1−p)^r assumes independent chances.

Watch out. Keeping the best k successors of each beam member creates up to k² candidates and describes a different algorithm from retaining the best k across the combined successor pool.
Check your understanding: Why can allowing unlimited equal-score moves make hill climbing worse?

It can cycle indefinitely across a plateau. Bound sideways moves, track repeated states or use a deliberate stochastic exploration policy.

Simulated annealing and genetic search

01 / The story

A landscape photographer wants a high viewpoint but must sometimes walk downhill to reach a better ridge. Early in the day, exploration is affordable; near sunset, risky detours become less attractive. Annealing captures that changing willingness to accept a worse step.

Genetic search instead resembles maintaining many candidate itineraries, combining promising segments and occasionally making a surprising change. The biological language is only a design metaphor: crossing two good itineraries can create an impossible trip, and a fitness score can reward the wrong thing. Both methods depend on how candidates, neighborhoods and objectives are encoded.

02 / The principle

Simulated annealing samples a neighbor and always accepts an improving move; a worsening move is accepted with a probability controlled by its loss and the current temperature. Cooling reduces exploratory moves. Asymptotic convergence results require restrictive cooling and connectivity assumptions and do not guarantee an optimum for an ordinary finite run.

A genetic algorithm maintains a population, selects parents according to fitness, recombines their encodings and applies mutation. Selection intensifies exploitation; mutation and population diversity support exploration.

Constraints may require a representation that always remains valid or an explicit repair or penalty method. Elitism can retain the best candidate but does not prove global optimality. Always report the best objective found and the computational budget, rather than presenting one stochastic run as a proof.

Words to know

Temperature
A positive control of willingness to accept worse moves.
Mutation
A random change to a candidate encoding.
Fitness
A score used to favor candidates during selection.

03 / The formula, unpacked

Δ = V(candidate) − V(current)
P(accept) = min(1, exp(−Δ/T)), T > 0
Fitness-proportional selection: P(i) = Fᵢ / Σⱼ Fⱼ

V is an objective to minimize, so a positive Δ means deterioration. T is the positive temperature on the same scale as the objective difference. The exponential gives a number between zero and one for worsening moves.

Fᵢ is a nonnegative fitness to maximize for individual i; the selection denominator must be positive. Objective values and fitness are different conventions, so a cost may need a justified transformation before fitness-proportional selection.

04 / A first worked example

A routing candidate costs 40 and a proposed neighbor costs 44, so Δ=4. At temperature 8, acceptance probability is exp(−0.5)≈0.6065; at temperature 2 it is exp(−2)≈0.1353. A uniform random draw of 0.3 accepts the first proposal but rejects the second.

Separately, three genetic candidates have fitnesses 2, 3 and 5, giving selection probabilities 0.2, 0.3 and 0.5. Crossing bit strings 1100 and 0011 after the second position produces 1111 and 0000. Their fitness must be evaluated afresh: parent quality does not determine child quality.

Let us work through it

  1. What if Δ is negative?

    The move improves a minimized objective and is accepted with probability 1.

  2. What does cooling change?

    It lowers acceptance probability for a fixed positive deterioration.

  3. Does crossover ensure valid children?

    No; representation and constraint handling must ensure validity.

Work through a problem · 01

A cooling decision

Minimize cost. Current cost 20, proposed 22. Use temperatures 4 and 1, with the same uniform draw 0.4; accept when draw is below probability.

Choose the method

Compute deterioration once, then substitute each temperature.

  1. Δ=22−20=2, a worsening move.

  2. At T=4, exp(−2/4)≈0.606531, above 0.4, so accept.

  3. At T=1, exp(−2)≈0.135335, below 0.4, so reject.

Interpret the answer

The warmer run accepts and the cooler run rejects this same worse proposal.

Check the reasoning

Both probabilities lie between 0 and 1 and decrease when temperature falls.

Work through a problem · 02

Select and recombine

Three fitnesses are 1,2,5. Parents 101010 and 010101 cross after position 3, counting from 1. Compute selection probabilities and children.

Choose the method

Normalize scores, then exchange suffixes at the stated cut.

  1. Total fitness is 1+2+5=8.

  2. Probabilities are 1/8,2/8,5/8, or 0.125,0.25,0.625.

  3. Split 101|010 and 010|101; exchanging suffixes gives 101101 and 010010.

Interpret the answer

The probabilities favor fitness 5, while the children are 101101 and 010010; their quality still needs evaluation.

Check the reasoning

Probabilities sum to 1 and both children retain length 6.

Guoliang's further thinking

Scale temperature with the objective

Multiplying all objective values and T by the same positive number leaves Δ/T and acceptance probabilities unchanged.

Zero fitness is allowed, zero total is not

An individual with fitness 0 receives probability 0. If all are 0, division fails and a fallback selection rule must be specified.

Watch out. Do not state that annealing is always complete and optimal because a slow-cooling theorem exists. Its limiting assumptions and infinite-time statement differ from a practical schedule.
Check your understanding: What happens if a fitness-proportional scheme is given negative fitness values?

They cannot define selection probabilities. Use an appropriate nonnegative transformation, rank selection or another explicitly defined selection scheme, and examine how the transformation changes selection pressure.

Minimax and alpha–beta bounds

01 / The story

Two players alternately choose which corridor a token follows through a maze. At the exit, one receives the number printed there and the other loses the same amount. A tempting corridor may contain a wonderful exit that the opponent will never permit. Minimax evaluates what each player can enforce, working backward from exits.

Alpha–beta pruning is like closing a corridor after proving that an earlier choice already guarantees something better. It is a proof that further inspection cannot change the present decision, not a guess that an unexplored corridor probably looks uninteresting.

02 / The principle

For a finite deterministic two-player zero-sum game with perfect information, minimax backs up maximum values at MAX nodes and minimum values at MIN nodes. Exact terminal utilities yield an optimal strategy against optimal opposition; a weaker opponent cannot force a worse value if MAX continues to follow a minimax strategy.

Alpha–beta performs the same depth-first backup while carrying bounds from ancestors. Alpha is a lower bound already available to MAX, and beta an upper bound available to MIN. Once alpha is at least beta, remaining siblings cannot improve the relevant ancestor’s decision.

The root value equals full minimax, although tied move selection can differ. Move ordering changes pruning efficiency; worst-case work remains exponential, while ideal ordering can roughly double reachable depth for a fixed budget.

Words to know

Utility
A numerical outcome value from a fixed player’s perspective.
Minimax
Choose the best outcome that optimal opposition allows.
Pruning
Skip a branch after proving it cannot change the needed decision.

03 / The formula, unpacked

V(s) = U(s) at terminal states
V(s) = max V(child) at MAX; min V(child) at MIN
Prune when α ≥ β
Full-tree time O(bᵐ); depth-first space O(bm)

U(s) is a terminal payoff measured from MAX’s perspective. V(s) is the backed-up value, and child ranges over legal successors. Alpha and beta describe bounds relevant to the current search path, not independent global scores for all nodes.

Here b is branching factor and m the searched depth. The storage expression assumes depth-first traversal with successor lists; storing the whole game tree would have a much larger memory cost.

04 / A first worked example

MAX has three moves leading to MIN nodes. Their leaves, visited left to right, are A:[5,7], B:[3,100], and C:[6,4]. A returns 5, so root alpha becomes 5. At B, seeing its first leaf 3 sets beta to 3.

Since beta≤alpha, leaf 100 can be skipped: MIN can already limit B to at most 3. At C, the first leaf 6 does not permit pruning, so inspect 4 and return 4. MAX chooses A, guaranteeing 5. The pruned leaf could be enormous without changing the choice.

Let us work through it

  1. Why does MIN take the smaller number?

    Numbers measure MAX’s utility, which the opponent seeks to reduce.

  2. Does a huge hidden leaf prevent pruning?

    Not if another MIN child already gives a low upper bound.

  3. Does move order change exact root value?

    No, but it changes how much work can be skipped.

Work through a problem · 01

Back up a small tree

MAX chooses between MIN nodes L with leaves 8,3 and R with leaves 4,6. All are terminal MAX utilities.

Choose the method

Evaluate opponents’ responses before choosing at the root.

  1. MIN at L takes min(8,3)=3.

  2. MIN at R takes min(4,6)=4.

  3. MAX then takes max(3,4)=4.

Interpret the answer

Choose R, guaranteeing 4 against optimal opposition.

Check the reasoning

Choosing the largest leaf 8 would fail because MIN can instead choose 3.

Work through a problem · 02

Prove a cutoff

Root MAX already has a completed move worth 6. Its next MIN child has leaves 4,9,100 in that order. Show what may be skipped.

Choose the method

Carry the root lower bound into the MIN node.

  1. The earlier move establishes α=6.

  2. Seeing the first leaf 4 gives this MIN node β≤4.

  3. Since β≤4<6≤α, the remaining leaves cannot make MIN’s value exceed the root’s available 6.

Interpret the answer

Skip 9 and 100; retain the earlier root move.

Check the reasoning

Full evaluation gives min(4,9,100)=4, confirming the bound and decision.

Guoliang's further thinking

A bound is not necessarily an exact value

After cutting a MIN node on a low child, its true value might be even lower. The ancestor only needs proof that this move cannot beat its alternative.

Model assumptions matter

Hidden cards require information-state reasoning. A minimax tree that secretly uses an opponent’s unseen cards solves a different problem.

Watch out. Use the same utility perspective throughout the tree. Alternating the sign informally while also applying MIN can reverse the decision twice.
Check your understanding: Does alpha–beta make a shallow heuristic evaluation more accurate?

No. It preserves the minimax result for the same searched tree and leaf values. Saved work can fund a deeper search, but pruning itself does not improve the evaluation function.

Cutoffs, chance nodes and multiple players

01 / The story

A board-game program has ten seconds to move. It cannot inspect every ending, so it stops at a horizon and estimates the unfinished positions. A position that looks profitable immediately before a forced loss illustrates the danger of a horizon.

Dice add a different complication: the player cannot choose which number appears, so outcomes must be averaged according to their probabilities. Adding a third player changes the incentives again, because two opponents need not want the same outcome. Time limits, randomness and multiple interests require separate changes to the model rather than one universal game-search shortcut.

02 / The principle

A depth cutoff substitutes a heuristic evaluation for terminal utility, sacrificing exact-game optimality. Iterative deepening retains the last completed search when time expires. Quiescence search extends tactically unstable positions using selected forcing moves, but still needs termination controls.

A linear evaluation combines features and may miss interactions. Expectiminimax adds chance nodes whose values are probability-weighted expectations, while MAX and MIN backups remain unchanged. Expected-utility decisions require cardinal utility: a positive affine transformation preserves preferences, but an arbitrary increasing transformation need not.

Ordinary alpha–beta reasoning cannot simply ignore chance outcomes; valid pruning needs bounds on unseen values and probability mass. For more than two players, a Max-n backup carries a utility vector and each player selects its own component, without the two-player zero-sum guarantee.

Words to know

01 / The story

A repair workshop estimates a new bicycle’s service time by finding similar past jobs. If past records include actual repair times, averaging nearby records is supervised regression; if they include repair categories, voting is classification. Grouping unlabeled jobs into types is clustering.

Learning which repair action earns a later reward is reinforcement learning, and discovering which replacement parts co-occur is association learning. 02 / The principle

A supervised learner uses input–target pairs to predict unseen targets. K-nearest neighbors stores training examples and delays most computation until prediction, making it a lazy learner. Classification uses a vote among k closest examples; regression typically averages their targets, optionally with distance weights. Euclidean, Manhattan and general Minkowski distances encode different geometry.

Fit scaling on training data only and apply it unchanged to validation and test data. Nominal features need a meaningful mismatch or encoding rule; arbitrary integer labels introduce false distances. Missing values require an explicit policy rather than an assumed universal penalty. Small k can follow noise, large k can blur real boundaries. Irrelevant dimensions can weaken useful neighborhoods, so feature selection and validation are important.

A measured input property, such as length.
Regression
Predicting a numerical target.
Distance weighting

1R: a useful one-feature baseline

01 / The story

A librarian wants a quick rule for predicting whether a returned item needs repair. They could inspect dozens of attributes, but first try a single one, such as binding type. For each binding type, they write the most common outcome observed in past records.

They then repeat with age group and cover material, keeping the attribute that makes the fewest mistakes. This is a deliberately modest benchmark: if a complicated system cannot beat it on new records, complexity needs justification. One feature can generate several branches, so “one rule” does not mean one literal sentence or one outcome.

02 / The principle

For each candidate attribute, 1R partitions the training data by attribute value and predicts the majority class in each group. It selects the attribute whose complete rule has the smallest training error. Ties need a deterministic convention. A missing value can be treated as a distinct category, provided that policy makes sense for the data-generating process.

Numeric attributes require intervals: sort values, propose boundaries and avoid tiny intervals that memorize individual labels. Minimum bucket sizes and merging adjacent same-label intervals can constrain complexity. A 1R model is interpretable and supplies a strong sanity-check baseline, but interactions between attributes are invisible to it. Attribute and discretization selection are training decisions, and final performance must be assessed on held-out observations.

Words to know

Baseline
A simple reference method used for comparison.
Majority class
The most frequent label in a group.
Discretization
Replacing numerical values with interval categories.

03 / The formula, unpacked

prediction(v) = argmax꜀ count(attribute=v, class=c)
Errors(attribute) = Σᵥ [count(v) − max꜀ count(v,c)]

The value v ranges over one attribute’s categories or numeric intervals, and c ranges over classes. Count(v,c) counts training records with both that value and that class; count(v) counts all records in the group.

Subtracting its majority count gives the unavoidable training mistakes for a constant prediction in that group. Sum those mistakes across groups and compare attributes. The rule for a previously unseen category must also be specified, such as a training-set majority fallback.

04 / A first worked example

Eight devices have a target label repair or keep. For cover type, metal contains three repair and one keep, while plastic contains one repair and three keep. Predicting repair for metal and keep for plastic makes one error in each group, two total.

For age band, young contains two repair and one keep; old contains two repair and three keep. The best age rule makes one plus two errors, three total. The chosen 1R model therefore uses cover type, achieving 6/8=75% training accuracy. A new plastic device is predicted keep regardless of its age, exposing the model’s deliberate limitation.

Let us work through it

  1. Does 1R use exactly one branch?

    No, one attribute can have several values and branches.

  2. How many errors in a group with 4A,1B?

    One, when predicting the majority A.

  3. Can zero training error prove a good model?

    No, the rule may merely memorize unique identifiers.

Naive Bayes and smoothed likelihoods

01 / The story

An inbox filter combines clues such as a special offer word and an unfamiliar sender. First it asks how frequent spam is before reading either clue. Then it asks how expected each clue would be if the message were spam or ordinary mail.

Combining those answers reverses the direction of reasoning from “what spam tends to contain” to “what this message probably is.” The naive step treats the clues as independent once the class is known. Repeating the same clue in several correlated forms can therefore make the filter more confident without supplying much genuinely new evidence.

02 / The principle

Naive Bayes models a class prior and one conditional feature distribution per class, then multiplies them using conditional independence given the class. This is not an assumption that every feature is equally informative: different likelihood ratios can have very different influence.

For categorical data, frequency estimates need smoothing so an unseen value does not force a whole class score to zero. Numeric features can use a Gaussian density with class-specific mean and variance, or another suitable distribution. Evaluate products in log space to avoid numerical underflow.

Missing observed features can be marginalized away under the model, but the winning class can change and informative missingness needs extra modeling. Normalize class scores when probabilities are required, while recognizing that a misspecified independence model may produce poorly calibrated probabilities.

Words to know

Prior
A class probability before the current evidence.
Likelihood
How expected the observed evidence is under a proposed class.
Smoothing
Adding specified pseudo-counts to avoid unsupported zero estimates.

03 / The formula, unpacked

P(c|x) ∝ P(c) Πⱼ P(xⱼ|c)
P(xⱼ=v|c) = (N꜀ᵥ + 1)/(N꜀ + kⱼ)
Gaussian density: exp(−(x−μ)²/(2σ²))/(σ√(2π))

Here c is a class, xⱼ the jth observed feature, and the proportionality omits a denominator shared by all classes. N꜀ᵥ counts class-c records with value v; N꜀ is the number with observed values for that feature, and kⱼ is its possible category count.

Laplace smoothing adds one to every category. The Gaussian expression is a density, not the probability of one exact real number; μ and positive σ are class-specific parameters.

04 / A first worked example

Suppose P(spam)=0.25 and P(ordinary)=0.75. Given spam, an offer word occurs with probability 0.8 and an unfamiliar sender with probability 0.6. Given ordinary mail, the corresponding probabilities are 0.1 and 0.2. For a message with both clues, the naive scores are 0.25×0.8×0.6=0.12 and 0.75×0.1×0.2=0.015.

Dividing by their sum 0.135 gives a spam posterior of 8/9≈0.8889. Separately, an unseen value among four possible categories in six class records receives smoothed probability (0+1)/(6+4)=0.1, rather than zero. Both class scores use the same evidence, so their normalization denominator is shared. A prediction compares those scores before normalization as well.

Let us work through it

  1. Independent before or after knowing the class?

    The model assumes independence after conditioning on the class.

  2. Do scores already sum to 1?

    Usually not; divide each by the sum when posterior probabilities are needed.

  3. Why use logarithms?

    Products of tiny probabilities can underflow; logs turn products into sums.

Validation, cross-validation and comparisons

01 / The story

A chef tunes a recipe with one group of tasters and reserves another group for the final tasting. Asking the reserved group after every adjustment turns them into tuning tasters, even if nobody changes their name. Machine-learning evaluation has the same problem: repeatedly inspecting a test score makes it part of development.

Cross-validation rotates the tasting role so limited data contributes to several training runs, but recipes trained on overlapping ingredients are not statistically independent experiments. Good evaluation begins by defining which future customers the result is intended to represent, then separating development choices from the final estimate.

02 / The principle

Training estimates model parameters; validation selects hyperparameters, features, preprocessing and stopping rules; a test set estimates performance after those choices are fixed. Holdout uses one split, repeated holdout explores split variability, and k-fold cross-validation rotates the held-out fold.

Stratification approximately preserves class proportions but does not solve leakage from repeated people, time order or related records; those need group-aware or chronological splitting. Fit every learned preprocessing operation within each training fold. Leave-one-out trains n models and can be expensive. Compare models on identical splits using paired differences.

A classical paired t interval assumes approximately independent differences with an appropriate distribution; ordinary cross-validation folds overlap in training data, so its naive interval can be overconfident. Retraining for deployment changes the fitted model and does not create a fresh test estimate.

Words to know

Validation
Development data used to choose model settings.
Leakage
Information unavailable at prediction time enters model development.
Paired comparison
Compare two models using the same evaluation observations.

03 / The formula, unpacked

CV score = (1/k) Σᵢ scoreᵢ for equally sized folds
d̄ = (1/k)Σᵢ dᵢ
sd² = Σᵢ(dᵢ − d̄)²/(k−1)
Classical paired interval: d̄ ± t* sd/√k

k is the number of paired evaluations and dᵢ is model A’s score minus model B’s score on the same evaluation data. The bar denotes a mean and sd the sample standard deviation of differences.

The critical value t* depends on the confidence level and k−1 degrees of freedom. This interval is a statistical model with assumptions, not an automatic certificate of superiority. Unequal fold sizes can require weighting when estimating pooled per-example performance.

04 / A first worked example

A dataset has 120 independent observations. In six-fold cross-validation, each run trains on 100 and evaluates on 20. Every observation is evaluated once, although training sets overlap. Suppose two models’ paired score differences across five separate, suitably independent experiments are 0.02, 0.04, 0.03, 0.01 and 0.05.

Their mean is 0.03 and sample standard deviation is about 0.01581. With t*=2.776, the classical 95% interval is 0.03±0.01963, or roughly [0.0104,0.0496]. Applying that calculation uncritically to five ordinary CV folds would ignore their dependence and overstate the evidence.

  1. Does stratification remove time leakage?

    No; it balances class proportions, not chronological order.

  2. Where should scaling be fitted in CV?

    Inside each fold’s training portion.

  3. Is the test set for tuning?

    No; using it for choices turns it into development data.

Confusion matrices and error costs

01 / The story

A parcel scanner flags damaged packages for inspection. Catching nearly every damaged parcel sounds excellent, but if it also flags almost every intact parcel, inspectors drown in unnecessary work. Conversely, a very cautious scanner may make few false accusations while missing most damage.

A confusion matrix keeps both stories visible by counting correct and incorrect decisions separately for each true condition. The practical decision also depends on consequences: an unnecessary inspection and a missed damaged package need not cost the same. A single headline percentage cannot express all of these operational tradeoffs.

02 / The principle

For a chosen positive class, a confusion matrix records true positives, false positives, false negatives and true negatives. Accuracy counts all correct decisions, precision asks how trustworthy positive predictions are, and recall asks how many actual positives are recovered.

F1 is their harmonic mean and does not use true negatives. Class imbalance can make accuracy high for a useless majority predictor. Define what to do when a metric denominator is zero, and choose macro, micro or weighted averaging deliberately in multiclass tasks.

Changing a decision threshold often trades precision against recall, although it is not a universal algebraic opposition across different models. A cost matrix weights the consequences of errors. Choose a threshold on validation data and assess it on held-out data under the relevant class prevalence.

Words to know

Precision
The fraction of positive predictions that are truly positive.
Recall
The fraction of actual positives successfully found.
False negative
A truly positive example incorrectly predicted negative.

03 / The formula, unpacked

Accuracy = (TP+TN)/N
Precision = TP/(TP+FP); Recall = TP/(TP+FN)
F1 = 2TP/(2TP+FP+FN)
Total error cost = cFP·FP + cFN·FN

TP counts true positives; FP false positives; FN missed positives; TN true negatives; N is their sum. The positive class must be named before computing the metrics. cFP and cFN are application-specific costs per corresponding mistake, assumed constant in this simplified expression.

F1 ranges from zero to one when defined and gives neither a probability nor a cost estimate. If no positive predictions exist, precision needs an explicit reporting convention.

04 / A first worked example

Among 200 packages, 40 are truly damaged. The scanner flags 50, including 30 damaged ones. Thus TP=30, FP=20, FN=10 and TN=140. Accuracy is 170/200=85%; precision is 30/50=60%; recall is 30/40=75%; F1 is 60/(60+20+10)=2/3≈66.7%. If unnecessary inspection costs 2 units and missing damage costs 15 units, total error cost is 20×2+10×15=190.

A scanner that never flags anything has 80% accuracy but costs 40×15=600, showing why the operational objective matters more than a small difference in accuracy alone. The cost comparison keeps the same package population and counts both kinds of mistake explicitly.

Let us work through it

  1. Which denominator measures recall?

    All actual positives: TP+FN.

  2. Does F1 use TN?

    No; adding true negatives alone does not change F1.

  3. Why name the positive class?

    Swapping class roles changes precision and recall.

Decision trees, entropy and information gain

01 / The story

A museum guide identifies an artifact by asking a sequence of questions. A helpful first question divides the collection into groups that are much easier to identify. A question that almost always receives the same answer teaches little; a question that identifies every item by its catalogue number memorizes the collection without helping with new arrivals.

Decision-tree learning formalizes this choice by measuring uncertainty before and after a question. Each branch then asks its own follow-up question using only the artifacts that reached it. This local process creates a readable decision procedure, although locally useful questions need not produce the globally smallest tree.

02 / The principle

A classification tree tests an attribute or threshold at each internal node and predicts a class at a leaf. ID3 greedily chooses high information gain, partitions the data and recurses on each subset. Entropy measures uncertainty in the class distribution; information gain subtracts the size-weighted child entropy from parent entropy.

Pure nodes have entropy zero. If no informative split remains, predict a majority class rather than continuing forever; empty branches need a fallback based on available parent data. Numeric threshold tests produce axis-aligned boundaries, whereas categorical tests branch on values.

A tree can represent complex finite mappings, but conflicting labels for identical features cannot be perfectly classified by a deterministic function. Learning a compact generalizable tree requires more than reducing training entropy.

Words to know

Entropy
A measure of uncertainty in a label distribution.
Information gain
Parent uncertainty minus expected uncertainty after a split.
Pure node
A node containing only one observed class.

03 / The formula, unpacked

H(Y) = −Σ꜀ p꜀ log₂ p꜀, with 0 log₂ 0 defined as 0
IG(S,A) = H(S) − Σᵥ (|Sᵥ|/|S|)H(Sᵥ)

p꜀ is the fraction of observations in class c. The logarithm base two measures entropy in bits; the zero-probability term is defined by its limit, not by claiming log₂0 equals zero.

S is the current training subset, A a candidate attribute and Sᵥ a child subset. Its weight |Sᵥ|/|S| is the fraction routed to that branch. Information gain therefore averages uncertainty over examples, not equally over differently sized branches.

04 / A first worked example

A node contains eight artifacts: four class A and four class B, so entropy is 1 bit. A proposed question creates one child with three A and one B and another with one A and three B. Each child has entropy −0.75log₂0.75−0.25log₂0.25≈0.8113 bits.

The weighted child entropy is also 0.8113, giving gain 0.1887 bits. A second question creates two pure four-item children, giving child entropy 0 and gain 1. On this training data, the greedy rule selects the second question. Whether it generalizes depends on how the question was obtained and validated.

Let us work through it

  1. Entropy of one certain class?

    Zero, since there is no class uncertainty.

  2. Why weight child entropies?

    Larger children contain more observations and should contribute more.

  3. Does greedy mean globally best tree?

    No, the best immediate split may not give the best complete tree.

Grow useful trees without memorizing noise

01 / The story

A gardener can let every twig grow or trim branches that consume space without producing useful fruit. A learned tree has a similar tension: extra branches can explain unusual training records while making future decisions less reliable. Trimming must be judged on evidence beyond the records that created the branches.

Numeric questions also need restraint; carving a tiny interval around every unusual value produces a tidy training story and a brittle classifier. The gardening analogy helps explain complexity control, but a statistically useful pruning decision depends on validation evidence and the cost of mistakes, not on visual symmetry.

02 / The principle

Pre-pruning limits growth through depth, minimum leaf size or minimum improvement. Post-pruning grows a tree and then compares simpler alternatives, such as replacing a subtree with a majority-class leaf, raising a subtree or pruning extracted rules.

Reduced-error pruning accepts changes that do not harm validation performance, subject to a chosen tie policy. Numeric splits usually test thresholds between distinct sorted values; evaluate their resulting weighted impurities. Information gain favors many-valued attributes, including identifiers.

Gain ratio divides by the entropy of the branch distribution to mitigate that bias, but very small denominators create another problem, so practical selection uses safeguards. Acquisition costs may also influence which tests are worthwhile. None of these devices guarantees the best tree, and the final test set must remain outside pruning decisions.

Post-pruning

03 / The formula, unpacked

Candidate threshold between a < b: θ = (a+b)/2

Perceptrons and linear decision boundaries

01 / The story

An automated gate awards points for several badge features, adds a baseline adjustment, and opens when the total reaches a threshold. Each feature’s weight determines how strongly it pushes the decision. When a known valid badge is rejected, a perceptron update nudges the scoring rule toward that badge; when an invalid badge is accepted, it nudges the other way.

Geometrically, this rotates or shifts a separating boundary. A single boundary cannot isolate every possible pattern: accepting two opposite corners of a square while rejecting the other two demands more than one straight dividing line.

02 / The principle

An artificial neuron computes a weighted input sum plus a bias, then applies an activation function. A perceptron uses a hard threshold and therefore forms a linear decision boundary. With binary targets 0 and 1, its error is target minus prediction; each mistaken example changes weights in proportion to its input and updates the bias.

An epoch is one pass through the training data. For a finite linearly separable dataset, standard perceptron learning converges after finitely many mistakes under its usual update conditions. Nonseparable data need a stopping budget or another objective.

The algorithm finds a separator, not necessarily the largest-margin separator. A multi-neuron hidden layer can combine linear tests to represent nonlinear patterns such as XOR, but the original single-perceptron update does not directly solve multilayer credit assignment.

Words to know

Dot product
Multiply matching entries, then add all products.
Bias
An adjustable constant added to the weighted input sum.
Linearly separable
One straight boundary can place all labels on their required sides.

03 / The formula, unpacked

z = w·x + b; a = 1 if z ≥ 0, otherwise 0
e = t − a
w ← w + ηex; b ← b + ηe
Boundary: w·x + b = 0

x is the input vector, w a matching weight vector, b the bias, z the pre-activation and a the binary output. The target t uses the same 0/1 convention. Eta, written η, is a positive learning rate.

The dot denotes a dot product. Weight updates must use the prediction made before the update. The normal vector w is perpendicular to the decision boundary, while b moves that boundary without changing its orientation.

04 / A first worked example

This example is now correct, but previously correct examples may have changed sides. Check the full training set before claiming an epoch has achieved separation. The update changed both orientation and offset of the boundary. Keeping the bias fixed would describe a different algorithm with a different sequence of future classifications.

    e=0, so this perceptron rule changes neither weights nor bias.

  2. Must learning find the widest margin?

    No, ordinary perceptron only seeks a separator.

  3. What does a score of zero predict here?

    Class 1 because the threshold is z≥0.

Multilayer networks and backpropagation

01 / The story

Imagine a workshop with several processing stations. The final product is wrong, but blaming only the last station misses how earlier stations shaped its input. Backpropagation traces how a small change at each station would influence the final error. Each station receives downstream sensitivity and multiplies it by its own local sensitivity.

This is a chain-rule calculation, not an instruction to send the original target unchanged to every hidden unit. The forward pass saves intermediate values; the backward pass reuses them. All gradients describe the same current workshop configuration before the optimizer changes any of its settings.

02 / The principle

A multilayer perceptron composes affine transformations with nonlinear activations. Without nonlinearities, stacked affine layers collapse to one affine map. Categorical inputs often use one-hot encodings or learned embeddings; output choices depend on the task, with one sigmoid common for binary classification and softmax common for exclusive multiclass classification.

Backpropagation efficiently differentiates a chosen loss through the computation graph. For sigmoid units and half squared error, output sensitivities combine prediction error with the sigmoid derivative; hidden sensitivities combine downstream sensitivities through outgoing weights.

Compute all gradients using the forward-pass parameter values, then update. A universal approximation theorem concerns the existence of sufficiently large networks under stated function and domain conditions; it does not guarantee that a particular architecture or training run finds suitable parameters.

Words to know

Derivative
The local rate at which one quantity changes when another changes slightly.
Chain rule
Multiply local rates along a dependency path, adding contributions from multiple paths.
Gradient
A list of loss derivatives, one for each adjustable parameter.

03 / The formula, unpacked

σ(z) = 1/(1+exp(−z)); σ′(z) = σ(z)(1−σ(z))
L = ½Σᵢ(aᵢ−tᵢ)²
δᵢ = (aᵢ−tᵢ)aᵢ(1−aᵢ) at output
δⱼ = aⱼ(1−aⱼ)Σᵢ wᵢⱼδᵢ at hidden unit
∂L/∂wᵢⱼ = δᵢaⱼ; w ← w − η∇L

a denotes a unit’s activation and t its target. Delta, δ, is the derivative of loss with respect to a unit’s pre-activation. The weight wᵢⱼ connects source j to destination i. A hidden unit has no direct target, so its sensitivity sums downstream contributions.

The gradient symbol ∇ collects partial derivatives of the loss. These delta expressions specifically assume sigmoid activation and half squared error; another activation or loss changes the local derivative.

    Usually no; it receives sensitivity through downstream connections.

  3. Why add nonlinear activations?

    Otherwise stacked affine layers still describe one affine transformation.

Optimization, initialization and regularization

01 / The story

A hiker descending a valley chooses a direction from the local slope and a step length from a training policy. Tiny steps take a long time; large steps can jump across the valley and climb the opposite side. Momentum gives the hiker some persistence, smoothing alternating directions but sometimes carrying them too far.

Training and validation losses act like two maps: one shows fit to the familiar terrain, while the other checks whether the route helps on unseen terrain. Neither a flat slope nor a low training loss proves the hiker has reached the best destination.

02 / The principle

Gradient descent updates parameters opposite the loss gradient. Full-batch updates average all training examples; stochastic updates use one example; minibatches trade gradient noise against efficient computation. Learning rate controls step size and can determine whether training converges or diverges.

Momentum accumulates past update directions, while adaptive methods rescale updates using gradient history. Random, appropriately scaled initialization breaks symmetry between hidden units. Input scaling helps optimization, but must be learned without leakage. Deep sigmoid networks can suffer vanishing gradients because many small derivatives multiply.

Monitor validation loss, retain the best checkpoint and stop after a defined patience period. Weight decay and dropout constrain fitting, though none guarantees generalization. A stationary point can be a minimum, maximum or saddle, and neural losses can have multiple equivalent minima.

Autoencoders and learned representations

01 / The story

An archivist compresses sketches into a short description and asks another archivist to reconstruct them. If the description can simply copy every pixel, little structure must be learned. A tight description forces it to preserve recurring features, such as shape and stroke direction.

An autoencoder creates this exercise from the data itself, using the input as the reconstruction target. However, a compact description is not encryption: anyone with enough access or an alternative decoder might recover information. Reconstruction quality also reflects what the model has learned to retain, rather than a universal measure of what humans consider important.

02 / The principle

An autoencoder combines an encoder that maps an input to a latent representation with a decoder that reconstructs it. Training minimizes a reconstruction loss without external class labels. An undercomplete bottleneck limits representation dimension; sparse penalties and denoising objectives impose other constraints even when a hidden layer is wide.

A denoising autoencoder receives a corrupted input but targets the clean input. Stacked autoencoders can pretrain successive representations, followed by a supervised head and optional end-to-end fine-tuning. Such pretraining is one historical and practical option, not a required step for every deep network.

Latent features can support compression, visualization or downstream prediction. High reconstruction error may suggest novelty, but anomaly detection needs separate validation because unfamiliar inputs can sometimes reconstruct well and harmless changes can reconstruct poorly.

Convolutions, pooling and shared features

01 / The story

A quality inspector slides a small stencil across a cloth. The same stencil checks each area for a local pattern. It may find an edge in one place and a corner in another. Reusing the stencil is the key idea behind a convolutional filter.

02 / The principle

Convolutional networks use local receptive fields and shared filter weights to exploit spatial structure. A filter spans all input channels and produces one output feature map; multiple filters learn multiple maps. Deep-learning libraries usually implement cross-correlation without flipping the filter, despite calling it convolution.

Stride controls sampling positions, padding controls border treatment and dilation spreads filter entries. Nonlinear activation follows filtering; pooling downsamples through a local maximum or average. Weight sharing greatly reduces parameters relative to dense connections and yields translation equivariance under suitable boundary assumptions.

Pooling may provide limited shift tolerance, not guaranteed global invariance. Multiple layers enlarge the effective receptive field. Local contrast normalization is an optional historical component; modern architectures vary. Train these operations through backpropagation and validate robustness rather than inferring it from architecture alone.

Words to know

Channel
One value plane, such as red intensity or a learned feature map.
Stride
The number of positions the filter moves between evaluations.
Weight sharing
Reuse the same filter numbers at many spatial positions.

03 / The formula, unpacked

yᵢⱼₖ = bₖ + Σᵤᵥ꜀ Wᵤᵥ꜀ₖ xᵢ₊ᵤ,ⱼ₊ᵥ,꜀

Parameters = Kheight·Kwidth·Cin·Cout + Cout

04 / A first worked example

Apply a 2×2 filter [[1,0],[0,−1]] to the 3×3 input [[1,2,3],[4,5,6],[7,8,9]], with stride one, no padding and zero bias. The four outputs are 1−5=−4, 2−6=−4, 4−8=−4 and 5−9=−4, forming a 2×2 map. ReLU would set all four to zero; max pooling before ReLU would produce −4.

For a separate RGB layer using eight 3×3 filters, parameter count is 3×3×3×8+8=224, regardless of whether the input image is 32×32 or 64×64. Output dimensions and computation cost still depend on image size. Weight sharing saves parameters without eliminating the work of visiting image positions.

Let us work through it

  1. Does a filter see all input channels?

    In an ordinary dense convolution, yes; it sums their contributions into one output channel.

  2. Does doubling image width double parameters?

    No; the same filter is reused, though computation increases.

  3. What does ReLU do to −3?

    It outputs max(0,−3)=0.

Margins, soft constraints and kernels

01 / The story

A surveyor places a fence between two kinds of plants. Many fences separate the observed plants, but a fence with a wide clear corridor on both sides is less sensitive to small movements. A hard-margin support vector machine seeks that widest corridor.

One mislabeled plant can make strict separation impossible, so a soft margin allows some violations at a cost. A kernel changes the geometry in which the fence is straight, making a curved boundary possible in the original garden. This is a mathematical preference for a margin, not a promise that every unseen plant will be classified correctly.

02 / The principle

A linear SVM predicts from the sign of a weighted feature sum. Under canonical scaling, hard-margin constraints place all training examples at signed functional margin at least one and minimize half the squared weight norm. Soft-margin training adds nonnegative slack variables, penalized by C, to allow points inside the margin or misclassified.

Larger C penalizes violations more strongly relative to the norm term. In the dual, predictions depend on inner products with training examples whose multipliers are nonzero. A kernel supplies an inner product in a feature space without explicitly constructing its coordinates.

Valid kernels require positive-semidefinite Gram matrices for finite point sets; arbitrary similarity functions need not qualify. Scaling, C and kernel parameters require validation. Soft-margin support vectors can lie inside the margin, so they are not always simply the nearest correctly classified points.

Words to know

Margin
The separation measured around a decision boundary under a stated scaling.
Slack
The nonnegative shortfall from the required signed margin of 1.
Kernel
A function acting as an inner product in a feature representation.

03 / The formula, unpacked

minimize ½||w||² + CΣᵢ ξᵢ
subject to yᵢ(w·xᵢ+b) ≥ 1−ξᵢ, ξᵢ ≥ 0
Margin width = 2/||w||
f(x) = Σᵢ αᵢyᵢK(xᵢ,x)+b

xᵢ is a training vector and yᵢ is either −1 or +1. The weight vector w and bias b define the separator; ξᵢ measures a margin shortfall. C is a positive penalty parameter. Alpha, αᵢ, is a learned dual multiplier.

K computes a feature-space inner product, and the sign of f predicts the class. The margin-width expression uses canonical scaling and a nonzero w; it is not the distance from every training point to the boundary.

04 / A first worked example

In one dimension, negative examples lie at −3 and −1 and positive examples at 1 and 4. The hard-margin solution is w=1 and b=0: the closest examples −1 and 1 satisfy y(wx+b)=1. The two margin boundaries are x=−1 and x=1, so their separation is 2/|w|=2.

For a soft-margin illustration, if a positive example at x=0.2 is evaluated under this same boundary, its functional margin is 0.2, requiring slack at least 0.8. For a degree-two kernel K(u,v)=(uv+1)², inputs u=2 and v=3 give K=49 without explicitly constructing the mapped vectors.

Let us work through it

  1. What labels does this SVM formula use?

    −1 and+1, unlike the earlier 0/1 perceptron convention.

  2. What does increasing C favor?

    Fewer margin violations relative to keeping the weight norm small.

  3. Is every similarity a valid kernel?

    No; the required inner-product structure must hold.

Bagging, boosting and random forests

01 / The story

Three weather spotters may outperform one if they make different mistakes. If they all read the same broken thermometer, their unanimous vote adds little. Ensembles depend on this distinction between multiple models and useful diversity. Bagging gives learners different resampled histories.

A random forest also limits which features each split may inspect. Boosting instead builds a sequence in which later learners focus on what the current collection handles poorly. The committee analogy is useful, but models are not independent witnesses: shared training data, shared features and shared biases can make their errors strongly correlated.

02 / The principle

Bagging trains base learners on bootstrap samples drawn with replacement and aggregates votes or numeric predictions. It often reduces variance for unstable learners such as deep trees. A random forest adds random feature subsets at individual splits, aiming to decorrelate trees while keeping them useful.

AdaBoost maintains a distribution over training examples, fits a weak classifier and increases relative emphasis on mistakes before the next round. Its final vote weights learners using their weighted error, rather than raw unweighted accuracy alone.

Gradient boosting instead fits successive learners to a loss-related correction such as a negative gradient. Diversity and adequate accuracy can help ensembles, but neither independence nor improvement is guaranteed in practice. Extra models cost training time, storage and prediction work; noisy labels can attract harmful boosting attention.

Words to know

Bootstrap
Sample training records with replacement, allowing repeats.
Correlated errors
Models tend to fail on the same examples.
Weighted vote
Combine predictions with specified unequal vote strengths.

Epsilon is weighted error and alpha the learner’s vote weight. The shown AdaBoost formula assumes 0<εₜ<0.5; zero error and non-improving learners require explicit special handling. Renormalize the next distribution to sum to one.

After exponential reweighting and normalization, the mistaken example has weight 1/2, while each correct example has weight 1/6. The next learner is trained against that changed distribution. This arithmetic explains the mechanism without assuming its future test error will decrease.

  1. Does more models guarantee improvement?

    No, identical or poor errors may persist.

  2. What error does AdaBoost use?

    The current example-weighted error, not necessarily ordinary error rate.

  3. Why normalize example weights?

    They must form a distribution summing to 1 for the stated weighted-error formula.

Joint distributions, conditioning and Bayes

01 / The story

A warehouse alarm sounds more often during equipment faults, but it also sounds occasionally during routine vibration. Hearing it changes belief about a fault; it does not prove a fault occurred. A useful calculation keeps a ledger of every combination: fault and alarm, fault without alarm, no fault with alarm, and neither.

Summing rows gives overall frequencies; restricting attention to alarm rows and renormalizing answers the question after an alarm. This bookkeeping explains why a reliable alarm can still generate many false alerts when faults are rare. Conditional reasoning depends on both the evidence and the prior situation.

02 / The principle

A joint probability distribution assigns nonnegative mass summing to one across complete assignments of discrete variables. Marginalization sums over variables that are not part of a query. Conditioning restricts to compatible assignments and divides by the probability of the evidence, which must be positive.

The product rule yields the chain rule, decomposing a joint into conditional factors. Bayes’ rule reverses conditioning by combining likelihood with prior probability. Independence means a joint factorizes without conditioning; conditional independence means it factorizes after a specified variable is known.

Neither type generally implies the other. Normalize unnormalized class scores only after summing all relevant hidden possibilities. Probability is a formal model of uncertainty; a frequency estimate is one way to obtain it, not the only interpretation.

Words to know

Joint probability
Probability that specified events occur together.
Marginalization
Sum over unwanted alternatives to obtain a smaller query.
Conditional probability
Probability after restricting to cases compatible with observed evidence.

03 / The formula, unpacked

P(A|B) = P(A,B)/P(B), P(B)>0
P(A|B) = P(B|A)P(A)/P(B)
P(A) = Σᵦ P(A,b)
A ⟂ B | C: P(A,B|C) = P(A|C)P(B|C)

A and B denote events or variable assignments; the comma means both occur and the vertical bar means given. The sum ranges over a complete set of mutually exclusive values b. C is the variable or evidence that makes A and B conditionally independent in the last expression.

The independence symbol applies to the stated conditioning set only. All formulas use a consistent probability model and require conditioning events to have positive probability.

04 / A first worked example

Suppose a machine fault occurs with probability 0.02. The alarm sounds with probability 0.9 during a fault and 0.05 without one. The joint fault-and-alarm mass is 0.02×0.9=0.018. The no-fault-and-alarm mass is 0.98×0.05=0.049. Thus P(alarm)=0.067 and P(fault|alarm)=0.018/0.067≈0.2687.

In a hypothetical 10,000 operating periods, expected counts are 180 true alarms and 490 false alarms. The alarm raises fault probability substantially above 2%, yet most alarm periods still have no fault. These are illustrative model probabilities, not an empirical reliability claim. The two joint alarm cases are mutually exclusive and exhaust all ways the alarm can sound.

Let us work through it

  1. Why divide by evidence probability?

    It rescales the retained cases so their probabilities sum to 1.

  2. Can we condition on zero-probability evidence using this formula?

    No; the denominator is zero.

  3. Does a strong likelihood remove the prior?

    No; posterior reasoning still multiplies by the prior.

Bayesian networks and inference

01 / The story

A building dashboard connects rain, a sprinkler and a wet courtyard. Drawing dependencies lets the engineer store local conditional tables instead of an enormous ledger of all combinations. The arrows tell the probability model how to factorize, but their direction alone does not certify causation.

To answer whether it rained after observing wet ground, the engineer must consider the unobserved sprinkler states, not silently choose the most convenient one. Variable elimination reuses intermediate calculations, much as an accountant totals repeated subtables once. Sampling offers another route, approximating answers from many simulated assignments when exact calculation becomes expensive.

02 / The principle

A Bayesian network is a directed acyclic graph with one conditional probability table per variable given its parents. Its local Markov property makes each variable independent of its non-descendants conditional on its parents, producing a product factorization of the joint. Absence of a direct edge does not mean unconditional independence.

A node’s Markov blanket comprises its parents, children and the other parents of its children. Exact enumeration sums over hidden assignments; variable elimination multiplies relevant factors and sums out one variable at a time, with complexity strongly affected by elimination order and intermediate factor size.

Approximate methods include prior sampling, rejection sampling, likelihood weighting and Gibbs sampling. Rare evidence harms rejection efficiency; weighted or dependent samples introduce their own variance and convergence issues. Network structure and tables can come from data, expertise or both.

Words to know

Directed acyclic graph
Arrows connect nodes without a directed path returning to its start.
Conditional table
A distribution for a node for every allowed parent assignment.
Variable elimination
Multiply relevant factors and sum out hidden variables in stages.

03 / The formula, unpacked

P(x₁,…,xₙ) = Πᵢ P(xᵢ | parents(Xᵢ))
P(Q|e) = α Σhidden Πᵢ P(xᵢ | parents(Xᵢ))
Binary-node parameter count = Σᵢ 2ᵏⁱ

Q is the queried variable, e the observed evidence and alpha the normalization constant making the resulting distribution sum to one. The sum covers every hidden-variable assignment consistent with the evidence. kᵢ is the number of binary parents of binary node i; each parent configuration needs one independent probability for that node.

The parameter-count expression assumes all variables are binary. Compact representation does not guarantee cheap inference, because products of factors can become large.

04 / A first worked example

Let R denote rain with P(R)=0.2 and S a sprinkler with P(S)=0.3, independent roots. Wet-ground probabilities for (R,S)=(1,1),(1,0),(0,1),(0,0) are 0.99, 0.8, 0.7 and 0.05. Sum over S to obtain P(wet|R)=0.3×0.99+0.7×0.8=0.857, and P(wet|not R)=0.3×0.7+0.7×0.05=0.245. The unnormalized rain scores are 0.1714 and 0.196, so P(R|wet)=0.1714/0.3674≈0.4665.

The network stores 1+1+4=6 independent parameters, compared with 2³−1=7 for an unrestricted joint distribution. The summation is essential because sprinkler status was not observed. Choosing just one sprinkler setting would answer a different conditional query. Observing wet ground makes the initially independent causes statistically coupled in general.

Let us work through it

  1. Does no edge mean independence?

    No; indirect paths and conditioning can create dependence.

  2. How many parameters for a binary root?

    One; the other probability is one minus it.

  3. Why sum hidden values?

    All unobserved alternatives can contribute to the observed evidence.

For independent causes A→C←B, observing C can make evidence for A reduce the need for B to explain C. The dependence depends on the tables.

Parameter savings use normalization

For a binary node, each parent row has two probabilities but only one independent choice, because the second is 1 minus the first.

Watch out. An arrow is a dependency in a probability factorization. Interpreting it as an intervention-ready causal relationship requires additional assumptions and evidence.
Check your understanding: Why can elimination order change runtime without changing the exact answer?

The distributive law permits different summation orders, but the orders create intermediate factors of different sizes. Correct exact arithmetic gives the same marginal while memory and multiplication costs differ.

K-means, representatives and vector quantization

01 / The story

A ceramics studio wants a small set of standard glaze colors to approximate thousands of observed samples. It assigns each sample to its nearest current standard, then moves each standard to the mean of its assigned samples. Repeating this can reduce approximation error. A standard need not equal an existing sample, just as a centroid need not be a data point.

If the studio must choose only available physical samples, a medoid is a different representative. The chosen distance also matters: numerical closeness in a color encoding need not perfectly match human perception, so a tidy mathematical cluster can still be unhelpful in practice.

02 / The principle

Lloyd’s k-means alternates assignment to the nearest centroid with updating each nonempty centroid to its cluster mean. Under squared Euclidean loss, each step cannot increase the objective, and standard finite-data implementations terminate at a locally stable partition subject to tie conventions.

Global optimality is not guaranteed; multiple starts and k-means++ initialization can help. Arithmetic means specifically minimize squared Euclidean distances: changing the distance generally requires changing the representative update. Scale features appropriately, handle empty clusters explicitly and examine sensitivity to outliers.

The number of clusters is a modeling choice, not necessarily a discovered natural truth. Centroids can form a codebook for vector quantization, replacing each input block with a centroid index. Storage savings require counting both indices and the codebook, and reconstruction becomes lossy.

Words to know

Centroid
The coordinate-by-coordinate mean of a cluster.
SSE
Sum of squared distances from points to their assigned representatives.
Codebook
The stored collection of representatives indexed during reconstruction.

03 / The formula, unpacked

J = Σᵣ Σx∈Cᵣ ||x−μᵣ||²
μᵣ = (1/|Cᵣ|) Σx∈Cᵣ x
Naive iteration cost: O(nkd)
Fixed-length index bits per item = ceil(log₂k)

Cᵣ is cluster r and μᵣ its centroid, the coordinatewise mean of its members. J is within-cluster sum of squared errors, with smaller values preferred for a fixed k and dataset. Here n is number of points, k number of clusters and d feature dimension.

The centroid formula requires a nonempty cluster. A fixed-length code for k representatives needs the stated number of bits; total compressed size also includes representative values and any format overhead.

04 / A first worked example

For points 0, 2, 8 and 10, choose k=2 with initial centroids 0 and 8. Nearest-centroid assignment forms {0,2} and {8,10}; the updated means are 1 and 9. Assignments then stay unchanged. The objective is (0−1)²+(2−1)²+(8−9)²+(10−9)²=4. As a separate compression calculation, 100 four-byte blocks originally occupy 400 bytes.

A four-entry codebook occupies 16 bytes, and 100 two-bit indices occupy 25 bytes, totaling 41 bytes before headers. The result saves storage by restricting reconstruction to four representative blocks, so exact original recovery is generally impossible.

Let us work through it

  1. Must a centroid be an observed point?

    No; a mean may lie between points.

  2. Does every run find the global optimum?

    No, initialization and ties can lead to different local results.

  3. What is needed for an empty cluster?

    An explicit policy, since its mean has denominator zero.

Encode 64 blocks, each originally 4 bytes, using 8 representative blocks of 4 bytes each. Use fixed-length indices and ignore headers.

Trace two Lloyd steps

points = [1, 3, 9, 11]
centers = [1, 9]
for step in range(2):
    groups = [[], []]
    for point in points:
        distances = [abs(point - centers[0]), abs(point - centers[1])]
        group_id = 0 if distances[0] <= distances[1] else 1
        groups[group_id].append(point)
    centers = [sum(group) / len(group) for group in groups]
    error = 0
    for group_id, group in enumerate(groups):
        for point in group:
            error += (point - centers[group_id]) ** 2
    print(f"Step {step + 1}: centers={centers}, SSE={error:.1f}")
assert centers == [2.0, 10.0]

Guoliang's further thinking

The mean matches squared loss

For absolute distance in one dimension, a median minimizes the total instead. Do not change the distance while blindly keeping the mean update.

Report codebook overhead

For a very small dataset, storing representatives may cost more than the saved index bits. Count all parts before claiming compression.

Watch out. A decreasing k-means objective does not prove that the clusters correspond to meaningful real-world categories. Interpretation and stability need separate investigation.
Check your understanding: Why does comparing raw SSE across different k tend to favor larger k?

Adding centroids cannot worsen the best achievable SSE and can eventually give one centroid per point. Choose k using additional criteria, stability and the intended use, not SSE alone.

Hierarchies, thresholds and cluster quality

01 / The story

A mapmaker groups villages first into neighboring pairs, then districts, then regions. A hierarchy preserves several levels of resolution, so the user chooses where to cut the tree. But “nearby groups” has several meanings. One short bridge can connect two long chains under single linkage; complete linkage instead checks their most distant cross-group pair.

A streaming grouping rule has another choice: a new village may join the cluster of its nearest already seen village if it lies within a threshold. That rule can depend on arrival order. Different algorithms answer different grouping questions, even when they use the same distance table.

02 / The principle

Agglomerative clustering starts with singleton clusters and repeatedly merges the closest pair under a linkage rule; divisive methods start together and split. A dendrogram records merge structure and heights, while a cut supplies an actual partition. Single linkage uses the smallest cross-cluster distance and can chain through bridge points.

Complete linkage uses the largest distance; average linkage averages all cross pairs. Centroid and medoid distances provide other definitions. An online nearest-neighbor threshold method assigns a point using previously seen neighbors or creates a new cluster; specify whether clusters can later merge and how ties are handled.

Evaluate cohesion and separation with measures such as silhouette or Davies–Bouldin, but internal scores favor particular geometries. Classical dense implementations store O(n²) distances; runtime depends on linkage and data structures rather than one universal bound.

Words to know

Linkage
A rule converting point distances into a distance between clusters.
Dendrogram
A tree recording cluster merges and their heights.
Silhouette
A comparison of within-cluster distance with distance to the nearest other cluster.

03 / The formula, unpacked

dsingle(A,B) = min{d(a,b): a∈A,b∈B}
dcomplete(A,B) = max{d(a,b): a∈A,b∈B}
s(i) = (b(i)−a(i))/max(a(i),b(i))
DB = (1/k)Σᵣ maxₛ≠ᵣ [(Sᵣ+Sₛ)/Mᵣₛ]

A and B are clusters. For silhouette, a(i) is point i’s mean distance to other members of its cluster and b(i) the smallest mean distance to another cluster; larger silhouette is usually better, with conventions for singletons.

In Davies–Bouldin, Sᵣ is within-cluster scatter and Mᵣₛ the distance between representatives; smaller DB is usually better. Specify scatter, representative and distance consistently, and handle coincident representatives because a zero denominator can make the score undefined.

04 / A first worked example

Consider one-dimensional clusters A={0,2} and B={5,9}. Their cross distances are 5, 9, 3 and 7. Single linkage gives 3, complete linkage 9 and average linkage 24/4=6. A threshold of 4 therefore permits their merge under single linkage but not complete linkage.

For point 2 in partition {0,2},{5,9}, within-cluster distance a=2 and mean distance to the other cluster b=(3+7)/2=5, so silhouette is (5−2)/5=0.6. With centroids 1 and 7, average absolute scatters are 1 and 2; for these two clusters DB=(1+2)/6=0.5. Every quantity uses the same one-dimensional Euclidean distance.

Let us work through it

  1. Which linkage uses the farthest pair?

    Complete linkage.

  2. What does negative silhouette suggest?

    The point is on average closer to another cluster than to its own.

  3. Does a hierarchy specify one unique partition?

    No; choose a cut height or cluster count.

Single linkage can connect by chains

With points 0,2,4 and threshold 2, successive short links join all three although the endpoint distance is 4.

Internal quality is conditional on the ruler

Changing feature scale changes distances and can reverse score comparisons. Choose a meaningful representation before optimizing a score.

Check your understanding: Why can a single outlying bridge point dramatically change single-link clustering?
