# Guoliang Python examples

Use Python 3.12 or newer. Most examples use only the standard library. Examples that import NumPy need `python -m pip install numpy`. No data downloads or trained model weights are needed.

Run a file with `python path/to/example.py`. Its topic page explains the input, expected output and limitations. These small examples explain mechanisms. They are not complete production systems.
