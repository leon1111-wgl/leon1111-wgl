## 字符串、语言与规格

### 01 / 从一个故事开始

想象门卫检查标签。选择扫描器前，先规定允许哪些标签，例如由 A、B 组成且以 B 结尾的序列。规格独立于检查设备描述规则。设备可以使用指示灯、程序或查表；不同实现仍能作出相同判断。类比也有限制：真实扫描器会机械故障，数学机器却严格遵守规则。我们研究规则是否描述了预期标签集合。

### 02 / 理解原理

字母表是有限符号集合，字符串是由这些符号组成的有限序列。空串 ε 长度为零。语言是所有有限串的任意子集，不一定是人类语言，也不一定能用实用方法描述。判定问题可表示成语言成员资格：答案为是的输入属于语言。

规格说明输入范围和要求答案，算法提供步骤。实现只有对每个允许输入都符合规格才正确。一般计算还需说明是否要求终止：只要结束就答对，比总能给出答案弱。

### 03 / 逐项读懂公式

```text
Σ* = ⋃ₖ≥₀ Σᵏ;  L ⊆ Σ*;  |ε| = 0
```

Σ 是字母表，Σᵏ 是长度 k 的所有串。星号包含全部有限长度，包括零，所以 ε 总属于 Σ*。L 是其中选出的语言。竖线在此表示串长，不是集合大小。这些定义说明允许输入及肯定答案，并不保证每种 L 都有可判定成员资格的机器。

### 04 / 先看一个完整例子

设 Σ={A,B}，L 为以 B 结尾的串。B、AB、BAB 属于它，ε、A、BAA 不属于。正确过程先拒绝空输入，再检查最后符号是否为 B。若表示方式允许，可以直接查看末字符；也可以从左到右扫描并记住最近字符，两者符合相同规格。只检查有没有 B 的过程在 BAA 上失败，这是具体反例。

### 先认识这些词

- **字母表:** 允许符号构成的有限集合。

- **字符串:** 有限的有序符号序列。

- **规格:** 说明允许输入与所需输出的规则。

### 一步步想清楚

**为什么将规则与扫描器分开？**

不同过程可符合相同规则，需要用统一目标判断。

**{x,y} 上有几个长度二的串？**

两个位置各两种选择，2×2=4：xx、xy、yx、yy。

**{ε} 是空集合吗？**

不是。它包含一个长度零的串。

### 统计有限部分

在 Σ={x,y} 上列出长度不超过二且以 x 结尾的全部串。候选输入包括 ε，但必须严格检查结尾规则。

**先选择方法**

按长度划分，避免漏计与重复。

1. 长度零只有 ε，没有末尾 x，因此拒绝。

2. 长度一有 x、y，只有 x 以 x 结尾。

3. 长度二有 xx、xy、yx、yy，检查第二位保留 xx、yx。

**解释最终答案**

所选有限部分为 {x,xx,yx}，共三个串。

**检验推理**

正长度 n 时，固定末尾 x 后有 2^(n−1) 种。n=1、2 得 1+2=3。

### 修复错误检查

规则为“二进制输入恰含两个 1”。候选测试在长度为二时接受。检查 10、101，并给出会停机的正确过程。

**先选择方法**

将候选条件与真实计数比较，再替换条件。

1. 10 长度二，候选接受；但只有一个 1，要求答案为否。

2. 101 长度三，候选拒绝；但有两个 1，要求答案为是。

3. 扫描有限输入，遇 1 加一。读完后仅在计数等于二时接受。

**解释最终答案**

仅看长度既会误接受也会误拒绝。计数过程在读完输入后停机。

**检验推理**

空串计数零被拒绝，11 计数二被接受。

### Leon 的进一步思考

**先检查输入合法性**

字母表为 {x,y} 时，xz 不在输入范围。实现应说明报输入错误还是答否，不能悄悄改变数学语言。

**反例有决定作用**

一次不符就足以推翻对所有输入正确的主张。一千次成功测试也不能覆盖无限输入。

**注意这个边界:** 不要混淆 ε 与 ∅。ε 是一个串，∅ 没有任何串；{ε} 有一个成员。

## 正则表达式：语言的代数

### 01 / 从一个故事开始

玩具制作有三种指令：选一种设计、将两块并排、把一块重复有限次。正则表达式也像字符串配方。选择给出替代项，连接拼起片段，重复允许数量变化。配方描述所有成品，不规定制作先后。重复可以为零次，容易遗漏。数学配方也不包含某些程序库的强大扩展，因此讨论正则语言时须明确基本运算。

### 02 / 理解原理

正则表达式从符号、空语言、空串、并、连接和 Kleene 星递归构造。语义给每个表达式对应语言。并允许来自任一边的串；连接要求串可拆成左语言的片段与右语言的片段；星允许零个或多个成员连接。

括号决定分组。通常星优先于连接，连接优先于并。本课匹配指整个字符串的成员资格；子串搜索是另一任务，除非表达式允许任意前后文。表达式是规格，不是对回溯实现的承诺。

### 03 / 逐项读懂公式

```text
L(R|S) = L(R) ∪ L(S)
L(RS) = {uv : u ∈ L(R), v ∈ L(S)}
L(R*) = ⋃ₖ≥₀ L(R)ᵏ
```

R、S 是表达式，L(R) 是其语言。表达式内竖线表示选择。uv 是串连接，上标 k 表示连接 k 块，不是对字符串求数字幂。L(R)⁰={ε}。先求小表达式，再按对应运算组合其语言。

### 04 / 先看一个完整例子

R=(ab|c)*d 的重复块是 ab 或 c，末尾恰有一个 d。选 ab、c、ab 得 abcabd，匹配。零块得 d，也匹配。acd 不匹配，因为末尾 d 前的 ac 无法分成 ab 或 c：a 后缺少 b。dcc 不匹配，因为 d 必须在末尾。写出分块就能解释成员资格。

### 先认识这些词

- **并:** 接受任一选择的字符串。

- **连接:** 把一个串接在另一个后面。

- **Kleene 星:** 将语言成员连接零次或多次。

### 一步步想清楚

**零次重复为何重要？**

即使重复块非空，也会加入 ε。

**xyx 如何按 (xy|x)* 分块？**

选择 xy 后接 x，因此属于该语言。

**前缀匹配能证明整体匹配吗？**

不能，剩余每个符号也必须由表达式匹配。

### 分解新模式

对 R=(xy|z)*x，判断 xyzzx、x、zxy 的成员资格，要求整个串匹配。

**先选择方法**

先分离必须的末尾 x，再拆重复前缀。

1. xyzzx 以 x 结尾，前缀 xyzz 可拆成 xy、z、z，均允许。

2. x 留下空前缀，星允许零个重复块。

3. zxy 以 y 结尾，无论前面怎样分块都不能提供末尾 x。

**解释最终答案**

xyzzx、x 匹配，zxy 不匹配。

**检验推理**

若删除模式末尾 x，语言会改变，ε 将匹配。

### 比较星的位置

在 {a,b} 上各找一串：属于 a*b* 不属于 (ab)*，以及相反。

**先选择方法**

比较块顺序：分组连续段与交替配对。

1. aab 是两个 a 后接一个 b，因此属于 a*b*。

2. 非空 (ab)* 交替 a、b 且长度为偶数。aab 长三，因此不属于。

3. abab 是两个 ab 块，但第一个 b 后又有 a，违反先全 a 后全 b 的结构。

**解释最终答案**

aab 见证第一方向差异，abab 见证反方向。两语言互不包含。

**检验推理**

两者都接受 ε，因此共享空串不能证明等价。

### Leon 的进一步思考

**表达式与实现**

表达式说明哪些串属于语言。回溯与同时状态模拟执行不同，却可以所有答案一致。

**星不等于加**

一次或多次可写 RR*。当 R 本身不能生成 ε 时，它与星的区别就是是否包含 ε。

**注意这个边界:** R* 总包含零次重复带来的 ε，即使 R 本身什么也不匹配。

## DFA 状态：概括已经读过的内容

### 01 / 从一个故事开始

门口计数器只需两盏灯报告进入人数奇偶，不必保留每次到达时间。每来一人切换灯，当前灯概括最终奇偶问题所需全部信息。确定有限自动机也如此：状态代表已读前缀的信息摘要。设计应先命名每个状态含义。若任务要求无限制精确计数，类比就到头了，因为固定灯数不能记住任意多种总数。

### 02 / 理解原理

DFA 有有限状态集、输入字母表、起点、接受状态集及完整转移函数。每次转移恰读一个符号，因此每个输入有唯一运行过程，读完全部输入后按最终状态判断接受。

围绕不变量设计状态：读完前缀后，当前状态保证什么？奇偶只需偶与奇；固定子串可记录最长有用后缀。定义必须包含每个状态与符号组合，包括拒绝汇点。先证初始不变量，再证每步保持，最后连接接受状态与规格。

### 03 / 逐项读懂公式

```text
D = (Q, Σ, δ, q₀, F)
δ : Q × Σ → Q
w ∈ L(D) ⇔ δ*(q₀,w) ∈ F
```

Q 是有限状态集，q₀ 是起点，F 是接受子集。δ 给出读一个符号的后继，δ* 扩展到整串：从 q₀ 连续应用 δ，且 δ*(q,ε)=q。这里 δ 的星表示扩展转移，不是语言重复。必须读完所有符号后检查接受。

### 04 / 先看一个完整例子

识别含奇数个 1 的二进制串。用 E、O 两状态，从 E 开始，只接受 O。读 0 不变，读 1 在 E、O 间切换。10110 的序列为 E,O,O,E,O,O，因此接受。ε 留在 E，因此拒绝。不变量为 E 表示已读前缀含偶数个 1，O 表示奇数。它能证明所有串，不只是例子。

### 先认识这些词

- **状态:** 已处理前缀的有限摘要。

- **不变量:** 每次转移后保持的陈述。

- **接受状态:** 输入结束于此时接受的状态。

### 一步步想清楚

**余数计数为何只需少量状态？**

问题不需要完整总数，只需要余数。

**模三余数二再读一个 1 会怎样？**

2+1=3 余零，转到零状态。

**接受前缀保证延长后也接受吗？**

不保证，额外符号可改变所概括性质。

### 跟踪余数机

状态 0、1、2 表示 1 的个数模三。从 0 开始，只接受 0；读 0 不变，读 1 加一模三。跟踪 110101。

**先选择方法**

每读一符号记录状态，并以累计个数核对不变量。

1. 初始计数零、状态 0。前两个 1 得计数 1、2，状态 1、2。

2. 下一 0 保持状态 2，下一 1 让计数到三，状态回 0。

3. 倒数第二个 0 保持状态 0，最后 1 让计数到四，结束于状态 1。

**解释最终答案**

完整轨迹 0,1,2,2,0,0,1。四不能被三整除，因此拒绝。

**检验推理**

直接数到四个 1，4 mod 3=1，与末状态一致。

### 设计末符号机器

在 {a,b} 上设计完整双状态 DFA，接受非空且以 b 结尾的串。

**先选择方法**

只记最近符号是否 b，把空前缀与拒绝状态归为一组。

1. 状态 N 表示空或末符号 a，B 表示末符号 b，从 N 开始。

2. 任一状态读 a 到 N，读 b 到 B，完整定义四种状态符号对。

3. 输入结束只接受 B。bab 的状态 N,B,N,B；ε 保持 N。

**解释最终答案**

该完整 DFA 接受 bab、拒绝 ε，符合末符号规则。

**检验推理**

在任何接受串后加 a 都转 N，因为所要求末字符已改变。

### Leon 的进一步思考

**证明状态含义**

余数机初始计数零；0 保持计数，1 同时增加计数与余数。这两种情形证明所有转移，不只一次运行。

**表示是设计选择**

若问末符号是否 1，奇偶状态不足：10 与 1 奇偶相同，末符号不同。摘要必须匹配实际问题。

**注意这个边界:** 不能一到接受状态就接受，后续符号可能离开它，必须消费全部输入。

## 非确定性与 ε 转移

### 01 / 从一个故事开始

想象一队人按给定颜色序列探索迷宫。到路口时，他们探索每条兼容分支。只要至少一人读完全部颜色并到达许可房间，任务就成功。失败分支不会取消成功分支。有些无色通道不消耗颜色即可经过，类似 ε 转移。这是推理模型，不是说电脑真有无限探索者；一个有限可达状态集合就能表示全部活跃分支。

### 02 / 理解原理

NFA 对一个状态与符号可有零个、一个或多个后继。ε 转移改变状态但不读符号。接受要求存在一条有限路径，消费全部输入并停在接受状态。其他分支卡住、结束于非接受状态或在 ε 边循环，都不取消成功路径。

NFA 易于组合：并选择分支，连接把一机器终点连到下一机器，星允许反复通过并提供空输入选项。这解释正则表达式转自动机。非确定性改变描述便利性与大小，却不增加正则语言的范围。

### 03 / 逐项读懂公式

```text
δ : Q × (Σ ∪ {ε}) → 𝒫(Q)
接受 w 当且仅当存在标签为 w 且终点在 F 的路径
```

𝒫(Q) 为 Q 的幂集，因此转移返回可能状态的集合。ε 不消费符号。路径标签把普通符号连接并忽略 ε。F 为接受状态集。“存在”是关键：一个成功运行就足够。缺失转移表示后继为空，不是等待后来的符号。

### 04 / 先看一个完整例子

识别以 ab 结尾的 {a,b} 串。起点在两字母上自环，也允许读 a 到第二状态；第二状态读 b 到没有出边的终点。baab 上，一分支猜第一个 a 是后缀起点，却被下一个 a 卡住；另一分支等到第二个 a，再读末尾 b 接受。aba 上，一分支在 ab 后到终点却不能消费末 a，所以全串拒绝。

### 先认识这些词

- **非确定性:** 一次转移可能有多个后继状态。

- **ε 转移:** 不消费输入符号的状态改变。

- **存在性接受:** 一条有限、完整、成功的运行就够。

### 一步步想清楚

**为何可以忽略失败分支？**

接受要求至少一次成功，不要求每条分支成功。

**ε 会消费空格字符吗？**

不会。它什么也不消费，实际空格会是普通字母表符号。

**提前到终态就够了吗？**

只有还能成功消费全部剩余符号才行。

### 字母前的免费分支

状态 s,p,f，起点 s，仅 f 接受。边为 s—ε→p、s—a→s、p—b→f，无其他边。判断 aab 与 ba。

**先选择方法**

每个符号前后维护包含所有免费 ε 移动的活跃状态。

1. 初始闭包 {s,p}。每个 a 沿 s 自环再用 ε 补回 p，读 aa 后仍为 {s,p}。

2. 末 b 将 p 移到 f，因此 aab 最后为 {f} 并接受。

3. 对 ba，b 先产生 {f}，f 没有 a 出边，读 a 后为 ∅，因此拒绝。

**解释最终答案**

接受 aab，拒绝 ba。在前缀后到终态并不够。

**检验推理**

成功串恰为 a*b：任意个 a 后接一个末 b。

### 为什么交换 NFA 终态失败

NFA 状态 s,f，字母表 {a}，起点 s，终态 {f}。仅有 s—a→s 与 s—a→f。交换终态为 {s} 前后比较输入 a。

**先选择方法**

列出两条完整运行；补语言应反转整体答案，而非各路径独立结果。

1. 原机器输入 a 有终点 s、f 两条运行。终点 f 的路径成功，因此接受。

2. 交换终态后两条运行仍存在，现在终点 s 的路径成功。

3. 两机器均接受 a。真正补机器应因原机器接受而拒绝 a。

**解释最终答案**

这个 NFA 交换终态不能得到补语言。

**检验推理**

确定化后 a 对应唯一子集 {s,f}，反转该子集接受性才能正确反转答案。

### Leon 的进一步思考

**同时模拟可能性**

每个前缀后记录可达状态集合。相同未读后缀下到同状态的两路径，未来选择相同，可合并。

**ε 环的闭包仍有限**

闭包搜索标记已访问状态。环 p→q→p 只各加入 p、q 一次，无需永远重复遍历。

**注意这个边界:** 不能直接交换 NFA 的接受与非接受状态来求补。存在性接受阻止该技巧，须先转完整 DFA。

<a id="subset-construction"></a>

## 把 NFA 转为 DFA

### 01 / 从一个故事开始

控制室用点亮房间的集合代替迷宫探索队。每读一种颜色，就熄灭旧灯，点亮队员现在可能所在的所有房间。给定前缀后，显示屏只有一种配置，虽然探索路径很多。配置就是 DFA 状态。ε 通道要求额外点亮所有免费可达房间。少量房间也有指数多个子集，所以显示配置可能很多，即使实际运行只出现少部分。

### 02 / 理解原理

子集构造为每个可达 NFA 状态集合建立一个 DFA 状态。先取起点 ε 闭包；读符号时从当前集合取所有该符号转移，再取 ε 闭包。集合与 NFA 接受集相交就接受。可达空子集应保留为拒绝汇点。

不变量为：每读完一个前缀，DFA 状态恰等于 NFA 在允许 ε 移动后所有可达状态。它证明两语言相同。m 个 NFA 状态最多有 2ᵐ 个子集，但通常只生成可达子集，不枚举所有子集。

### 03 / 逐项读懂公式

```text
S₀ = E({q₀})
Δ(S,a) = E(⋃q∈S δ(q,a))
S 接受 ⇔ S ∩ F ≠ ∅
```

E(S) 是含 S 本身及只沿 ε 边可达状态的闭包。Δ 属于新 DFA，δ 属于旧 NFA。并集收集每个可能普通 a 转移。F 是原接受集。最终条件表示至少一个活跃 NFA 状态接受，保留非确定性的存在含义。

### 04 / 先看一个完整例子

NFA 有 p,q,r，从 p 开始，p 可经 ε 到 q，p 在 a 上自环，q 经 b 到 r，仅 r 接受。初始 DFA 状态 {p,q}。

读 a 时 p 到 p、q 无后继，闭包补回 q，仍为 {p,q}。读 b 仅 q 到 r，产生 {r}。再读任一字母变 ∅。因此 aab 接受，aaba 拒绝，构造直接显出语言 a*b。

### 先认识这些词

- **子集状态:** 表示多个可能 NFA 状态的一个 DFA 状态。

- **ε 闭包:** 不消费符号可达的所有状态，包含原集合。

- **汇点:** 每条转移都回到自身的状态。

### 一步步想清楚

**为何普通转移后还取闭包？**

NFA 可在读下一符号前继续免费移动。

**四个状态有多少子集？**

每个状态选或不选，因此 2⁴=16。

**所有可能子集都必须建立吗？**

不必，可达子集构造省略所有输入都到不了的子集。

### 构造四个可达子集

NFA 状态 0,1,2，起点 0，终态 2。边为 0—ε→1、1—x→1、1—y→2。字母表 {x,y}，缺失移动为空。构造可达 DFA。

**先选择方法**

从闭包开始，不断探索新子集直到没有新项。

1. 起点 A={0,1}。读 x 到 B={1}，读 y 到 C={2}。

2. B 读 x 自环、读 y 到 C。C 无普通移动，两符号都到 D=∅。

3. D 在两符号上自环。仅 C 含终态 2，因此仅 C 接受。A,B,C,D 四个子集可达。

**解释最终答案**

DFA 有四个可达子集状态，识别 x*y。

**检验推理**

最多 2³=8 个子集。A、B 行为相同，之后可最小化合并为更小等价 DFA。

### 跨环求闭包

ε 边为 p→q、q→r、r→q；唯一 a 边为 r→f，只有 f 接受。从 p 开始，求初闭包和读 a 后子集。

**先选择方法**

用已访问集合，有限探索免费移动环。

1. 零次移动先含 p，再由 p 加 q、由 q 加 r。

2. r 的 ε 边回到已有 q，因此停止，闭包为 {p,q,r}。

3. 读 a 时 p、q 无后继，r 贡献 f。f 无 ε 出边，后继子集 {f}。

**解释最终答案**

初子集 {p,q,r}；输入 a 最终到接受子集 {f}。

**检验推理**

若漏初闭包，p 无 a 转移，错误模拟就会拒绝 a。

### Leon 的进一步思考

**闭包包含自身**

状态可以用零次 ε 移动留在原地。忘记零步选项会使有效起点消失。

**空子集有用途**

没有分支幸存后，后续符号无法复活分支。空子集在所有符号上自环，使 DFA 完整。

**注意这个边界:** 不能忘起点或每次符号后的 ε 闭包，否则可能丢失接受路径。

## 从自动机回到表达式

### 01 / 从一个故事开始

移除交通图上的小车站时，所有进入该站、可能绕本地环若干次、再离开的路线，都须用新直达连接表示。旧直达路线仍作为另一选择。不断重复后只剩起终点，以及描述全部旅行的连接。状态消除用边上的正则表达式做这种压缩。结果可能比原图长很多，不同消除顺序也会给出外观不同但语言相同的表达式。

### 02 / 理解原理

广义 NFA 用正则表达式标边。添加无入边的新起点与无出边的新终点，用 ε 接旧边界。缺边表示 ∅，平行边用并合并。移除 k 时，为每个幸存 i→j 加入经 k 的选择：进入、循环任意次、离开。

最后只剩新起终点，其边表达式表示原语言。结合表达式转 NFA 与子集构造，可证表达式、NFA、DFA 表达能力相同，但表示大小与执行成本未必相同。

### 03 / 逐项读懂公式

```text
Rᵢⱼ ← Rᵢⱼ | Rᵢₖ(Rₖₖ)*Rₖⱼ
```

Rᵢⱼ 是当前 i 到 j 的边表达式。k 为待删状态。新选择依次连接进入路线、在 k 上零次或多次循环、离开路线。原直达路线仍保留。一步消除中所有边标签都取自消除前图，i、j 必须是幸存状态。

### 04 / 先看一个完整例子

设起点 s、中间 k、终点 f，边为 s→k:a、k→k:b、k→f:c、s→f:d。删除 k 后 s→f 为 d|ab*c。abbbc 走 a 进入、三次 b 循环、c 离开。ac 用零次循环，d 用旧直达边。abcabc 不允许，因为到 f 后不能重启。若无直达边，其标签 ∅，结果简化为 ab*c。

### 先认识这些词

- **广义边:** 以正则表达式标记的边。

- **消除:** 移除状态同时保留幸存端点间全部路线。

- **自环:** 从状态返回自身的路线。

### 一步步想清楚

**为何保留旧边？**

有些接受路线从不经过被删状态。

**缺失自环贡献什么？**

其星贡献 ε，表示绕环零次。

**表达式更长就表示不同语言吗？**

不是，消除顺序可改变长度而不改接受串。

### 删除有环中间状态

s,k,f 的标签为 s→f:u、s→k:v、k→k:w|x、k→f:y，无其他边。删除 k 并检验 vwxwy。

**先选择方法**

区分不经 k 与进入、循环、离开 k 的路线。

1. 不经 k 的路线贡献 u，必须保留。

2. 经 k 路线贡献 v(w|x)*y，每次环独立选 w 或 x。

3. vwxwy 分成入口 v、环 w,x,w、出口 y，顺序均符合。

**解释最终答案**

结果 u|v(w|x)*y，接受 vwxwy。

**检验推理**

零环路线 vy 也匹配，u 不进入 k 仍被接受。

### 区分缺边与免费边

无 s→f 边。s→k:ε、k→f:ab，k 无自环。删除 k，再与 s→k 缺失的变体比较。

**先选择方法**

缺边代 ∅，存在的免费边代 ε。

1. 第一图代入 ∅|ε(∅)*ab，旧直达选择为空。

2. 因 ∅*={ε}，连接 ε、ε、ab 得 ab。

3. 变体入口为 ∅，因此 ∅|∅(∅)*ab=∅，根本无法进入 k。

**解释最终答案**

免费入口允许恰为 ab 的串，缺失入口不允许任何串。

**检验推理**

第一图及其表达式都不接受 ε，因为出口仍需 a、b 两符号。

### Leon 的进一步思考

**一次更新只用一张旧图**

所有经 k 路线应使用消除前标签。同一步混入刚更新标签，可能意外引入不期望的重复结构。

**空语言消灭连接**

若无入口或出口，经该点路线为 ∅。相反，ε 入口或出口不消费符号，却仍允许路线。

**注意这个边界:** 不能删掉原 i→j 表达式，不经过 k 的路线也必须保留。

## 匹配策略与重复工作

### 01 / 从一个故事开始

图书管理员把一排相同卡片分成一张或两张的包。若末尾要求无法满足，她可能撤销选择，反复尝试面对相同剩余任务的不同分法。更有条理的方法记录已到达的不同情况并合并等价尝试。这说明短正则表达式在回溯引擎中也可能很慢，尽管有限状态匹配可行。数学语言与引擎搜索策略是两层，都影响性能判断。

### 02 / 理解原理

成员问题问整个输入是否属于表达式语言。朴素递归或回溯匹配可能探索同一前缀的多种分解，重复等价子问题。Thompson 风格 NFA 模拟维护活跃状态集，逐符号更新并包含 ε 闭包。

大小 m 的表达式可构造状态与边数 O(m) 的 NFA，直接模拟长 n 输入需 O(mn) 时间、O(m) 工作空间。先确定化后，固定 DFA 的常数时间转移可使匹配 O(n)，但构造 DFA 可能需指数状态。这些界针对基本正则表达式，不包括反向引用等扩展。

### 03 / 逐项读懂公式

```text
NFA 模拟：O(mn) 时间、O(m) 活跃状态空间
已预处理的固定 DFA：O(n) 匹配时间
```

m 衡量 Thompson 风格 NFA 大小，包括转移；n 为输入长度。每个字符的 ε 可达与普通转移都避免重复访问已加入状态。DFA 界假定自动机已构造，查转移为常数时间。不是所有库引擎都采用这些策略，表达式也属输入时须计预处理成本。

### 04 / 先看一个完整例子

对 (a|aa)*b 与 aaaaac，五个 a 可分成一张或两张块，例如 a,a,a,a,a 或 aa,a,aa。因缺末 b，所有选择最后都失败。回溯可能按许多分法重复发现失败。NFA 模拟合并同前缀后到同状态的分支，c 没有续路时拒绝。改为 aaaaab 则匹配。例子展示重复工作，而没有改变语言。

### 先认识这些词

- **回溯:** 撤销选择并尝试其他路径。

- **活跃集合:** 当前输入前缀后所有可达状态。

- **预处理:** 匹配某个输入前进行的工作。

### 一步步想清楚

**短模式为何也慢？**

执行可能重复探索最终同样失败的许多分法。

**什么信息允许合并尝试？**

相同自动机状态与输入位置表示相同剩余任务。

**DFA 构造总便宜吗？**

不是。子集构造可产生指数状态，即使后续匹配为线性。

### 统计重复分解

对 (a|aa)*b 和输入 aaaaac，统计五个 a 分成长度一或二块的方式。不把它当作引擎指令总数。

**先选择方法**

设 F(n) 为分法数，按第一块长一还是二分类。

1. F(0)=1 表示空分法，F(1)=1 表示一个单块。

2. n≥2 时 F(n)=F(n−1)+F(n−2)，移去首块剩对应长度。因此 F(2)=2、F(3)=3。

3. 继续 F(4)=3+2=5，F(5)=5+3=8。每种分法最后仍遇 c 而非所需 b。

**解释最终答案**

八种分法都失败。这量化重复选择，不是通用运行时间。

**检验推理**

将 c 改为 b 会接受，但 a 块仍有八种分法。

### 区分准备与匹配

假设已构造 DFA 每符号转移一次。三输入长 4、7、9。构造耗 30 个抽象工作单位，每转移一单位。求匹配成本与总成本。

**先选择方法**

先累加每输入扫描，再仅加一次准备成本。

1. 前两输入分别需四与七次转移，小计 11。

2. 加第三输入九次，匹配成本为 20。

3. 只加一次构造 30，三输入总成本 50。

**解释最终答案**

匹配成本 20，完整批次 50。线性扫描并未消除准备成本。

**检验推理**

若每输入都需新 DFA 且构造成本相同，准备为 90，总数 110。

### Leon 的进一步思考

**统计状态，不统计想象的人**

成员判断无需保留同状态多个副本。路径数可增长而集合仍小；统计解析数是不同问题。

**合理分摊准备成本**

固定 DFA 多次复用可分摊构造成本。每请求换模式时忽略准备工作，会误导比较。

**注意这个边界:** 某回溯实现耗指数时间，并不证明正则匹配本身必然指数困难。

未来只依赖当前状态与未读后缀，不同历史不再提供成员判断所需信息。

## 正则语言的封闭性与判定过程

### 01 / 从一个故事开始

一个面板同时记录两传感器状态。第一传感器三种模式，第二四种，组合最多十二对。策略可在两者都许可、任一许可或两者不同意时通过。这就是自动机积。接受状态对表达策略，转移结构不变。检查哪些状态对可达，就能判定是否可能发生分歧，为比较不同规格提供有限过程。

### 02 / 理解原理

正则语言对并、交、补封闭。相同字母表上的完整 DFA 可构造积，每读一符号同时更新两个状态，再按所需布尔运算选择接受对。求补只需交换完整 DFA 的接受与非接受状态。

模拟可判定成员资格，从起点寻找接受状态可判定非空。等价归约为对称差是否为空：若没有可达状态对恰有一个分量接受，两机器就对所有串一致。表达式转 DFA 因此也能判定表达式等价，虽然转换可能指数增长。

### 03 / 逐项读懂公式

```text
δ×((p,q),a) = (δ₁(p,a),δ₂(q,a))
L₁ = L₂ ⇔ (L₁ ∖ L₂) ∪ (L₂ ∖ L₁) = ∅
```

p、q 是两个 DFA 的状态，δ₁、δ₂ 是各自转移，δ× 为积转移。L₁、L₂ 是语言。差集保留只在一侧的串，两差的并称对称差。要求共同字母表；求补或积前，必要时添加拒绝汇点使机器完整。

### 04 / 先看一个完整例子

A 接受以 1 结尾的串，B 接受含奇数个 1 的串。积起点是（不以1结尾，偶）。输入 10 时 A 先接受后拒绝；B 读 1 到奇、读 0 不变。末状态恰有一侧接受，所以 10 证明语言不同。可达搜索可用前驱链接还原反例。一个反例足够，很多一致样本则不足。

### 先认识这些词

- **积状态:** 记录每台机器一个状态的有序对。

- **对称差:** 恰属于两个语言之一的串。

- **可达性:** 是否有有限路径从起点到某状态。

### 一步步想清楚

**一次分歧为何足够？**

等价要求每个输入一致，任一反例就推翻它。

**三状态与五状态机器的积大小界是多少？**

最多 3×5=15 对，部分可能不可达。

**完整 DFA 能交换终态求补吗？**

能。每输入恰有一个完整运行，反转末状态接受性就反转答案。

**为什么测试很多字符串仍弱于搜索乘积图？**

有限样例可能漏掉更长的反例。乘积图虽然节点有限，却覆盖任意字符串可能到达的状态对。

### 求两个小规则的交

在 {0,1} 上，A 接受偶数长度，B 接受末尾 1。给出积的接受规则，检查 101、01。

**先选择方法**

独立跟踪长度奇偶与末符号，交要求两者都满足。

1. 状态为 (E,N),(E,Y),(O,N),(O,Y)，起点 (E,N)。每符号切奇偶，1 设置 Y，0 设置 N。

2. 101 长三且末 1，状态 (O,Y)，不满足偶长。

3. 01 长二且末 1，结束于唯一接受对 (E,Y)。

**解释最终答案**

交语言接受 01、拒绝 101，仅 (E,Y) 为终态。

**检验推理**

ε 虽偶长却无末尾 1，起点正确拒绝。

### 寻找语言反例

A 接受偶数个 1，B 接受末 0 串且拒绝 ε。在 {0,1} 上找最短分歧，允许 ε。

**先选择方法**

搜索边前先检查起点对，空串长度零。

1. 对 ε，A 见零个 1，零为偶数，所以接受。

2. B 因无末符号明确拒绝 ε，起点对已经分歧。

3. 不存在长度小于零的串，因此不可能有更短分歧。

**解释最终答案**

ε 是最短反例，两语言在起点就不同。

**检验推理**

0 被两者接受，说明只看非空例子可能漏掉最简单证据。

### 跟踪 aba 在两个自动机中的状态

比较“包含 ab”和“以 ab 结尾”。两机都从 0 开始，只接受状态 2。使用程序中的转移表。

**先选择方法**

每读一个字母记录状态对，读完整个单词后比较接受性。

1. 从 (0,0) 出发。读 a 后都到 1，得到 (1,1)。

2. 再读 b 得到 (2,2)，前缀 ab 被两者接受。

3. 最后读 a，得到 (2,1)，只有“包含 ab”接受。

**解释最终答案**

aba 属于对称差，因此两个语言不等价。

**检验推理**

长度小于 3 且含 ab 的字符串只有 ab 本身，它也以 ab 结尾，因此不存在更短反例。

### 找到区分两个 DFA 的最短单词

两位同学制作文本过滤器：一个接受任意位置含 ab 的单词，另一个只接受以 ab 结尾的单词。ab 和 aab 的测试都通过，于是他们以为两个过滤器等价。米娜不再猜测试字符串，而是同时运行两个自动机，搜索恰好只有一个接受的状态对。最终找到 aba，直接说明二者为何不同。

```python
from collections import deque
from itertools import product

def witness(a, accepting_a, b, accepting_b):
    alphabet = ("a", "b")
    start = (0, 0)
    parents = {start: None}
    queue = deque([start])
    while queue:
        pair = queue.popleft()
        x, y = pair
        if (x in accepting_a) != (y in accepting_b):
            letters = []
            while parents[pair] is not None:
                previous, letter = parents[pair]
                letters.append(letter)
                pair = previous
            return "".join(reversed(letters))
        for letter in alphabet:
            nxt = (a[x][letter], b[y][letter])
            if nxt not in parents:
                parents[nxt] = (pair, letter)
                queue.append(nxt)
    return None

def accepts(table, word):
    state = 0
    for letter in word:
        state = table[state][letter]
    return state == 2

contains = [{"a": 1, "b": 0}, {"a": 1, "b": 2}, {"a": 2, "b": 2}]
ends = [{"a": 1, "b": 0}, {"a": 1, "b": 2}, {"a": 1, "b": 0}]
word = witness(contains, {2}, ends, {2})
assert word == "aba" and witness(contains, {2}, contains, {2}) is None
for size in range(len(word)):
    for letters in product("ab", repeat=size):
        test = "".join(letters)
        assert accepts(contains, test) == accepts(ends, test)
print("shortest witness:", repr(word))
print("contains ab:", accepts(contains, word))
print("ends in ab:", accepts(ends, word))
```

**在本地运行**

```sh
python regular-decision-problems-shortest-dfa-counterexample.py
```

**预期输出**

```text
shortest witness: 'aba'
contains ab: True
ends in ab: False
```

**按执行顺序理解**

1. 乘积状态 (x,y) 记录两个自动机读完同一前缀后的状态。

2. 状态对入队时标记；图中最多有 |Q_A|×|Q_B| 个状态对。

3. 恰好一个分量接受时，将乘积状态视为目标。这是对称差，而非交集。

4. 用父指针恢复字符串。BFS 保证首次找到的反例按符号数最短。

**逐步读懂代码**

两个语言不同，当且仅当对称差非空：L(A)≠L(B) 等价于存在 w，使 accept_A(w) 与 accept_B(w) 恰好一真一假。完整乘积搜索可以判定给定有限自动机的这一条件。若找不到可达的分歧状态对，任何单词都会到达判断一致的状态对。

状态数分别为 q_A、q_B，字母表大小为 s 时，时间为 O(s×q_A×q_B)，存储状态需要 O(q_A×q_B) 空间。自动机必须完整：每个状态对每个字母都有转移。缺失转移应先补到明确的拒绝汇点。

若初始状态就有分歧，返回空字符串也是合法反例。None 才表示不存在反例。这里的小规模穷举检查核实样例中没有更短反例；乘积状态的访问论证解释一般搜索为何终止。本方法比较 DFA，不能用于判定任意程序等价。

### Leon 的进一步思考

**共同字母表重要**

补集相对于 Σ*。改变字母表会改变未见符号的处理，因此应在共同字母表上补全机器。

**广度优先找最短证据**

每边消费一个符号时，积图广度优先搜索可找最短分歧串。记录入边符号与父状态以还原。

**注意这个边界:** 不完整 DFA 求补前要加汇点。缺转移所拒绝的输入也须在补机器中接受。

## 证明有限记忆不够

### 01 / 从一个故事开始

衣帽间管理员用固定卡片记录进入人数，稍后必须允许恰同数量离开。人数无上限时，两个不同总数迟早共用一张卡。此后相同退出序列会导致相同行为，尽管一者应该通过，另一者应失败。这不是某套卡片设计失败，而是反对所有固定有限卡片系统的论证。关键在无界的精确要求；人数有上限或只问固定模数余数，就改变了问题。

### 02 / 理解原理

证明非正则，可说明任何有限状态摘要都保不住所需后缀区别。对 L={aⁿbⁿ:n≥0}，假设存在 m 状态 DFA。m+1 个前缀 ε,a,…,aᵐ 中必有 aⁱ、aʲ 到同状态。接同后缀 bⁱ 后两串行为相同，但 aⁱbⁱ 属于 L，aʲbⁱ 不属于，矛盾。

另一技巧利用封闭性：若假设语言正则，与已知正则语言运算后得到已知非正则语言，假设就错。这些论证只排除有限自动机，不表示语言不可判定。

### 03 / 逐项读懂公式

```text
δ*(q₀,aⁱ) = δ*(q₀,aʲ), i < j
⇒ δ*(q₀,aⁱbⁱ) = δ*(q₀,aʲbⁱ)
```

m 为状态数，m+1 个前缀由抽屉原理迫使状态重复。i、j 是不同前缀长度，bⁱ 为共同区分后缀，δ* 为扩展转移。同状态的确定机器处理相同剩余输入必然一样。矛盾来自两完整串的成员资格，而不只是长度不同。

### 04 / 先看一个完整例子

E 为任意顺序下 a、b 数相同的串。若 E 正则，与正则 a*b* 的交也应正则。该交恰为 {aⁿbⁿ:n≥0}，重复状态论证已证它非正则，矛盾，所以 E 也非正则。abba 在 E 却不在 a*b*；取交故意排除混合顺序，显出已知困难模式。

### 先认识这些词

- **抽屉原理:** 对象多于类别时，至少两对象进入同类。

- **区分后缀:** 同一追加串使所需成员答案不同。

- **非正则:** 没有有限自动机能识别该语言。

### 一步步想清楚

**为什么用 m+1 个前缀？**

只有 m 个状态，因此两个前缀必共享一个。

**为何恰接 bⁱ？**

它配平较短 a 前缀，却不能配平较长者。

**非正则是否表示没有算法能判定？**

不是。可用无界工作记忆的机器能对有限输入计数比较。

### 走完必然碰撞论证

假设识别 {aⁿbⁿ:n≥0} 的 DFA 在 a²、a⁵ 后到同状态，解释为何矛盾。

**先选择方法**

找一个共同后缀，让一前缀必须接受，另一必须拒绝。

1. 选 b²，为较短前缀提供恰两个 b。

2. a²b² 数相同必须接受；a⁵b² 有五 a 两 b 必须拒绝。

3. 两运行处理后缀时状态相同，确定性迫使后续状态与最终答案相同，与要求矛盾。

**解释最终答案**

正确 DFA 中两前缀不能共状态。需要任意多区别，因此排除有限 DFA。

**检验推理**

改接 b⁵ 会交换哪个串配平，同样矛盾。

### 有界版本是正则

设 L₃={aⁿbⁿ:0≤n≤3}，给正则表达式，并解释为何无限语言证明不能原样套用。

**先选择方法**

枚举有限 n 值，无需无界计数器。

1. n=0 得 ε，n=1 得 ab。

2. n=2 得 aabb，n=3 得 aaabbb，没有其他允许 n。

3. 取并 ε|ab|aabb|aaabbb，有限表达式正则地描述四串。

**解释最终答案**

L₃ 正则。先前证明需要任意多个必须区分的前缀，这里固定上限消除了它。

**检验推理**

a⁴b⁴ 虽数相等仍拒绝，因为 n=4 超过上限。

### Leon 的进一步思考

**量词承担证明**

状态数 m 任意。证明某个三状态机失败，弱于从任意有限 m 出发推出矛盾。

**上限改变语言**

限制 n≤3 只剩 ε,ab,aabb,aaabbb。有限列表总可识别，尽管无界模式不能用有限记忆。

**注意这个边界:** 画不出 DFA 不是非正则证明，必须排除每个可能有限 DFA。

## 文法与递归结构

### 01 / 从一个故事开始

嵌套收纳盒可选择空隔间，或在大盒里包一个小盒。指令可以引用自身，因此有限配方生成任意深度嵌套。上下文无关文法类似：有名称的未完成组件可替换为终结符与更多未完成组件。只有全部完成才得到成品。类比解释递归，却不规定实际执行顺序。不同替换次序可能描述同一结构、生成同一串。

### 02 / 理解原理

CFG 包含非终结变量、终结符、产生式和起始变量。每条规则将一个非终结符替换为有限序列，也可替为 ε。“上下文无关”表示无论邻近符号是什么，都可应用规则。推导从起始变量开始，只有全为终结符的结果才属于语言。

文法可描述超出有限状态记忆的嵌套。正确性有两个方向：生成串都符合目标，目标串都能生成。上下文无关语言对并、连接、星封闭：先改名避免变量冲突，再加新起点选择、连接或重复。它们不像正则语言那样对任意交与补封闭。每个正则语言都上下文无关，反向不成立。

### 03 / 逐项读懂公式

```text
G = (V, Σ, P, S)
L(G) = {w ∈ Σ* : S ⇒* w}
```

V 是非终结符集，Σ 是与其不交的终结字母表，P 为产生式，S 为起点。⇒ 是一步重写，⇒* 为零步或多步。中间形式可混有变量，但不属于语言成员。w∈Σ* 要求最终只有终结符，包括可能的 ε。

### 04 / 先看一个完整例子

用 S→[S]S|ε 生成平衡方括号。生成 [][]：先 S⇒[S]S，把内部 S 替 ε 得 []S，再展开余 S 为 [S]S，最后消去两个 S。生成 [[]] 则改为展开内部 S。任意非空平衡串的第一个 [ 都有匹配 ]，把串分成平衡内部及平衡后缀，恰对应两个 S。该分解支持按串长归纳证明。

### 先认识这些词

- **非终结符:** 仍需重写的命名组件。

- **终结符:** 允许出现在完成串中的符号。

- **推导:** 从起始变量出发的一系列规则应用。

### 一步步想清楚

**有限文法为何可生成无限多个串？**

递归规则可应用任意有限次数。

**aSb 已经是语言成员吗？**

只要 S 仍是非终结符就不是，必须完成剩余工作。

**生成几个例子就证明完备吗？**

不能，必须解释每个目标串如何生成。

### 生成镜像串

文法 S→aSa|bSb|ε，字母表 {a,b}。完整推导 abba，并说明所有生成串共有性质。

**先选择方法**

匹配外层相同符号，递归中间，以 ε 结束。

1. abba 外符号为 a，因此 S⇒aSa。

2. 内部目标 bb，因此把 S 替 bSb，得 aSa⇒abSba。

3. 剩余 S 替 ε，得 abba，无变量。每次包裹添加两个相同端符号。

**解释最终答案**

S⇒aSa⇒abSba⇒abba。每个生成串都是偶长度回文。

**检验推理**

aba 虽回文却为奇长，文法不能生成；长度不变量解释原因。

### 用新名称构造连接

G₁ 为 A→aA|ε，G₂ 为 B→bB|b。构造前者串一条接后者串一条的文法，再推导 aab。

**先选择方法**

保留不相交变量 A、B，用新起点将其连接。

1. 加 S→AB。A 生成零个或多个 a，B 生成一个或多个 b。

2. 两次 A 递归后用 ε：S⇒AB⇒aAB⇒aaAB⇒aaB。

3. 用 B→b 得 aab。两组件顺序固定，任何规则都不能将 a 放到 b 后。

**解释最终答案**

文法生成 a*b⁺，即任意 a 块后接非空 b 块，并可生成 aab。

**检验推理**

A 立即消失时允许 b；B 无法消失，所以不含 ε。

### Leon 的进一步思考

**可靠性与完备性不同**

只生成 ε 的文法对平衡括号是可靠却不完备的。它不生成坏串，却漏掉所有非空好串。

**组合前先改名**

两文法都可能用 S 表示不同内容。连接前先改名，否则规则可能发生意外交互。

**注意这个边界:** [S] 仍有非终结符，是中间形式，不是已生成终结串。

## 解析树与歧义

### 01 / 从一个故事开始

书面表达式像缺少分组标记的装配指令。先拼前两块或先拼后两块，可能从相同符号造出不同结构。解析树把结构写清：叶是可见串，内部节点记录文法如何组装。独立工作的不同先后顺序不一定改变结构。歧义关乎不同树，因此不能仅列两种任意规则应用顺序就断言有歧义。

### 02 / 理解原理

解析树记录推导的层级结构。根为起始变量，内部节点按产生式展开，叶从左到右组成结果串。若某串有两棵不同解析树，等价地有两条不同最左推导，则文法有歧义。

E→E+E|E×E|n 没规定优先级和结合性，因此有歧义。分层文法让表达式用加法组合项，项用乘法组合因子，因子提供原子或括号。歧义属于特定文法，不能由一份有歧义文法断言语言没有无歧义文法。可靠求值或翻译前须先确定结构。

### 03 / 逐项读懂公式

```text
G 有歧义 ⇔ 存在 w∈L(G)，且 w 至少有两棵不同解析树
```

G 为文法，w 为终结串，存在量词表示一个见证就足够。不同树指产生式结构不同，不是书写或遍历顺序不同。最左推导总展开最左未完成变量，排除无关执行次序差异。这是歧义定义，不是能判定任意文法歧义的算法。

### 04 / 先看一个完整例子

E→E+E|E×E|n 对 n+n×n 可有根为加或根为乘的树。三个 n 分别取 2、3、4，则 2+(3×4)=14，而 (2+3)×4=20。用 E→E+T|T，T→T×F|F，F→n|(E) 可让乘法先在项内形成，再由加法组合。括号仍能明确要求另一结构。

### 先认识这些词

- **解析树:** 展示哪些规则构造该串的层级树。

- **优先级:** 决定哪个运算结合得更紧的规则。

- **结合性:** 同级重复运算如何分组。

### 一步步想清楚

**两条任意推导为何不够？**

它们可能只在不同次序展开独立分支，仍是同一树。

**同一表达式如何有 17 与 27？**

5+4×3 若为 5+(4×3) 得 17，若为 (5+4)×3 得 27。

**加乘优先级能决定减法结合性吗？**

不能。重复减法还需独立分组规则。

**为什么一次切分内部相乘，不同切分之间相加？**

一次切分中，每棵左树可与每棵右树配对；不同切分下，一棵树的根划分唯一，因此集合互不重叠。

### 两棵树产生不同结果

使用 E→E+E|E×E|n，其中 n 表示一个数字记号。三个数字记号依次显示数值 5、4、3。给出 5+4×3 的两种解析并求值。

**先选择方法**

保持叶顺序不变，选择不同根运算。

1. 根选 +，左叶 5，右子树 4×3。先乘得 12。

2. 根相加 5+12=17，该树为 5+(4×3)。

3. 改根为 ×，左子树 5+4=9，右叶 3，根值 9×3=27。

**解释最终答案**

两树给相同无括号文字，却得 17、27，证明文法有歧义。

**检验推理**

加显式括号可区分两个所求结构，消除这次歧义。

### 展开顺序不是树歧义

文法仅 S→AB、A→a、B→b。比较先展开 A 与先展开 B。

**先选择方法**

写两推导，再比较父子结构。

1. 先 A 得 S⇒AB⇒aB⇒ab。

2. 先 B 得 S⇒AB⇒Ab⇒ab。

3. 两树均根 S，子为 A、B，A 下 a、B 下 b，没有产生式选择不同。

**解释最终答案**

两种调度描述同一解析树，不构成歧义；该文法无歧义。

**检验推理**

只有第一种始终最左展开，从而排除无关次序差异。

### 用小规模结果算出五棵树

对 E→E+E | n，计算 T(4)，不要枚举所有推导顺序。

**先选择方法**

按根切分数树结构。不同节点展开顺序可能得到同一棵树，不能重复计数。

1. T(1)=1，T(2)=T(1)T(1)=1。

2. T(3)=T(1)T(2)+T(2)T(1)=2。

3. T(4)=T(1)T(3)+T(2)T(2)+T(3)T(1)=2+1+2。

**解释最终答案**

共有五棵语法树。程序打印五种不同的完全括号化形式。

**检验推理**

三个操作数的两棵树是 ((n+n)+n) 和 (n+(n+n))，可核对第一个非平凡情形。

<a id="lab-parse-trees-ambiguity-count-expression-trees"></a>

### 数清语法树，不要默认只有一种解析

计算器接受 n+n+n+n。米娜先合并第一对操作数，朋友却先合并最后一对。两种做法都符合 E→E+E | n。字符串合法，但结构并不唯一。米娜枚举根节点的所有切分，再组合左右子树，最终找到五棵树，也理解了解析器为什么需要结合性规则。

```python
from functools import lru_cache

def count_trees(operands):
    if operands < 1:
        raise ValueError("at least one operand required")
    ways = [0] * (operands + 1)
    ways[1] = 1
    for size in range(2, operands + 1):
        ways[size] = sum(ways[left] * ways[size - left]
                         for left in range(1, size))
    return ways[operands]

@lru_cache(None)
def trees(operands):
    if operands == 1:
        return ("n",)
    return tuple(f"({left}+{right})"
                 for cut in range(1, operands)
                 for left in trees(cut)
                 for right in trees(operands - cut))

assert [count_trees(n) for n in range(1, 6)] == [1, 1, 2, 5, 14]
assert len(set(trees(4))) == count_trees(4)
print("four operands:", count_trees(4), "parse trees")
for tree in trees(4):
    print(tree)
```

**在本地运行**

```sh
python parse-trees-ambiguity-count-expression-trees.py
```

**预期输出**

```text
four operands: 5 parse trees
(n+(n+(n+n)))
(n+((n+n)+n))
((n+n)+(n+n))
((n+(n+n))+n)
(((n+n)+n)+n)
```

**按执行顺序理解**

1. 一个操作数对应一棵叶子树，基础值是一，不是零。

2. 根在 left 个操作数之后切分时，左右树数量相乘，每对左右树构成一棵树。

3. 对不同根切分求和；根的划分不同，不会得到同一棵有序树。

4. 只枚举四个操作数用于展示。计数与实际生成全部树，输出成本差别很大。

**逐步读懂代码**

设 T(m) 表示 m 个相同操作数词元用加号连接时的语法树数量。T(1)=1，T(m)=对 k=1 到 m-1 求和 T(k)×T(m-k)。k 表示左子树的叶子数量。m=4 时，三种根切分分别贡献 1×2、1×1、2×1，总数为 5。

计数器需要 O(m²) 次算术操作，并保存 O(m) 个整数。大计数需要大整数，因此这里没有声称任意大 m 下算术仍是常数成本。枚举所有树至少要花费与输出字符数相关的时间，增长快得多。

算出的数值相同，不表示文法无歧义。歧义指同一词元字符串具有多棵语法树。对这个简单语言，E→E+n | n 可以规定左结合。本例假定已经分词且只有加号，并未实现词法分析、其他运算符优先级或通用文法解析器。

### Leon 的进一步思考

**同值可能掩盖歧义**

1+2+3 两树都算六，但仍不同。数值相等不能证明文法无歧义。

**修文法而非猜结构**

分表达式、项、因子可将优先级写入语法。求值器据树计算，无需事后添加可能矛盾的规则。

**注意这个边界:** 仅以不同次序展开独立分支并不构成歧义。应比较树或最左推导。

## 不改变语言的 Chomsky 范式

### 01 / 从一个故事开始

设装配说明只能有两种形状：连接两个未完成组件，或安装一个完成零件。复杂指令拆成小阶段，可选组件和别名需谨慎处理，确保新说明仍生成相同成品。Chomsky 范式为文法规则提供这种形状。目的不是最短或最优雅，而是让解析容易推理。空成品例外单独保留，因为有可见叶的树无法表示无零件成品。

### 02 / 理解原理

CNF 普通产生式只能 A→BC 或 A→a。若语言含 ε，新起点还可 S₀→ε，且新起点不可出现在任何右侧。转换通过为长规则中终结符引入变量、将长右侧拆成二元规则、为可空变量添加所有所需省略选择，以及按别名可达关系移除单位规则来保留语言。

顺序与记录很重要：可空变量可重复出现，只删 ε 规则而不添选择会丢串。长 n 的非空词的 CNF 树有 n 个终结生成节点、n−1 个二元节点。该受限结构支持可判定成员检查与动态规划。

### 03 / 逐项读懂公式

```text
A→BC 或 A→a；可选 S₀→ε
含 n 个终结符的非空解析需 2n−1 次产生式应用
```

A、B、C 为非终结符，a 为终结符，S₀ 为受保护起点。可选空规则是唯一 ε 例外。n 为非空串长。二叉结构有 n 个叶和 n−1 个分支节点，终结规则再对应 n 个叶应用。该计数只适用于 CNF，不适用于有单位链或可空环的任意文法。

### 04 / 先看一个完整例子

从 S→aS|b 开始，引入 A→a，使混合规则变 S→AS。因 S 在右侧出现，加入新起点 S₀→S。去单位规则时复制 S 的非单位规则，得 S₀→AS|b、S→AS|b、A→a。

仍生成 aⁿb。对 aab：S₀⇒AS⇒aS⇒aAS⇒aaS⇒aab，共五次，与 2×3−1 一致。不同展开顺序计数仍一样，因为树节点数固定。

### 先认识这些词

- **Chomsky 范式:** 规则限两个变量或一个终结符，另有受保护起点例外。

- **可空:** 变量能够推导 ε。

- **单位产生式:** 右侧仅一个变量的 A→B 规则。

### 一步步想清楚

**为何引入终结符辅助变量？**

二元 CNF 规则须是两个变量，不能是 aB 这样的混合。

**CNF 生成四终结符要几步？**

四个终结规则加三个二元规则，共 2×4−1=7。

**ε 能用相同正长计数吗？**

不能。它无终结叶，使用独立起点例外。

### 转换长度三规则

文法 S→aBC、B→b、C→c 只生成 abc。转换到 CNF 且不改变语言。

**先选择方法**

先分离长规则中的终结符，再把三个变量拆为二元步骤。

1. 加入 A→a，用 S→ABC 替代 S→aBC，生成符号不变。

2. 加入 X→BC，并将长规则改 S→AX。S 每步产生两个变量。

3. 保留 B→b、C→c。S→AX、X→BC、A→a、B→b、C→c 均符合形式。

**解释最终答案**

CNF 文法仍恰生成 abc，每次解析用两个二元、三个终结产生式。

**检验推理**

n=3 时 2n−1=5，与五次相符；没有其他规则可生成别的串。

### 删除重复可空变量

文法 S→AA、A→a|ε。转为保语言 CNF，允许 S 作受保护起点，且 S 不在右侧出现。

**先选择方法**

移除空与单位规则前，枚举两个 A 独立保留或省略。

1. 保留两 A 得 S→AA，删一个得 S→A，两种删法得到同规则。

2. 都删得 S→ε，因为 S 受保护，允许该空规则。

3. 删除 A→ε，保留 A→a。把单位 S→A 替为 S→a。最终 S→AA|a|ε、A→a。

**解释最终答案**

两文法均恰生成 {ε,a,aa}，最终是带所述起点例外的 CNF。

**检验推理**

若删 A→ε 却不添 S→a、S→ε，就会丢掉三串中的两串。

### Leon 的进一步思考

**先保留选择再删除**

变量可消失时，每个相关出现都能保留或省略。先删 ε 规则可能悄悄删掉短词。

**范式是工具**

CNF 可能增加很多辅助变量。收益是可预测二叉解析结构，不一定文法更小或文字更短。

**注意这个边界:** 右侧长度不超过二并不就属于 CNF。A→B 是单位规则，A→aB 混合终结与非终结符，都需转换。

## CYK：从短片段构造长解析

### 01 / 从一个故事开始

校对者先给单词贴标签，再处理两个词和更长片段。只有长片段可分成两个已理解且符合规则的短片段时，才给它标签。表格存结果避免重做。CYK 对 CNF 文法采用此计划，不把有希望的分界当成唯一分界，而会检查所有边界。表格直接回答成员资格，若保存成功选择，还能还原解析树。

### 02 / 理解原理

使用左闭右开区间：T[i,j] 是生成 w[i:j] 的非终结符集合，边界为 0 到 n。用终结规则初始化长度一，再按长度 2 到 n 处理。对每个 i<k<j 和 A→BC，若 B∈T[i,k]、C∈T[k,j]，则加入 A。依赖都是更短片段，因此顺序有效。

非空词接受当且仅当起始变量在 T[0,n]。ε 按起点例外单独处理。直接扫描二元产生式时，时间 O(|P|n³)，成员存储 O(|V|n²)。固定文法下分别为三次时间、二次空间。

### 03 / 逐项读懂公式

```text
T[i,i+1] = {A : A→w[i]}
T[i,j] = {A : ∃k, i<k<j, A→BC, B∈T[i,k], C∈T[k,j]}
```

i 含起点，j 不含终点，k 为两个非空子串的边界，所以 w[i:j] 长 j−i。P 为规则集，V 为变量集。T 保存集合而非一个胜者，因为同子串可能承担多个语法角色。递推要求 CNF 且片段非空，空输入另查。

### 04 / 先看一个完整例子

用 S→AB、A→AA|a、B→b 解析 aab。初 T[0,1]={A}、T[1,2]={A}、T[2,3]={B}。长二时，A→AA 将前两格合成 T[0,2] 中的 A；S→AB 将末 a,b 合成 T[1,3] 中的 S。

整串在 k=2 处分割，A∈T[0,2]、B∈T[2,3]，故加入 S 并接受。短格已有 S 并不足够，必须整串格含 S。记录分界可还原树 S(A(A(a),A(a)),B(b))。

### 先认识这些词

- **片段:** 两个边界之间的连续子串。

- **动态规划:** 存储短子问题答案并用于更大问题。

- **左闭右开区间:** 包含开始位置而不包含结束位置。

### 一步步想清楚

**为何每格存集合？**

多个变量可能生成同子串，并用于不同父规则。

**abc 中 T[1,3] 覆盖什么？**

位置 1、2，即 bc；3 只是结束边界。

**短格含 S 能证明全串接受吗？**

不能，起始变量须在覆盖全串的格中。

### 填写小型 CYK 表

CNF 文法 S→AC、C→BB、A→a、B→b。用边界 0,1,2,3 解析 abb。

**先选择方法**

先初始化字母再扩大片段，保证先子后父。

1. 长一格为 T[0,1]={A}、T[1,2]={B}、T[2,3]={B}。

2. 长二时 ab 无可用二元规则，T[0,2]=∅。两 b 用 C→BB 合并，T[1,3]={C}。

3. 整段在 k=1 分开：前格 A、后格 C 满足 S→AC，因此加入 S。

**解释最终答案**

S∈T[0,3]，因此接受 abb，树为 S(A(a),C(B(b),B(b)))。

**检验推理**

文法无其他选择，因此唯一可能终结串确为 abb。

### 字母合法仍拒绝

使用相同文法 S→AC、C→BB、A→a、B→b，测试 bab，解释整格失败。

**先选择方法**

检查全部二元分界，不能只看每个字母有终结规则。

1. b,a,b 的对角格为 {B},{A},{B}，每字母都可识别。

2. ba、ab 都不匹配唯一长二规则 C→BB，因此两个长二格都空。

3. k=1 时右格空，k=2 时左格空，两者都无法提供 A 后接 C。

**解释最终答案**

T[0,3]=∅，拒绝 bab。符号合法不保证结构合法。

**检验推理**

对照接受的 abb，只有它把 a 放在所需双 b 区域之前。

### Leon 的进一步思考

**保留全部成功分界**

成员判断只需知道变量是否存在。若要恢复全部解析，则每个成功规则与分界都须保留，而非一个指针。

**三次来自循环结构**

区间数量为二次，每区间可有线性分界数。扫描文法另加因子；固定文法三次时间不意味着成本固定。

**注意这个边界:** 不要混用含端点与不含端点。T[i,j] 对应 w[i:j] 时，子格必须 T[i,k]、T[k,j]，不可漏或重复字符。

## 图灵机与配置

### 01 / 从一个故事开始

想象细心书记员拿长方格纸、铅笔和小指令卡。卡片根据当前模式与笔下符号决定动作，一步可改符号、移动一格并换模式。不同于有限自动机，他可回看旧格并留记号。纸带提供可扩展记忆，指令仍有限。无限纸带是可用存储无固定上限的理想化，并非一步做无限操作。

### 02 / 理解原理

图灵机由有限控制、可读写纸带、可移动读写头组成。带字母表含输入符号、空白及可能标记。配置记录状态、头位置与纸带内容，转移决定下一配置。有限次计算后，绝大多数格仍空白。

机器可停机接受、停机拒绝或永远继续。作为函数计算器时，要规定输出编码和头最终位置。单向或双向带、允许原地不动等标准约定改变描述，但不改变可计算函数范围。时间与模拟开销仍可能不同。

### 03 / 逐项读懂公式

```text
δ(q,a) = (q′,b,d),  d ∈ {L,R,S}
C₀ ⊢ C₁ ⊢ C₂ ⊢ ⋯
```

q 为当前状态，a 为头下符号，q′ 为新状态，b 为写入符号，d 为方向，S 表示原地。Cᵢ 为 i 步后完整配置，⊢ 为一次有效转移。停机状态无后续工作。一次只读当前格，不会同时查看整带。

### 04 / 先看一个完整例子

机器扫描二进制串，将每个 0 改为 1，原 1 不变。scan 状态读 0 或 1 都写 1、右移并保持 scan；读空白进入停机且不改带。输入 010 从首位开始，非空带依次 110、110、111，再一次看到空白后停机。空输入立即停机。有限状态不存整词，纸带记录不断变化的输出。

### 先认识这些词

- **配置:** 当前状态、头位置与带内容的整体。

- **带字母表:** 可写符号全集，包括空白与标记。

- **转移:** 一次读取、写入、移动与换状态的规则。

### 一步步想清楚

**为何只有状态还不算配置？**

同状态可能处在不同格或符号上，下一步会不同。

**从位置 2 右移会怎样？**

写完当前格后，下一头位置为 3。

**无界纸带意味着每步无限工作吗？**

不是，每步只访问一个格并有限移动。

### 跟踪翻转位机器

scan 中读0写1右移；读1写0右移；读空白写空白原地停机。101 位于 0–2，头从 0 开始。跟踪到停机。

**先选择方法**

每步记录纸带与头，控制状态不变不表示无事发生。

1. 位置0读1写0，头到1，带为001。

2. 位置1读0写1，头到2，带为011。

3. 位置2读1写0，头到空白位置3，带为010。第四转移看到空白，在此停机。

**解释最终答案**

输出010，四次转移后头在3。

**检验推理**

再翻转输出各位得到原101，独立验证变换。

### 从配置求唯一后继

带位置0,1,2为a,b,空白。头在1，状态q。规则 δ(q,b)=(r,X,L)。求下一配置。

**先选择方法**

读指定格，分开处理写入、移动、控制更新。

1. 头位置1是b，因此规则适用；本步不读位置0的a。

2. 将位置1换X，带成a,X,空白，其他格不变。

3. 从1左移到0，状态q改r。新头下a在下一转移才被读取。

**解释最终答案**

下一配置为状态r、头0、纸带aX后接空白。

**检验推理**

带改变局部；左移和换状态都不会擦掉a。

### Leon 的进一步思考

**说明输出约定**

若有效数字间留临时标记，只说输出在带上不完整。须指明输出格和是否擦标记。

**统计停机转移**

扫描器通常还需一步看到数据后的首空白。只数改变的格可能少算，即使某些写入没改符号。

**注意这个边界:** 缺失转移、拒绝和无限循环不等价。须说明约定，区分停机结果与发散。

## 用标记与不变量设计机器

### 01 / 从一个故事开始

书记员检查两组物品是否配对：先标左组一件，走到右组标一件，再回去重复。标记让记忆跨行走保留。右组提前用完或结束时还有未配物品就失败。这适合比较需要无界记忆而控制模式有限的任务。好的设计要说明每趟保证什么，以及有限输入为什么不可能无限往返。

### 02 / 理解原理

图灵机实现描述可先用阶段而非立即列全部转移。规定每阶段不变量、预期标记、成功与失败出口。对 aⁿbⁿ，先检查输入是一个 a 块后接 b 块，再反复标最左未标 a、找一未标 b、返回左边界。缺伙伴即拒绝；a、b 全标完才接受。

每成功轮未标 a 数严格下降，证明终止。每轮可扫描 O(n) 格，共 O(n) 轮，因此此简单单带实现有 O(n²) 上界，不是所有算法的普遍下界。

### 03 / 逐项读懂公式

```text
r 轮后不变量：已标 r 个 a 与 r 个 b
每成功轮，未标 a 数减少一
```

r 为已完成配对轮数。不变量假设带已通过 a*b* 形状检查，标记仍对应两个有序块。剩余 a 数为非负整数终止量。运行界中的 n 为总输入长。阶段描述还需说明边界检测与坏输入，才能扩成完整转移表。

### 04 / 先看一个完整例子

对 aaabbb，形状检查后每轮带为 XaaYbb、XXaYYb、XXXYYY，最后无未标字母而接受。对 aabbb，两轮 XXYYb，剩 b 而拒绝。abab 有 a 出现在 b 块之后，先被形状检查拒绝。三例分别测试数量相等、数量不等、次序错误。只比数量会误接受某些混合顺序串。

### 先认识这些词

- **标记:** 记录位置已被处理的带符号。

- **阶段:** 服务于明确目标的一组步骤。

- **终止度量:** 重复推进时严格下降的非负量。

### 一步步想清楚

**配对前为何检查顺序？**

仅数量相等也会接受abab等混合串。

**完成一轮保证什么？**

恰好新增一个已标a和一个已标b。

**二次界是普遍下界吗？**

不是。它限制本重复扫描设计，不限制所有模型或算法。

### 伙伴不足时拒绝

用X标a、Y标b，对aaaabb运行有序块配对算法，每轮标最左未标a和b。

**先选择方法**

先跟踪完整成功轮，再定位首次缺伙伴。

1. 形状a*b*合法。首轮配一a一b，得XaaaYb。

2. 第二轮得XXaaYY，还剩两个a，b却全标。

3. 第三轮选a得XXXaYY，但向右直到空白无未标b，明确失败并拒绝。

**解释最终答案**

拒绝aaaabb，因为四个a无法与两个b一一配对。

**检验推理**

直接计数4≠2核实结果，机器有限控制无需保存数字四。

### 证明配对循环停机

输入为有限a块后接b块，总长n，每次扫描到带边界或明确失败便结束。证明不能完成无限多配对轮。

**先选择方法**

以未标a数作为下降非负整数。

1. 初始未标a数为u，0≤u≤n。

2. 每成功轮恰标一个旧未标a，度量u→u−1，且无规则恢复。

3. 至多初始u轮后计数零。缺b可更早拒绝；最终残余b检查也只是有限扫描。

**解释最终答案**

所有允许输入都终止。至多n轮、每轮O(n)，给此实现O(n²)上界。

**检验推理**

u=0时无配对轮，最终扫描仍区分ε与非空b块。

### Leon 的进一步思考

**区分失败类型**

顺序错立即拒绝，所选a无伙伴拒绝，结束残余b拒绝。各检查填补不同正确性缺口。

**下降计数还需要阶段有限**

未标a减少只能证明成功轮有限，还须每轮扫描能到边界或明确失败。停机论证要包含这点。

**注意这个边界:** 不能只证接受者正确而忘记终止或漏拒未配符号。判定器需要双向正确性与停机证明。

## 规则表、三种描述层次与多带机器

### 01 / 从一个故事开始

Leon 在一家小面包店里培训新助手。同一份工作，他用三种方式讲。对店主，他说：“每个做好的蛋糕都盖一颗星。”对助手，他说：“沿着货架从左往右走。看每个蛋糕上的标签。写着已完成的，就在蛋糕上盖一颗星，然后往前走。货架走到头就停。”对安全检查员，他递上一本规则册，每种情况一行：“在状态‘行走’，看到‘已完成’标签：盖星，向右一步，保持‘行走’状态。”这三种说法讲的是同一份工作，区别只在于细节的多少。

后来面包店又买了第二个货架，助手可以把蛋糕放在一个货架上，把标签放在另一个货架上。助手并没有变得更有本事，只是更方便了。助手用两个货架能做的事，一个有耐心、只用一个货架的助手来回走动也都能做。这就是机器的“等价”：同样的活都能完成，只是用时不一定相同。

### 02 / 理解原理

图灵机是一本有限的规则册加上一条纸带。形式上它是一个七元组 (Q, Σ, Γ, δ, q₀, q_accept, q_reject)：状态集、输入符号、带符号（包含输入符号和空白）、转移函数、起始状态和两个停机状态。每条规则的意思是：处于状态 q，读到符号 a，就写下 b，磁头移动一格或不动，并转到状态 q′。转移规则表为每一对（状态，读到的符号）列一行。状态图为每个状态画一个圆，为每条规则画一条箭头，标签写成 a/b,D，读作：读到 a，写 b，移动 D。表和图包含的信息完全一样。一定要说明没有适用规则时会发生什么。常见的约定是：缺少规则就算拒绝。

描述一台机器可以有三个层次。高层描述是用普通语言写的算法，不提纸带：“把二进制数加一。”实现层描述说明磁头做什么、纸带上写什么，但不给状态起名：“走到最右端，再向左移动，把每个 1 改成 0，直到遇到 0 或空白，然后写 1。”形式层描述给出整个七元组和完整的表。要选择题目要求的层次，并且要能向下展开一层：高层描述中的每一句话，都应该对应一组有名字的状态和规则。

多轨机器只有一个磁头和一条带，但每个格子里叠放着多个符号，每条轨道一个。在字母表 Γ 上有两条轨道时，一个格子里放的是 Γ × Γ 中的一对符号。把每一对重新命名为一个符号，就得到普通的单带机器，所以多轨没有增加能力。多带机器有 k 条带和 k 个磁头。一条规则同时读取 k 个磁头下的符号，同时在 k 个磁头下写入，各个磁头分别移动，并且只改变那个共享的状态。

两台机器，或者两种机器模型，如果识别同样的语言，计算同样的函数，就是等价的。证明等价要在两个方向上都做模拟。单带机器就是 k = 1 的 k 带机器。另一个方向则要把 k 条带并排存在一条带上，用 # 隔开，并在每个磁头所在的符号上做标记。模拟一步需要扫一遍，读出被标记的符号，再扫一遍，写入并移动标记。如果某条带需要新的格子，它右边的内容整体后移一格。能力等价并不意味着速度相同：k 条带上的 t 步，在一条带上可能需要大约 t² 步。

一个小程序可以对应到这些形状。像 x = x + 1 这样的赋值，对应一小段改变格子的状态路径。语句的顺序对应一条链：前一段的结束状态就是后一段的起始状态。循环对应一个带测试的状态环，测试有一条箭头回到环中重来，另一条箭头离开。变量对应一条带、一条轨道，或者带上用 # 隔出来的一块区域。要说清每个磁头从哪里开始、在哪里结束，因为循环开始时磁头位置不对，就会读错格子。

### 03 / 逐项读懂公式

```text
M = (Q, Σ, Γ, δ, q₀, q_accept, q_reject)        δ(q, a) = (q′, b, D),   D ∈ {L, R, S}
k 条带：   δ : Q × Γᵏ → Q × Γᵏ × {L, R, S}ᵏ
k 条轨道： 一个磁头，每个格子存放 Γᵏ 中的一个符号

二进制加一。   Q = {start, carry, halt},   Γ = {0, 1, _}

   状态     读     新状态       写      移动
   start    0      start        0       R
   start    1      start        1       R
   start    _      carry        _       L
   carry    1      carry        0       L
   carry    0      halt         1       S
   carry    _      halt         1       S

   0/0,R 1/1,R              1/0,L
      +---+                  +---+
      |   v                  |   v
 --> (start) --- _/_,L ---> (carry) --- 0/1,S ---> ((halt))
                               |                       ^
                               +-------- _/1,S --------+
```

Q 是有限的状态集。Σ 是输入字母表，Γ ⊇ Σ 是带字母表。空白符 _ 属于 Γ，但不属于 Σ。δ(q, a) = (q′, b, D) 给出下一个状态、写入的符号和移动方向：L 向左，R 向右，S 不动。在 1/0,L 这样的标签里，斜线前面是读到的符号，斜线后面先是写入的符号，再是移动方向。双圆圈（这里画成 (( ))）表示停机状态。像加一机器这样计算函数的机器，可以只用一个停机状态来代替 q_accept 和 q_reject。

k 是带的条数。轨道是格子中的一层。带是一条独立的纸带，有自己的磁头。# 是分隔符，不出现在输入里。后面的代价估计中，t 表示被模拟的步数，L 表示编码后那条带的格子数。

### 04 / 先看一个完整例子

在 1011 上跟踪加一机器，1011 是二进制的十一。磁头从最左边的一位开始。在状态 start 下，它向右走过 1、0、1、1（四步），到达空白。随后在状态 carry 下退回最后一位（第 5 步）。这一位是 1，所以写 0 并向左（第 6 步）。再下一位也是 1：写 0，向左（第 7 步）。再下一位是 0：写 1 并停机（第 8 步）。纸带上是 1100，也就是十二。对 111，进位会越过最左端，空白对应的规则写下一个新的最高位 1，输出是 1000。

下面是这台机器的三种层次。高层：“把二进制数加一。”实现层：“向右扫到第一个空白，再退回最后一位。磁头读到 1 就写 0 并向左。读到 0 或空白时，写 1 并停止。”形式层：公式框里的那张表。

再看一个带循环的程序：x = 101（五），然后“重复 3 次：x = x + 1”。用两条带。第 1 条带用二进制存 x，第 2 条带用一进制存计数器 111。状态 start 检查计数器：磁头看到 1，说明还要再做一遍；看到空白，机器停机。状态 scan、carry、back 在第 1 条带上做加一，并让磁头回到最左端，最后一条规则把计数器的磁头向右移一格，用掉一个 1。start、scan、carry、back、start 这个环就是循环。scan 和 carry 是加一，依次经过各个状态就是顺序执行。每次检查时，第 1 条带上依次是 101、110、111、1000。机器在 29 步后停机，x = 1000，也就是八。

要在一条带上运行同一个程序，把两条带存成 #101#111#，并标记每个磁头下的格子。模拟一步要把这个串扫两三遍。如果编码后的串从不超过 12 格，模拟一步最多花大约 3 × 12 = 36 步，29 个被模拟的步骤最多花大约一千步。答案相同，只是更慢。

### 先认识这些词

- **转移规则表:** 一张规则列表，为每对（状态，读到的符号）列一行，给出新状态、要写的符号和移动方向。

- **状态图:** 一幅图，每个状态一个圆，每条规则一条箭头，标签写成 读/写,移动。

- **多轨带:** 一条带、一个磁头，每个格子为每条轨道存放一个符号。

- **多带机器:** 有几条带的机器，每条带有自己的磁头，由同一个状态控制。

- **等价模型:** 识别同样的语言、计算同样的函数的两种模型，即使其中一个更慢。

### 一步步想清楚

**标签 1/0,L 的三部分各是什么意思？**

读到 1，写下 0，磁头向左移动一格。

**实现层和形式层有什么不同？**

实现层说明磁头做什么、纸带上写什么。形式层要给每个状态命名，列出每条规则，并说明规则缺失时怎么办。

**循环在状态图里是什么样子？**

是一个环：某个状态有箭头回到前面的状态，途中的一个测试还有第二条离开这个环的箭头。

**为什么单带模拟要在各条带之间放 #？**

它标出一条带到哪里结束、下一条带从哪里开始。没有它，模拟器分不清哪些格子属于哪条带。

### 把规则表变成状态图并跟踪运行

一台机器有状态 even、odd、acc 和 rej。规则为 (even,0)→(even,0,R)，(even,1)→(odd,1,R)，(even,_)→(acc,_,S)，(odd,0)→(odd,0,R)，(odd,1)→(even,1,R)，(odd,_)→(rej,_,S)。请把状态图写成箭头列表，在 1101 上跟踪运行，并给出高层描述。

**先选择方法**

把每一行变成一条带标签的箭头。然后一格一格地跟着磁头走，每一步之后写下当前状态。

1. 箭头：even 到 even，标签 0/0,R；even 到 odd，标签 1/1,R；even 到 acc，标签 _/_,S；odd 到 odd，标签 0/0,R；odd 到 even，标签 1/1,R；odd 到 rej，标签 _/_,S。起始状态是 even。

2. 在 1101 上跟踪：在 even 下读到第一个 1，转到 odd；读到 1，转到 even；读到 0，仍在 even；读到 1，转到 odd；在 odd 下读到空白，转到 rej。

3. 机器每遇到一个 1 就在 even 与 odd 之间切换，遇到 0 则不变。一共见到三个 1，所以最后停在 odd。状态 odd 读到空白就拒绝。

4. 高层描述：恰好接受含偶数个 1 的串。

**解释最终答案**

机器拒绝 1101，因为这个串含有三个 1。高层描述是：它判定含偶数个 1 的串。

**检验推理**

在空输入上，机器从 even 出发读到空白，于是接受。零是偶数个 1，所以这是对的。

### 把一个小程序对应到两带机器上

程序：total = 0；对输入中的每个 1：total = total + 1；total = total + 1。第 1 条带上是输入 111，第 2 条带开始时为空白。规则 (状态, 带1, 带2) → (状态, 写1, 写2, 移动1, 移动2) 为 (first,1,_)→(second,1,1,S,R)，(second,1,_)→(first,1,1,R,R)，(first,_,_)→(halt,_,_,S,S)。请跟踪运行，并指出其中的加一、顺序执行和循环。

**先选择方法**

跟着状态名走。注意第 2 条带上的磁头只向右移动，所以第 2 条带像一个不断增长的计数器。

1. 第 1 步：状态 first 在第 1 条带上读到 1，在第 2 条带上读到空白。它在第 2 条带上写 1，让那个磁头右移，并转到 second。第 2 条带上是 1。

2. 第 2 步：状态 second 读到 1 和空白。它在第 2 条带上再写一个 1，两个磁头都右移，转到 first。第 2 条带上是 11，输入磁头前进了一格。

3. 第 3 到第 6 步对第二个和第三个 1 重复同样的一对动作。第 4 步后第 2 条带上是 1111，第 6 步后是 111111。

4. 第 7 步：状态 first 在第 1 条带上读到空白，停机。机器共用了 2 × 3 + 1 = 7 步。

5. 加一就是在第 2 条带上“写 1 并右移”，在 first 和 second 中各出现一次。顺序执行就是先 first 后 second。循环就是从 second 回到 first 的那条箭头，由第 1 条带上的测试决定是继续循环还是停机。

**解释最终答案**

输出是 111111，三个输入符号对应六个 1：循环每一遍把总数加 2。

**检验推理**

输入为空时，机器立刻停机，第 2 条带为空，对应循环执行零遍。

### 数一数轨道，并估算一次模拟的代价

(a) 一台 3 轨机器的每条轨道上都使用符号 0、1 和空白。与它等价的单轨机器需要多少个不同的符号？(b) 一台 2 带机器 29 步后停机。它在单带上的编码从不超过 12 格，而且每个被模拟的步骤最多花 3 次扫描。给出单带步数的一个上界。

**先选择方法**

(a) 数一数一个格子可能出现多少种“列”。(b) 把步数乘以模拟一步的代价。

1. 一个格子是一列，有 3 个位置，每个位置有 3 种符号可选。可能的列共有 3 × 3 × 3 = 27 种。

2. 单轨机器把每一列当作一个符号，所以它的带字母表有 27 个符号，包括全空白的那一列。

3. 一次扫描最多花 12 步，所以模拟一步最多花 3 × 12 = 36 步。

4. 模拟 29 步，总共最多 29 × 36 = 1044 步。

**解释最终答案**

单轨机器需要 27 个符号，单带模拟最多用 1044 步。所识别的语言或所计算的函数不变。

**检验推理**

27 是 3 的 3 次方。所以 k 条轨道、每条 a 个符号时，字母表有 aᵏ 个符号。只有一条轨道时是 a，符合预期。

### 在一条带和两条带上运行规则表

Mia 把机器的规则当作数据来保存。规则表是一个 Python 字典，从（状态，读到的符号）映射到（新状态，写入的符号，移动方向）。一个小模拟器可以运行任意条带的表。第一张表在一条带上给二进制数加一。第二张表在两条带上运行程序“重复 3 次：x = x + 1”。

```python
def run_tm(rules, tapes, start="start", halt="halt", limit=500):
    """Run a deterministic k-tape machine. Every tape starts with its head on cell 0.

    rules maps (state, symbols read) to (new state, symbols written, moves)."""
    cells = [dict(enumerate(t)) for t in tapes]
    heads = [0] * len(tapes)
    state, steps, history = start, 0, []

    def snapshot():
        shown = []
        for tape, head in zip(cells, heads):
            used = [i for i, c in tape.items() if c != "_"] + [head]
            lo, hi = min(used), max(used)
            shown.append("".join(f"[{tape.get(i, '_')}]" if i == head else tape.get(i, "_")
                                 for i in range(lo, hi + 1)))
        return state, shown

    history.append(snapshot())
    while state != halt:
        read = tuple(t.get(h, "_") for t, h in zip(cells, heads))
        if (state, read) not in rules:
            raise RuntimeError(f"no rule for {state} reading {read}")
        state, write, moves = rules[(state, read)]
        for i, (w, m) in enumerate(zip(write, moves)):
            cells[i][heads[i]] = w
            heads[i] += {"L": -1, "R": 1, "S": 0}[m]
        steps += 1
        history.append(snapshot())
        if steps > limit:
            raise RuntimeError("step limit reached")
    return steps, history


def contents(history):
    return [t.replace("[", "").replace("]", "").strip("_") for t in history[-1][1]]


# One tape: add 1 to a binary number. Rules: (state, (read,)) -> (state, (write,), (move,))
increment = {}
for bit in "01":
    increment[("start", (bit,))] = ("start", (bit,), "R")      # walk to the right end
increment[("start", ("_",))] = ("carry", ("_",), "L")           # step back onto the last bit
increment[("carry", ("1",))] = ("carry", ("0",), "L")           # 1 plus carry: write 0, carry on
increment[("carry", ("0",))] = ("halt", ("1",), "S")            # 0 plus carry: write 1, done
increment[("carry", ("_",))] = ("halt", ("1",), "S")            # ran off the left end: new leading 1

for text in ("1011", "111"):
    steps, history = run_tm(increment, [text])
    print(f"one tape : {text} + 1 = {contents(history)[0]} in {steps} steps")

# Two tapes: tape 1 holds x in binary, tape 2 holds a unary counter.
# Program:  repeat 3 times: x = x + 1
loop = {}
for bit in "01":
    loop[("start", (bit, "1"))] = ("scan", (bit, "1"), "SS")    # counter left? do one more pass
    loop[("start", (bit, "_"))] = ("halt", (bit, "_"), "SS")    # counter empty: finished
    loop[("scan", (bit, "1"))] = ("scan", (bit, "1"), "RS")     # find the end of x
    loop[("back", (bit, "1"))] = ("back", (bit, "1"), "LS")     # return to the start of x
loop[("scan", ("_", "1"))] = ("carry", ("_", "1"), "LS")
loop[("carry", ("1", "1"))] = ("carry", ("0", "1"), "LS")       # the increment, as before
loop[("carry", ("0", "1"))] = ("back", ("1", "1"), "LS")
loop[("carry", ("_", "1"))] = ("back", ("1", "1"), "LS")
loop[("back", ("_", "1"))] = ("start", ("_", "1"), "RR")        # count one pass, loop again

steps, history = run_tm(loop, ["101", "111"])
print(f"two tapes: x = 101, counter 111 -> x = {contents(history)[0]} in {steps} steps")
for state, (tape1, tape2) in history:
    if state == "start":
        print(f"  at the loop test: x = {tape1:<8} counter = {tape2}")
```


**预期输出**

```text
one tape : 1011 + 1 = 1100 in 8 steps
one tape : 111 + 1 = 1000 in 8 steps
two tapes: x = 101, counter 111 -> x = 1000 in 29 steps
  at the loop test: x = [1]01    counter = [1]11
  at the loop test: x = [1]10    counter = 1[1]1
  at the loop test: x = [1]11    counter = 11[1]
  at the loop test: x = [1]000   counter = 111[_]
```

**按执行顺序理解**

1. run_tm 为每条带保存一个格子字典和一个磁头位置。不在字典里的格子都是空白。

2. 每一步从每条带读一个符号，查规则，在每个磁头下写入，移动每个磁头，并改变状态。缺少规则就抛出错误，这是本程序对“崩溃”的约定。

3. 加一的表有六条规则：两条用于向右走过各个比特，一条用于在空白处折返，三条用于进位。起始状态是 start，停机状态是 halt。

4. 循环的表增加了第二条带。计数器磁头下的 1 表示还要再做一遍。状态 start 检查它，状态 scan、carry 和 back 完成加一并回到最左端，最后一条规则把计数器磁头向右移一格。

5. snapshot 生成被打印和被跟踪的字符串：每个磁头下的格子用方括号标出。

**跟踪状态的变化**

| 步数 | 状态 | 纸带（磁头在方括号内） |
| --- | --- | --- |
| 0 | start | [1]011 |
| 1 | start | 1[0]11 |
| 2 | start | 10[1]1 |
| 3 | start | 101[1] |
| 4 | start | 1011[_] |
| 5 | carry | 101[1] |
| 6 | carry | 10[1]0 |
| 7 | carry | 1[0]00 |
| 8 | halt | 1[1]00 |

**逐步读懂代码**

输出的前两行显示，加一机器在 1011 和 111 上都用 8 步，尽管后一个输入的进位一直传到最左边。对 1011，向右走用 5 步（四个比特，再加空白），进位用 3 步。对 111，向右走用 4 步，进位用 4 步，因为最后的进位落在空白上，写下一个新的最高位 1。

循环机器每次重新进入状态 start，也就是每次检查计数器时，都会打印 x 的值：101、110、111 和 1000。方括号显示磁头的位置。第三遍之后，计数器磁头落在空白上，于是下一次检查就结束了循环。机器 29 步后停机。

找一找这三种形状。加一是 scan 和 carry 这一对状态。顺序执行是依次经过 scan、carry 和 back。循环是从 back 回到 start 的那条规则。因为计数器有自己的带，它不会干扰那个数。如果只有一条带，就需要在带上隔出一块区域放计数器，而且每一遍都要跑过去一趟。

### Leon 的进一步思考

**选择与论断相配的层次**

要证明一个语言可判定，通常用实现层描述就够了，前提是每个阶段都明确会停机并且正确。高层的“加一”把进位藏起来了。实现层把进位的循环摆出来，终止性论证就在这里：每一步都向左移动，所以循环到 0 或最左端就结束。当具体细节很重要时，比如要数步数或给出一台很小的机器，就用形式层的表。

**用边界输入检验小表**

在空输入、单个比特和全是 1 的输入上跑一遍。加一的表在空输入上，于状态 start 读到空白，转到 carry，再读到空白并写 1，输出是 1。要判断这样是否可以接受。这张表还依赖数字左边有一个空白格。如果纸带在左端是封闭的，向左进位的情形就需要额外的移位阶段，表也要随之改变。

**等价说的是能力，不是速度**

在两条带上，把长度为 n 的串复制到第二条带只需要大约 n 步。在一条带上，机器必须在两份拷贝之间来回奔走，代价按 n² 增长。有一个经典结果：单带机器判定一个串是否为回文，需要 n² 数量级的步数，而两带机器只需要大约 n 步。所以多加几条带虽然不改变任何语言，却会改变运行时间。

**注意这个边界:** 只在一个方向上证明等价，或者把“等价”理解为“一样快”。k 带机器显然至少和单带机器一样强，因为可以取 k = 1。真正的工作在另一个方向，而且即使做到了，k 条带上的 t 步在一条带上也可能要花大约 t² 步。

## 模拟、通用性与 Church–Turing 论题

### 01 / 从一个故事开始

通用播放器读取乐谱就能播放不同曲子，无需为每首重造硬件。通用图灵机同样读取机器编码及其输入，逐步解释。类比也显出限制：能跟乐谱不代表事先知道古怪乐谱会否要求无限重复。通用性是模拟任意编码程序的能力，不是无需执行便预测每个程序最终行为的能力。

### 02 / 理解原理

通用图灵机 U 从有限编码 ⟨M,w⟩ 模拟 M 在 w 上运行，保留接受、拒绝或不终止结果。有限字母表、状态及转移表可编码为有限串，因此机器描述能作为数据。两种形式模型等价需双向模拟，单向仅证能力包含。

Church–Turing 论题把非形式的有效算法计算与图灵可计算联系起来，是关于“算法”的论题，不是仅靠定义 TM 就证明的定理。通用性与标准纸带变体等价是具体数学定理。可计算能力相同本身不保证速度、内存或实用性相同。

### 03 / 逐项读懂公式

```text
U(⟨M,w⟩) 模拟 M(w)
M(w) 接受／拒绝／发散 ⇒ U(⟨M,w⟩) 结果相同
```

⟨M,w⟩ 为机器有限描述与有限输入的可计算编码，必须能分开两部分。U 固定，M 遍历编码机器。发散表示从不停机。关系描述行为而非模拟步数。坏编码也需规定处理，常用立即拒绝。

### 04 / 先看一个完整例子

M 在一元输入末尾添加一个1后停机。向 U 给 M 编码及111。U 存模拟状态和头位置，查编码规则、更新模拟带并重复直到停机，模拟输出1111。换成一直右移的机器，U 也一直运行。同一解释器处理两者，说明通用性并不提供停机测试。

### 先认识这些词

- **编码:** 表示机器或输入的有限串。

- **通用机器:** 能模拟编码机器的单一解释器。

- **模拟开销:** 复现另一模型步骤所需额外工作。

### 一步步想清楚

**机器描述为何能作输入数据？**

其有限规则可列出并用有限符号编码。

**模拟一个循环会让它停机吗？**

不会，忠实模拟保留不终止。

**为何需要双向模拟？**

单向只证模拟器能力至少包含被模拟模型。

### 模拟简单加一器

M 向右扫描一元1，在首空白写一个额外1并停机。输入11，头在首符号。说明模拟输出与步骤。

**先选择方法**

保留模拟带、头和状态，一次应用一个编码规则。

1. 首步读位置0的1，保持并移到1。

2. 第二步读位置1的1，移到空白位置2。

3. 下一规则在位置2写1并停机，模拟带现为111。

**解释最终答案**

模拟输出111，表示一元三。按约定 M 用三次转移。

**检验推理**

通用解释器可能用超过三次自身转移实现这三步。

### 跟踪明确模拟开销

教学解释器每模拟一步需自身6步，准备10步。被模拟程序7步停机。求解释器总工作，再讨论被模拟程序不停止的情形。

**先选择方法**

区分固定准备与逐步成本，再区分有限成本和保留发散。

1. 七模拟步耗7×6=42解释器步。

2. 加一次准备：42+10=52。这是题给成本模型，不是普遍界。

3. 若被模拟程序无限运行，逐步复现也需要无限解释器步。

**解释最终答案**

停机例耗52步；忠实模拟不停止例也不会停机。

**检验推理**

模拟步数零时只剩准备10，与10+6t一致。

### Leon 的进一步思考

**行为与资源不同**

两模型可计算相同函数却用很不同步数。讨论模拟应同时说明保留结果与资源关系。

**坏编码也是输入**

通用解释器要识别机器描述边界，并按约定拒绝坏格式，否则形式输入行为不完整。

**注意这个边界:** 不能说论题证明所有可想象物理设备都与 TM 等价，也不能说模拟保证效率相同。

## 识别器与判定器

### 01 / 从一个故事开始

失物处找到匹配标签就能确认包已到，但没找到时可能无限搜。另一处承诺查完有限完整登记册，总回答是或否。前者类似识别，后者类似判定。久等前者并不能把沉默当可靠否定。区别是对全部输入的保证，不是已观察请求上是否友好或快。

### 02 / 理解原理

语言识别器必须接受每个成员，绝不接受非成员；对非成员可拒绝或永远运行。判定器还要求每输入停机，因此每成员问题都得到正确是或否。每个可判定语言都可识别，但反向不成立。

对编码机器的接受问题，通用模拟识别肯定例：若被模拟机器接受，迟早会观察到；若拒绝可拒绝，若循环也可循环。有限测试不能证明程序为判定器，因为未测输入可能发散。证明既需全部允许计算终止，也需答案正确。

### 03 / 逐项读懂公式

```text
L(M) = {w : M 接受 w}
判定器：每个 w∈Σ* 上 M 都停机
可判定语言 ⊊ 可识别语言
```

L(M) 只记录接受串，拒绝与发散均不属于该语言。Σ* 是选定编码下有限输入宇宙。严格包含表示全部可判定语言可识别，但至少一可识别语言不可判定。分类问是否存在某种合适机器，不是某个坏实现是否碰巧停机。

### 04 / 先看一个完整例子

程序依次试0,1,2,…，若找到满足输入谓词 P(x) 的整数就接受，假设每次 P 检查会停机。有见证就迟早遇到并接受，无见证则一直找，所以它识别见证存在性，却未自动判定。P 为 x²=49 时在7接受，P 为 x²=50 时在非负整数上一直搜，虽然该特殊家族可另设计有界判定。一个循环实现不能证明语言不可判定。

### 先认识这些词

- **识别器:** 接受所有成员且不接受非成员，但可在非成员上循环。

- **判定器:** 对每输入给正确成员答案并停机。

- **见证:** 能建立肯定答案的有限对象。

### 一步步想清楚

**识别器沉默可能意味着什么？**

可能尚未找到未来见证，也可能永远搜，沉默本身无法区分。

**为什么判定器都是识别器？**

正确接受已满足识别，还多保证否定例也停止。

**可判定语言也能有很差识别器吗？**

能。可判定性问某判定器是否存在，不保证每个实现好。

### 在简单否定例上循环的识别器

输入n≥0，依次测试x=0,1,2,…，x²=n时接受，每次平方检查会停。比较16与18。

**先选择方法**

区分见证存在与无见证时终止。

1. n=16时测试0,1,4,9,16，x=4提供见证并接受。

2. n=18时4²=16、5²=25，后续非负平方继续增长，故无解。

3. 指定程序没有超过n后停止的规则，因此在18上永远试，尽管数学上能拒绝。

**解释最终答案**

该程序识别完全平方数但不判定；接受16，在18上发散。

**检验推理**

另一个程序可在x²>n时拒绝，所以循环例不证明平方语言不可判定。

### 把特殊搜索变为判定器

修改平方搜索：整数n≥0，测试x从0到n，含端点；相等接受，循环结束否则拒绝。证明正确与终止。

**先选择方法**

证明有限范围包含每个可能非负平方根。

1. n=0只需x=0且成功。n≥1时x>n则x²≥x>n，不可能为解。

2. 循环检查n+1候选，每次会停，因此整体有限。

3. 相等提供真实见证；充分范围中无相等就不存在非负整数解，因此拒绝正确。

**解释最终答案**

有界过程判定平方数成员资格，更紧上界可提速但不改答案。

**检验推理**

n=1时包含x=1，漏掉上端点会错误拒绝边界例。

### Leon 的进一步思考

**证明要涵盖全部终止**

十条轨迹停只证明十例。覆盖每个允许输入的上界或下降度量才补全一般论证。

**限制可能使搜索有限**

若证明可计算有限上界足够，无界见证搜索可变判定器。上界须来自问题，而非任意超时。

**注意这个边界:** 不能由超时推非成员，也不能因某算法循环就推不可判定。

## 为什么通用停机测试不可能

### 01 / 从一个故事开始

想象目录声称分类每个可能检查目录的程序，包括读取自己条目的程序。一个调皮程序可查看对自己的预测，再故意反着做。若目录总正确且总回答，自指就产生矛盾。问题不是太慢或内存少，而是完整过程能否存在。真实分析工具仍有用，因为可限制程序类型、允许未知，或只保证部分问题而非回答所有程序的一切。

### 02 / 理解原理

假设全停机算法 H 能判定任意编码机器在任意输入是否停机。构造 D：输入机器描述x，问 H(x,x)；若答是就永远循环，若答否就停机。让 D 读取自己的描述，两答案都与行为矛盾，因此不存在全正确且全停机的 H。

停机语言仍可识别：模拟直到任何停机结果。接受问题也可识别却不可判定。相关对角语言为不接受自身描述的机器描述，它不可识别，因为任何候选识别器都会在自身描述上与定义冲突。形式证明要一致处理编码与坏输入。

### 03 / 逐项读懂公式

```text
HALT = {⟨M,w⟩ : M 在 w 上停机}
D(x)：若 H(x,x)=是 则循环，否则停机
```

H 为假设判定器，因此每个合法对都必须返回。x 编码机器，同时也可作为该机器输入。D 是使用 H 的有限程序。代入 x=⟨D⟩ 强制矛盾。HALT 包含接受及拒绝两种停机，不同于只计接受计算的语言。

### 04 / 先看一个完整例子

若 H 预测 D 在 ⟨D⟩ 上停机，D 见是后故意循环，预测错。若 H 预测不停机，D 见否后立即停止，仍错。两情况穷尽判定器布尔答案。允许第三答案“未知”避开矛盾，却不再判定原问题。限制固定步数的程序也可有界模拟，但这是另一输入类别。

### 先认识这些词

- **不可判定:** 没有算法对每允许输入都停机并答对。

- **对角化:** 利用构造自身描述强制产生分歧。

- **全停机算法:** 保证在定义域每输入上停机的算法。

### 一步步想清楚

**对 H 假设什么？**

它对每合法机器输入对都正确回答且总停机。

**预测是后 D 做什么？**

故意循环，反驳其会停的预测。

**未知能避开矛盾吗？**

可以，但 H 就不是覆盖全部输入的判定器。

### 补全自指两种情况

假设 H 是全正确全停机判定器。D(x) 在 H(x,x)=是时循环，为否时停。分析 H(⟨D⟩,⟨D⟩)。

**先选择方法**

穷尽两种布尔答案，不猜实际是哪种。

1. 若 H 答是，预测 D 在自身描述停；但 D 的是分支永远循环。

2. 若 H 答否，预测 D 不停；但 D 的否分支立即停。

3. 因 H 全停机，必须返回两者之一，而两者都违反正确性，因此初假设失败。

**解释最终答案**

不存在适用于任意编码程序与输入的全正确全停机判定器 H。

**检验推理**

若 H 可不返回，第三步就不可用。证明针对完整判定器，不针对部分工具。

### 有界问题可判定

给有限机器描述 M、输入 w、非负整数 B，判定 M 是否至多 B 次转移内停机。包括 B=0。

**先选择方法**

给定有限界允许完整模拟到该界，只回答有界问题。

1. 检查初始配置，若已是指定停机配置，即使 B=0 也答是。

2. 否则最多执行 B 次合法转移，每步后查停机，出现则答是。

3. 若检查配置都不停，则对“B内”答否。计数器限制模拟，所以过程自身停机。

**解释最终答案**

有界停机可判定。否表示界内没停，不表示永远不停。

**检验推理**

在 B+1 步停的机器被有界问题正确拒绝，却属于无界 HALT。

### Leon 的进一步思考

**别混淆停机与接受**

停机拒绝也属于 HALT。因此 HALT 识别器在任一种模拟停机后都应接受，不仅模拟接受时。

**有用工具仍然可能**

检查器可对有下降整数计数器的受限循环语言证明终止，这不违反涵盖任意程序的定理。

**注意这个边界:** 定理不表示程序永远不能证明其他程序会停。它只排除适用于所有程序输入的完整、总正确判定器。

## 交错模拟与补语言

### 01 / 从一个故事开始

两位调查员分别寻找同一主张的真证书与假证书。若让第一位一直独占直到完成，第二位可能永无机会。改给交替时段，只要其中一位保证迟早找到相应证书，就能获得结论。这叫交错模拟。它不会凭空造证书，力量来自每个输入恰属于两个可搜索方面之一。

### 02 / 理解原理

可判定语言对补、并、交封闭，因为判定器总结束。交换接受与拒绝即可补判定器。可识别语言对并、交封闭，却不保证对补封闭。并可公平模拟两个识别器，任一接受就接受；若顺序等第一台，可能卡住而错过第二台成功。交则等两台都接受，公平模拟可作为统一构造。

语言可判定当且仅当它与补都可识别。反向证明交错两识别器，必有一个最终接受，从而确定答案。因此可识别却不可判定语言的补不能也可识别。

### 03 / 逐项读懂公式

```text
L 可判定 ⇔ L 与 Σ*∖L 都可识别
并识别器：R₁ 或 R₂ 接受就接受
交识别器：两者都接受后接受
```

Σ* 固定输入宇宙，补含全部不在 L 的串。R₁、R₂ 各有独立模拟配置。公平模拟让每个未完成过程获得无限多机会，例如每次各一步。可保存已接受标志。非成员上组合识别器仍可能永远运行，这不违反识别定义。

### 04 / 先看一个完整例子

Ryes 识别 L，Rno 识别其补。输入 z 上，Ryes 永远循环，Rno 在37步接受。先等 Ryes 的顺序策略永无答案。每台交替一步，至多74个模拟步就看到 Rno 接受，组合过程拒绝 z。若 z∈L，Ryes 保证接受，因此总停机。保证依赖互补语言，两项无关搜索可同时永远不结束。

### 先认识这些词

- **交错模拟:** 公平分配模拟步，避免一过程永远等另一过程。

- **补语言:** 允许输入宇宙中不属于该语言的全部串。

- **接受标志:** 记录某模拟已接受的事实。

### 一步步想清楚

**为什么不先跑完一识别器？**

它可能在该输入永不结束，阻止另一台找到见证。

**交识别器要记什么？**

各组件是否已接受，两个标志都真才接受。

**互补识别器为何给判定器？**

每输入恰属于一侧，该侧识别器保证最终接受。

### 统计公平模拟步

Ryes 识别L，Rno识别补。w上Ryes循环，Rno自身第五步接受。按Ryes再Rno各一步交替，求组合何时回答。

**先选择方法**

给全局模拟步编号，跟踪各步归谁。

1. 全局1,3,5,7,9归Ryes，不终止其搜索。

2. 全局2,4,6,8,10是Rno第一至第五步，第10步它接受。

3. 补识别器接受证明w∉L，因此组合机器立即拒绝。

**解释最终答案**

判定器在10个组件模拟步后拒绝，不计调度额外工作。

**检验推理**

若先等Ryes，则即使证书仅需五步，也永远不会执行Rno。

### 为什么补不能也可识别

假设L可识别却不可判定。反证假设其补有识别器C，不假设任一识别器对所有输入停机，推出矛盾。

**先选择方法**

用公平调度与成员互斥性组合两个部分成功过程。

1. 对同输入交替运行L的识别器R与补识别器C。

2. 输入属于L时R最终接受，否则C最终接受，二者都不能在错误侧接受。

3. R接受则接受，C接受则拒绝，因此每输入都获得正确且终止答案。

**解释最终答案**

这构造L判定器，与前提矛盾，因此补不可识别。

**检验推理**

可判定语言则无矛盾：两侧均有判定器，因此均有识别器。

### Leon 的进一步思考

**公平是一项算法保证**

每个活跃过程轮流一步就足够。只说两者都试不完整，因为实现可能不给一方后续机会。

**拒绝并非补识别器已就绪**

识别器可能拒绝部分外部输入却在其他上循环。仅复用拒绝行为不能覆盖补的每个成员。

**注意这个边界:** 交换识别器停机标签不能求补，其无限计算仍无限，不会让所有原非接受输入变接受。

补不可识别，否则两侧识别器交错就能判定 L，与不可判定矛盾。

## 证明新语言不可判定或不可识别

### 01 / 从一个故事开始

Noah 宣布他做出了一个检查器。他说，只要把任意一台机器的说明书交给它，它就能立刻告诉你这台机器是否至少接受一个输入。Iris 并不相信。她没有拿成千上万份说明书去试这个检查器，而是换了一个问题：如果这个检查器真的有效，我还能用它做什么？

Iris 已经知道一件谁也做不到的事：给定机器 M 和输入 w，判断 M 是否接受 w。她想到一个办法。根据 M 和 w，她写出一份新的说明书 M_w。新机器对除 w 以外的所有输入都不理会，遇到 w 时就照着 M 的步骤去做。这样，M_w 恰好在 M 接受 w 时才会接受某个输入。Iris 把 M_w 交给 Noah 的检查器，读出答案。如果检查器有效，Iris 就解决了那件谁也做不到的事。所以它不可能有效。

请注意，Iris 只是写出了新说明书，并没有照着去执行。写说明书只要几分钟，照着执行却可能永远没有结果。

### 02 / 理解原理

要证明一个新语言 L 不可判定，先选一个已知不可判定的语言 A，通常是 A_TM，也就是所有满足“机器 M 接受输入 w”的二元组 ⟨M,w⟩。然后用反证法，假设 L 有判定器 R。把 R 当作子程序，造一台判定 A 的机器 S。这样的 S 不可能存在，所以 R 也不可能存在。

一个完整的证明有五个部分：假设、S 的构造、答案为“是”时 S 正确的证明、答案为“否”时 S 正确的证明，以及 S 对每个输入都会停机的证明。最后一部分最容易被忘记。它通常依赖两个事实：构造这一步只是写出一个有限长的串，而 R 是判定器，总会给出答案。

同样的想法还有一种简洁的写法。从 A 到 B 的映射归约是一个可计算的函数 f，它对每个串都有定义，并且 w 属于 A 当且仅当 f(w) 属于 B。记作 A ≤m B。如果 B 可判定，那么 A 也可判定：先算出 f(w)，再请 B 的判定器回答。如果 B 可识别，A 也可识别。反过来读，这些结论正是我们要用的工具：A 不可判定，则 B 不可判定；A 不可识别，则 B 不可识别。方向很重要：已知很难的语言放在左边，新语言放在右边。

封闭性给出第二条往往更短的路。可判定语言对补、并、交、差都封闭，因为判定器总会停机，它们的答案可以组合起来。可识别语言对并和交封闭，但对补不封闭。两类语言之间有一个关键联系：一个语言可判定，当且仅当它和它的补都可识别。因此，要证明 L 不可判定，可以假设它可判定，再用一条封闭规则把它与一个可判定语言组合，重新得到一个已知不可判定的语言。要证明 L 不可识别，则证明它的补可识别但不可判定。

### 03 / 逐项读懂公式

```text
A ≤m B：存在可计算的 f，对每个串都有定义，并且  w ∈ A  ⇔  f(w) ∈ B

A ≤m B 且 B 可判定          ⇒  A 可判定
A ≤m B 且 B 可识别          ⇒  A 可识别
A ≤m B 且 A 不可判定        ⇒  B 不可判定
A ≤m B 且 A 不可识别        ⇒  B 不可识别

L 可判定  ⇔  L 与它的补都可识别

证明“L 不可判定”的模板：
  1. 假设 R 判定 L。
  2. S 在输入 ⟨M,w⟩ 上：写出 ⟨M′⟩；在 ⟨M′⟩ 上运行 R；给出答案（有时要取反）。
  3. 证明  M 接受 w  ⇔  S 接受（两个方向都要证）。
  4. 证明 S 对每个输入都会停机。
  5. 于是 S 判定了 A_TM，矛盾。
```

A_TM = {⟨M,w⟩ : M 接受 w} 和 HALT_TM = {⟨M,w⟩ : M 在 w 上停机} 是两个标准的不可判定语言。A_TM 可识别，因为可以模拟 M 在 w 上的运行，但它的补不可识别。记号 ⟨M⟩ 是描述机器 M 的一个串，这样别的机器就能把它当作输入。L(M) 是 M 接受的全部串。E_TM = {⟨M⟩ : L(M) = ∅} 是那些什么也不接受的机器所组成的语言。按照约定，不是合法编码的串，被看作一台什么也不接受的机器的编码。

M′ 和 M_w 是 S 写出来的机器，它们依赖于 M 和 w。映射归约中的函数 f 起的是第 2 步的作用：它是一个总会结束并输出一份描述的程序。Σ* 是所有串的集合，L 的补是 Σ* ∖ L。

### 04 / 先看一个完整例子

命题：E_TM 不可判定。证明：假设 R 判定 E_TM，来构造 S。输入 ⟨M,w⟩ 时，S 先写出机器 M_w 的代码，M_w 的行为如下：输入 x 时，若 x 不是 w，就拒绝；若 x 是 w，就在 w 上运行 M，M 接受则接受。然后 S 在 ⟨M_w⟩ 上运行 R。R 接受，则 S 拒绝；R 拒绝，则 S 接受。

两个方向都要检查。若 M 接受 w，则 M_w 接受 w 而且只接受 w，于是 L(M_w) = {w} 非空，R 拒绝 ⟨M_w⟩，S 接受。若 M 不接受 w（因为拒绝或者死循环），则 M_w 什么也不接受，L(M_w) = ∅，R 接受，S 拒绝。S 总会停机：写出 ⟨M_w⟩ 只是把 ⟨M⟩ 和 w 抄进一个固定模板，而 R 总会给出答案。所以 S 判定了 A_TM，这是不可能的。因此 R 不存在。

取一台具体的 M：当且仅当串里 1 的个数是偶数时接受。对 w = 1001，串里有两个 1，M 接受，L(M_w) = {1001}，S 回答“是”。对 w = 1011，有三个 1，M 拒绝，L(M_w) = ∅，S 回答“否”。若 M 在 w 上死循环，则 M_w 在 w 上也死循环，L(M_w) 仍然为空，S 仍回答“否”。

再看不可识别的那一半。E_TM 的补，是至少接受一个串的机器的编码所成的语言。这个语言可识别：对串 0、1、00、01、…… 公平地交错运行 M，只要有一次运行接受就接受。如果 E_TM 也可识别，那么 E_TM 就可判定，而这一点刚刚被排除。所以 E_TM 不可识别。

### 先认识这些词

- **归约:** 一种可计算的改写，把关于一个语言的问题变成关于另一个语言的问题。

- **假想的判定器:** 我们只是为了推出矛盾而假设存在的判定器。

- **编码 ⟨M⟩:** 描述机器 M 的一个串，使别的机器可以把它当作输入。

- **封闭性:** 如果对一类语言中的成员施行某种运算，结果总还在这一类里，就说这类语言对该运算封闭。

- **构造件:** 构造过程中包在 M 和 w 外面的那一小段固定的机器行为。

### 一步步想清楚

**我们假设哪个语言有判定器？**

假设新语言 L 有判定器，也就是我们想证明不可判定的那个语言。对已知很难的语言，我们只用它不可判定这一点。

**证明的最后，机器 S 判定的是什么？**

一个已知不可判定的语言，例如 A_TM。矛盾就出在这里。

**为什么要证明“M 接受 w 当且仅当 S 接受”的两个方向？**

只证一个方向的话，S 仍可能在某些输入上出错，比如拒绝了 M 确实接受的二元组。那样 S 就没有判定 A_TM。

**对补封闭怎样帮上忙？**

如果 L 可判定，把答案“是”和“否”互换，就能判定它的补。所以不可判定语言的补也不可判定。

### 证明停机语言不可判定

设 HALT_TM = {⟨M,w⟩ : M 在 w 上停机}。已知 A_TM 不可判定。请写出完整证明：从 HALT_TM 的假想判定器 H 出发，构造 A_TM 的判定器，从而证明 HALT_TM 不可判定。

**先选择方法**

要判定的是已知很难的 A_TM。用 H 排除循环的情形，因为只有在 H 保证 M 停机之后，模拟 M 才是安全的。

1. 假设 H 判定 HALT_TM。定义 S：输入 ⟨M,w⟩ 时，先在 ⟨M,w⟩ 上运行 H。

2. 若 H 拒绝，则 M 在 w 上循环，M 不接受 w，S 拒绝。若 H 接受，则 M 在 w 上停机，所以模拟 M 在 w 上的运行一定会结束。S 进行模拟，并给出相同的答案：M 接受就接受，M 拒绝就拒绝。

3. 正确性：若 M 接受 w，则 H 接受，模拟接受，S 接受。若 M 拒绝 w，则 H 接受，模拟拒绝，S 拒绝。若 M 循环，则 H 拒绝，S 拒绝。每种情形下，S 接受当且仅当 M 接受 w。

4. 终止性：H 总会停机。模拟只在 H 说 M 在 w 上停机之后才开始，所以它也会停机。因此 S 对每个输入都停机，并判定了 A_TM，这是不可能的，所以 H 不存在。例如，M 接受含偶数个 1 的串，w = 1011：H 接受（M 在 4 步后停机），模拟结果为拒绝，S 拒绝。

**解释最终答案**

HALT_TM 不可判定。证明成立，是因为唯一可能循环的那一步，也就是对 M 的模拟，只在 H 证明它会停机之后才开始。

**检验推理**

如果允许 H 在某些输入上循环，最后一步就不成立：S 也可能循环，S 就不是判定器，也就没有矛盾。

### 用封闭性证明一个“填充过”的语言不可判定

设 V 是所有形如 ⟨M,w⟩ 的合法编码的集合，X = A_TM ∪ (Σ* ∖ V)，即 M 接受 w 的二元组，再加上所有不是合法二元组编码的串。只使用 A_TM 不可判定、V 可判定这两条事实，证明 X 不可判定。

**先选择方法**

假设 X 可判定，再与可判定集合 V 取交，还原出 A_TM。

1. V 可判定：机器可以在有限步内检查一个串的格式，然后接受或拒绝。可判定语言对交封闭。

2. 计算 X ∩ V。A_TM 的每个成员都是合法的二元组编码，所以 A_TM ∩ V = A_TM。填充部分 Σ* ∖ V 与 V 没有公共元素，所以 (Σ* ∖ V) ∩ V = ∅。因此 X ∩ V = A_TM。

3. 假设 X 有判定器 D_X。那么下面这台机器总会停机：输入 z 时，先做 V 的格式检查；z 不合法就拒绝；否则在 z 上运行 D_X 并照抄它的答案。这台机器判定了 A_TM。比如 z = “hello”，格式检查不通过，机器拒绝，这是对的，因为“hello”不在 A_TM 里。

4. 这与 A_TM 不可判定矛盾，所以 D_X 不存在。

**解释最终答案**

X 不可判定。给不可判定语言添上容易识别的杂项，并不会让它变得可判定。

**检验推理**

这个论证要求 V 可判定。如果检查格式本身就不可判定，第 1 步就不成立，第 3 步中的机器也可能不停机。

### 用带步数上限的构造件证明语言不可识别

设 ALL_TM = {⟨M⟩ : L(M) = Σ*}。证明 ALL_TM 不可识别。可以使用 A_TM 的补不可识别这一事实。

**先选择方法**

把 A_TM 的补归约到 ALL_TM。构造件必须恰好在 M 不接受 w 时接受所有串，而加上步数上限就能做到这一点。

1. 定义 f。对合法的二元组 ⟨M,w⟩，f 输出机器 N 的代码，N 对输入 x 的行为是：模拟 M 在 w 上最多 |x| 步；若这时 M 已经接受，就拒绝；否则接受。对不合法的串，f 输出一台接受所有串的机器的代码。写出这些代码总会结束，所以 f 可计算，并且对每个串都有定义。

2. 若 M 不接受 w（拒绝或循环），则任何模拟都看不到 M 接受，N 接受每个 x，L(N) = Σ*。所以 f(⟨M,w⟩) 属于 ALL_TM，而 ⟨M,w⟩ 属于 A_TM 的补。

3. 若 M 恰好在 5 步后接受 w，则 N 拒绝所有满足 |x| ≥ 5 的 x，只接受更短的串，所以 L(N) ≠ Σ*。于是 f(⟨M,w⟩) 不属于 ALL_TM，而 ⟨M,w⟩ 不属于 A_TM 的补。不合法的串被映射进 ALL_TM，同时也在补里。所以两边总是一致的。

4. 假设 Q 识别 ALL_TM。那么“先算 f，再运行 Q”就能识别 A_TM 的补，这是不可能的。所以 Q 不存在。

**解释最终答案**

ALL_TM 不可识别。步数上限的作用，是把“M 在某个时刻接受 w”变成“N 没有接受所有串”。

**检验推理**

若 M 在 t 步后接受 w，N 恰好拒绝长度至少为 t 的串。t = 5 时，长度不小于 5 的串都被拒绝，N 漏掉无穷多个串，正符合要求。

<a id="lab-reductions-closure-reduction-gadget-demo"></a>

### 只构造，不运行：构造件演示

Emma 想把这个证明的结构写成程序看一看。这里的玩具机器是 Python 生成器：每次 yield 算一步，返回 "accept" 或 "reject" 表示停机。函数 build_Mw 就是主例子里的归约，它只写出一台新机器，不运行任何东西。判定器 R 的替身在有限步数内寻找被接受的串。真正的 R 并不存在，所以这个替身只是猜测，表格会显示它在哪里出错。

```python
# A toy machine is a generator function. Each yield is one step.
# Returning "accept" or "reject" halts it. Never returning means looping.

def run(machine, text, budget):
    """Run for at most `budget` steps. Return the answer, or None if unfinished."""
    steps = machine(text)
    for _ in range(budget):
        try:
            next(steps)
        except StopIteration as done:
            return done.value
    return None


def even_ones(text):                 # accepts when the number of 1s is even
    ones = 0
    for ch in text:
        yield
        ones += ch == "1"
    return "accept" if ones % 2 == 0 else "reject"


def spin(text):                      # loops forever
    while True:
        yield


def slow_accept(text):               # accepts, but only after 5000 steps
    for _ in range(5000):
        yield
    return "accept"


def build_Mw(M, w):
    """The reduction. It writes down a new machine and runs nothing."""
    def Mw(x):
        yield
        if x != w:
            return "reject"
        answer = yield from M(w)     # simulate M on w, one step at a time
        return "accept" if answer == "accept" else "reject"
    return Mw


def stand_in_for_R(machine, probes, budget):
    """A budgeted guess at 'is the language empty?'. A real decider cannot exist."""
    return all(run(machine, p, budget) != "accept" for p in probes)


def S(M, w, budget):
    Mw = build_Mw(M, w)                              # step 1: always finishes
    empty = stand_in_for_R(Mw, [w, "", "0"], budget)  # step 2: ask R
    return not empty                                 # step 3: flip the answer


cases = [("even_ones", even_ones, "1001"), ("even_ones", even_ones, "1011"),
         ("spin", spin, "1001"), ("slow_accept", slow_accept, "1001")]
print("machine      w     M accepts w  R says empty  S accepts  S correct")
for name, M, w in cases:
    truth = run(M, w, 20000) == "accept"
    says = S(M, w, 100)
    print(f"{name:<12} {w}  {str(truth):<11}  {str(not says):<12}  {str(says):<9}  {says == truth}")

print("building M_w for a looping M returns at once:", callable(build_Mw(spin, "1001")))
print("running that M_w on w for 100 steps gives:", run(build_Mw(spin, "1001"), "1001", 100))
```

**在本地运行**

```sh
python reductions-closure-reduction-gadget-demo.py
```

**预期输出**

```text
machine      w     M accepts w  R says empty  S accepts  S correct
even_ones    1001  True         False         True       True
even_ones    1011  False        True          False      True
spin         1001  False        True          False      True
slow_accept  1001  True         True          False      False
building M_w for a looping M returns at once: True
running that M_w on w for 100 steps gives: None
```

**按执行顺序理解**

1. run 最多运行玩具机器 budget 步，返回它的答案；若机器还没结束，就返回 None。程序不能无限等待，这个函数模拟的正是这种限制。

2. even_ones、spin 和 slow_accept 在每个输入上行为各不相同：一台带着答案停机，一台永远循环，一台要到 5000 步以后才接受。

3. build_Mw 就是归约。它返回一台新机器：对 w 以外的 x 一律拒绝，遇到 w 时用 yield from 运行 M。调用 build_Mw 时什么也不会运行。

4. S 遵循证明的三个步骤：构造 M_w，问 R 的替身 M_w 是不是什么也不接受，然后给出相反的答案。

5. 最后的循环把 S 和真相作比较。“真相”一列用的是很大的步数上限，这只因为我们事先知道这些玩具机器的行为。对真实的机器，它是算不出来的。

**跟踪状态的变化**

| 情形 | M 在 w 上 | L(M_w) | R 说“空” | S 的答案 |
| --- | --- | --- | --- | --- |
| even_ones, w = 1001 | 接受 | {1001} | False | 接受（正确） |
| even_ones, w = 1011 | 拒绝 | 空 | True | 拒绝（正确） |
| spin, w = 1001 | 循环 | 空 | True | 拒绝（正确） |
| slow_accept, w = 1001 | 5000 步后接受 | {1001} | True（步数上限太小） | 拒绝（错误） |

**逐步读懂代码**

表格展示了 S 的逻辑。若 100 步内没有任何探测串被接受，R 的替身就说“空”，S 返回相反的答案。前三行与 M 和 w 的真实情况一致。对 slow_accept，M 确实接受 w，但要等 5000 步。100 步以内 M_w 还没有接受，替身说“空”，S 就答错了。

把步数上限调大，可以修好这台机器，却会在下一台更慢的机器上出错。这正是定理的缩影：不管等多久，都无法把一台永远不接受的机器和一台很晚才接受的机器区分开。真正的判定器 R 必须对每台机器都答对，而这恰恰是不可能存在的。

最后两行说明构造这一步为什么是安全的。对一台循环的机器构造 M_w，会立刻返回，因为构造只是新建一个函数。真正运行这个 M_w 却永远不会结束，程序在 100 步后把它截停。证明从不运行 M_w，只把描述交给 R。

### Leon 的进一步思考

**先问目标语言在检验什么，再选构造件**

E_TM 检验的是“有没有被接受的串”，所以 M_w 要做成恰好在 M 接受 w 时才接受某个串。如果目标是“机器的语言是正则的”，就要让 M_w 的语言恰好在 M 接受 w 时是正则的：让 M_w 接受所有形如 0ⁿ1ⁿ 的串，对其他串则在 w 上运行 M，M 接受就接受。若 M 接受 w，L(M_w) 是 Σ*，是正则的；否则 L(M_w) 是 {0ⁿ1ⁿ}，不是正则的。套路不变，只换构造件。

**只和代码本身有关的性质很容易判定**

“M 的状态数是否超过五个”这个问题，读一遍 ⟨M⟩ 就能回答，所以它可判定，任何构造件都无法把它和接受行为挂上钩。归约证明只适用于那些取决于机器做什么，而不是取决于机器怎么写的性质。动手证明之前，可以先用它快速检查一下。

**封闭性论证需要一个可判定的搭档**

如果 X 和 D 都可判定，那么 X ∩ D、X ∪ D 和 X ∖ D 都可判定。使用时，要找一个可判定的 D，把未知语言 X 削成一个已知不可判定的语言。常见的搭档是语法：合法的二元组编码 ⟨M,w⟩ 所成的集合是可判定的，因为机器能在有限步内检查格式。第二道例题就用了这一点。

**注意这个边界:** 把归约的方向弄反。如果证明了“用新语言可以解决已知很难的语言”，这才有意义。如果只证明了“用已知很难的语言可以解决新语言”，那只说明新语言不比它更难，并不能说明它是否可判定。

## 命题语法与真值

### 01 / 从一个故事开始

实验室警报板组合门开、风扇开、温度超限等信号。连线说明怎样组合，当前开关值决定警报值。逻辑将两层区分为语法与语义。括号像接线，改变它可能改变结果。模型假设信号有明确真假，并不自动表示测量不确定或因果，因此逻辑蕴含不能当作传感器间物理机制。

### 02 / 理解原理

命题公式由原子与否定、合取、析取等联结词组成。赋值给每原子布尔值，再按解析树递归算公式值。除非声明异或，析取是包含式。实质蕴含 P→Q 只在P真Q假时为假，P假时为真。

有至少一赋值使真称可满足，每赋值都真称有效，没有真赋值称不可满足。k个原子的完整真值表有2ᵏ行，给有限判定法，但赋值数指数增长，单行容易不代表整体便宜。

### 03 / 逐项读懂公式

```text
P→Q ≡ ¬P∨Q
F 可满足：∃α，α(F)=1
F 有效：∀α，α(F)=1
```

P、Q为公式，F为待查公式，α为原子真值赋值，α(F)递归扩展到全公式。∃为存在，∀为每个，1表示真。蕴含等价式只定义真值行为，不表示P导致Q，也不要求Q与P相关。

### 04 / 先看一个完整例子

设p为样本冷藏，q为封口完整，F=p→q。(假,假)、(假,真)、(真,真)都满足，只有(真,假)使假，所以可满足而非有效。再要求p，得p∧(p→q)，唯一满足为p=q=真。再要求¬q就无赋值而不可满足。推理排除配置，不是在说冷藏物理上确保封口。

### 先认识这些词

- **真值赋值:** 为每原子命题选择真或假。

- **可满足:** 至少一个赋值下真。

- **有效公式:** 每个赋值下真。

### 一步步想清楚

**三原子为何八行？**

各有两选择，2×2×2=8赋值。

**p→q何时假？**

恰在p真q假时。

**可满足公式还能某处假吗？**

能。可满足只需一真行，有效才要求全部真。

### 分类受限制蕴含

原子p,q，分类F=(p→q)∧¬q为可满足、有效或不可满足，使用四赋值。

**先选择方法**

合取先强制¬q，再检查剩余行的蕴含。

1. q真时¬q假，因此p两选择都使F假。

2. q假p真时p→q假，因此F假。

3. q假p假时p→q真且¬q真，因此F真。

**解释最终答案**

仅(p,q)=(假,假)满足。F可满足但不有效。

**检验推理**

改写为(¬p∨q)∧¬q，在¬q下化为¬p∧¬q，核对结果。

### 统计包含式或的模型

F=(p∨q)∧r，有三个独立布尔原子，或为包含式，统计满足赋值。

**先选择方法**

将被强制的r与允许的p,q对分开。

1. 合取要求r真，四个r假赋值全失败。

2. r真时p∨q接受(真,假)、(假,真)、(真,真)，不接受(假,假)。

3. 一个r选择配三个对，得1×3=3模型，总赋值2³=8。

**解释最终答案**

F有三个满足赋值，可满足但不有效。

**检验推理**

若或改为异或，则去掉同时真对，模型数降二。

### Leon 的进一步思考

**从内向外求值**

先算括号子公式，再算父联结词，可防止把长公式按自然语句意外分组。

**经典蕴含不是因果**

真蕴含只排除前提真结论假组合，不解释事件成因，也不给概率。

**注意这个边界:** “p only if q”应为p→q，不是q→p；only if给必要条件。

## 逻辑等价与安全改写

### 01 / 从一个故事开始

两警报电路外观不同，却可能在每种输入设置下都亮相同灯。一次测试只证明一次一致，等价要求全部一致。代数改写可不看外观而证明一致。替换法须匹配完整子电路，逻辑等价也作用于完整子公式。类比适于布尔行为，但转为有状态表达式的程序时，等价公式不保证求值成本或副作用相同。

### 02 / 理解原理

F与G在每真值赋值下相同称逻辑等价。它允许在更大公式内用等价子公式替换而不改整体真值。常用双否定、De Morgan、分配、吸收、消蕴含等规则。真值表检查所有行可证明，一条差异行可推翻。

F↔G是在一个赋值下有真值的公式；F≡G是对全部赋值的元层断言。双条件有效当且仅当两侧等价。仅改排符号或给少量例子不足以证明语义关系。

### 03 / 逐项读懂公式

```text
F ≡ G ⇔ ∀α, α(F)=α(G)
¬(F∧G) ≡ ¬F∨¬G
F→G ≡ ¬G→¬F
```

α遍历涉及原子的全部赋值。≡陈述公式间关系，∧、∨、¬、→构造公式。最后一律为逆否：反转箭头并否定两侧，不能只反转。改写时要找完整匹配子公式，保留周围分组。

### 04 / 先看一个完整例子

化简F=¬(p∨¬q)。用De Morgan得¬p∧¬¬q，再双否定得¬p∧q。p假q真时两式真，但单行不是证明，规则保证四行全部一致。比较p→q与q→p，p假q真时前真后假，立即推翻等价。正确反向等价式是¬q→¬p，仍排除p真q假。

### 先认识这些词

- **等价:** 每个赋值下真值一致。

- **逆命题:** 将P→Q反转为Q→P。

- **逆否命题:** 与P→Q等价的¬Q→¬P。

### 一步步想清楚

**一差异行为何确定不等价？**

等价要求每行，一次失败就推翻。

**¬(p∧q)怎样分配？**

否定两侧并将合取换析取，得¬p∨¬q。

**反转蕴含会保留它吗？**

逆否还须否定两侧，仅逆命题通常不同。

### 化简嵌套否定

用等价律化简F=¬(p∧¬q)，并在p真q假时求两式值。

**先选择方法**

先将外否定推过合取，再删双否定。

1. De Morgan得¬p∨¬¬q，因为否定将∧换∨。

2. 双否定将¬¬q化为q，得¬p∨q。

3. p真q假时原内部p∧¬q真，F假；改写式假∨假也假。

**解释最终答案**

F≡¬p∨q≡p→q。样本行一致，而规则证明全行等价。

**检验推理**

p假时改写式无论q都真，符合原式否定假合取。

### 推翻诱人的反转

比较F=p→q与G=q→p，给反赋值，再写F正确等价反向式。

**先选择方法**

寻找一侧前件假，另一侧真前件假结论的行。

1. 取p假q真，F因前件p假而真。

2. G因q真p假而假，因此两式此行不同。

3. 反转同时否定两侧得¬q→¬p，与F同样仅在p真q假时为假。

**解释最终答案**

逆命题不等价，逆否¬q→¬p等价。

**检验推理**

p=q=真时两者碰巧都真，但该一致行不能修复反例。

### Leon 的进一步思考

**子公式边界重要**

¬(p∨q)∧r中否定只覆盖p∨q。De Morgan改写不能改外层与r的合取。

**程序副作用需另行处理**

纯布尔等价不保证函数调用顺序或次数相同，逻辑假设原子已具有固定真值。

**注意这个边界:** p→q与q→p通常不同。逆否既反转也否定两侧。

## 命题逻辑的范式

### 01 / 从一个故事开始

仓库检查员有一组必须全部通过的清单，每份清单允许若干替代条件。这个“每组至少一个、全部组都满足”的形状就是合取范式。换成统一形状方便算法处理，却可能重复很多内容。范式并不意味着唯一、最短或最容易读。

### 02 / 理解原理

否定范式只用合取、析取，并把否定放在原子前。先消去蕴含与双条件，再用 De Morgan 律把否定向内推。合取范式是若干子句的合取，每个子句是文字的析取。把析取分配到合取上可得到它，但表达式可能指数增长。单个文字也可作为子句。

这里的命题 CNF 与文法的 Chomsky 范式是不同概念。SAT 转换有时引入新变量以避免膨胀；这通常保证可满足性对应，不能直接说新旧公式在同一组变量上等价。

### 03 / 逐项读懂公式

```text
F∨(G∧H) ≡ (F∨G)∧(F∨H)
CNF = C₁∧⋯∧Cₘ，每个 Cᵢ 是若干文字的析取
```

F、G、H 可以是复合公式。Cᵢ 是第 i 个子句，m 是子句数。文字是 p 或 ¬p，不是带否定的任意复合式。分配方向决定得到合取范式还是析取范式。若出现空合取或空析取，须先声明约定。

### 04 / 先看一个完整例子

把 p→(q∧r) 写成 ¬p∨(q∧r)，再分配得到 (¬p∨q)∧(¬p∨r)。p 假时两子句自动成立，p 真时必须 q、r 都真。式子 (p∧q)∨r 当前不是合取范式，但可改写为 (p∨r)∧(q∨r)；判断当前语法形状与判断能否转换是两回事。

### 先认识这些词

- **文字:** 原子或单个原子的否定。

- **子句:** 文字的析取，例如 p∨¬q。

- **合取范式:** 子句的合取，每条子句都须成立。

### 一步步想清楚

**p 是子句吗？**

是，单个文字是一文字子句。

**¬(p∨q) 是否是否定范式？**

不是，改为 ¬p∧¬q 将否定移到原子前。

**转换一定缩短公式吗？**

不一定，分配可能重复子公式并大幅增大长度。

### 转换带替代条件的规则

用普通二值逻辑将 (p∧q)→r 转为合取范式，不引入新变量。

**先选择方法**

消去蕴含，再把否定向内推。

1. A→B 等于 ¬A∨B，故得到 ¬(p∧q)∨r。

2. De Morgan 将 ¬(p∧q) 改为 ¬p∨¬q。

3. 结合律得到一个子句 ¬p∨¬q∨r，已是合取范式。

**解释最终答案**

合取范式为 ¬p∨¬q∨r，仅禁止 p、q 真而 r 假。

**检验推理**

这恰是原规则真前提、假结论的情况。

### 分配两组条件

将 (p∧q)∨(r∧s) 转为合取范式，数子句，并在 p 真、q 假、r 真、s 真时求值。

**先选择方法**

每次分配一个合取，保留全部配对。

1. 先得到 [p∨(r∧s)]∧[q∨(r∧s)]。

2. 分别分配得 (p∨r)∧(p∨s)∧(q∨r)∧(q∨s)。

3. 共有四条子句。给定赋值下因 r、s 都真，每条都真。

**解释最终答案**

四子句合取范式为真，与原式右边合取为真一致。

**检验推理**

p=r=假时 p∨r 子句假，原式两合取也都假。

### Leon 的进一步思考

**把合取范式读成清单**

一个真文字满足所在子句，不会自动满足所有子句。在 (p∨q)∧r 中令 p 真仍须满足 r。

**新变量改变比较方式**

若用新变量 z 代表 p∧q，须用子句约束两者关系。保可满足性问是否存在合适 z，不是每个 z 都与原式一致。

**注意这个边界:** 不要把合取范式与析取范式混淆。子句不一定恰有三个文字。

<summary>检查自己的理解</summary>

不是，否定作用于复合式。改写 ¬p∨¬q 后是否定范式，也是一条子句组成的合取范式。

</details>

## 逻辑后承与反模型

### 01 / 从一个故事开始

审查员问：只要所有前提都成立，结论就一定成立吗？一份所有前提真而结论假的记录，就足以推翻这种保证。这叫反模型。如果前提本来就相互矛盾，没有任何记录能同时满足它们，那么所有结论都会在形式上空泛成立。

### 02 / 理解原理

Γ 在语义上蕴涵 F，指每个满足 Γ 中全部公式的赋值也满足 F。对有限前提，可以把它们与 ¬F 合取；若不可满足，推理有效。若可满足，该赋值就是反模型。有效性不保证现实中的前提为真；某次结论碰巧为真也不证明推理有效。

肯定前件与否定后件是有效规则。肯定后件、否定前件一般无效。后承有方向；等价则要求两个方向都成立。

### 03 / 逐项读懂公式

```text
Γ ⊨ F ⇔ 不存在同时满足 Γ 中全部公式及 ¬F 的赋值
{P→Q, P} ⊨ Q
```

Γ 是公式集合，⊨ 表示语义后承。满足 Γ 要求其每个公式都真。第二式是肯定前件：P→Q 与 P 推出 Q。⊨ 是公式之间的元层关系，不是一个原子。前提有限时才直接写成有限合取。

### 04 / 先看一个完整例子

设 p 为文件通过验证，q 为文件被接受。p→q 与 q 不能推出 p：p 假、q 真使两个前提真而结论假，文件或许通过另一条途径被接受。若把前提 q 改成 ¬q，则可推出 ¬p；因为 p 真会与规则一起迫使 q 真，与已知 ¬q 冲突。

### 先认识这些词

- **前提:** 检查推理时暂时假定为真的陈述。

- **反模型:** 全部前提真而结论假的赋值。

- **后承:** 在前提的每个模型中都为真的结论。

### 一步步想清楚

**前提现实中为假会令推理形式无效吗？**

不会，有效性考察所有前提成立时能否保真。

**怎样用可满足性检查后承？**

寻找前提与结论否定一起的满足赋值。

**为何一个反模型就够？**

后承要求前提的每个模型都成功。

### 连接两条蕴含

经典命题逻辑中，p→q、q→r、p 是否推出 r？

**先选择方法**

假设所有前提真，逐步传播其必需后果。

1. 第三前提使 p 真。

2. p→q 真且 p 真，故 q 必真，否则蕴含失败。

3. q→r 真且 q 真，故 r 必真，不可能有反模型。

**解释最终答案**

能，通过两次肯定前件推出 r。

**检验推理**

p=q=r=真满足前提，故并非不一致前提造成的空泛结果。

### 检验否定前件

p→q 与 ¬p 能推出 ¬q 吗？若可行请构造反模型。

**先选择方法**

先使拟议结论假，再看前提是否仍成立。

1. 要使 ¬q 假，令 q 真。

2. 要满足 ¬p，令 p 假。

3. p 前件假使 p→q 真。两前提都成立，但 ¬q 失败。

**解释最终答案**

不能。p 假、q 真是反模型；规则没有说 p 是 q 的唯一途径。

**检验推理**

该赋值确实满足 p→q，因为没有真前件假结论。

<a id="lab-logical-consequence-entailment-countermodels"></a>

### 找出全部反模型

穷举两个布尔原子，检查 p→q 是否推出 p∨q。

```python
from itertools import product

rows = []
for p, q in product([False, True], repeat=2):
    premise = (not p) or q
    conclusion = q or p
    if premise and not conclusion:
        rows.append((p, q))
print("Countermodels:", rows)
assert rows == [(False, False)]
```

**在本地运行**

```sh
python logical-consequence-entailment-countermodels.py
```

**预期输出**

```text
Countermodels: [(False, False)]
```

**按执行顺序理解**

1. 枚举（假，假）、（假，真）、（真，假）、（真，真）。

2. 在（假，假）下蕴含真，而 p∨q 假。

3. 其他三行都不是反模型；保存的一个值对足以推翻后承。

**逐步读懂代码**

product 生成 p 与 q 的全部四种组合。for 循环把每对值分别赋给两个变量。Python 的 not 表示否定，or 表示包含“两者都真”的析取，因此 (not p) or q 表示蕴含。

if 只保留前提真而结论假的行。append 把该值对加到列表，print 显示完成的列表，assert 检查预期结果。这个有限穷举只检验此推理；原子更多时所需行也更多。

### Leon 的进一步思考

**利用结论指导寻找**

反驳 Γ⊨p∨q 时先令 p=q=假，这是结论失败的唯一方式，再检查前提能否仍真。

**区分一致性与有效性**

在把 p 与 ¬p 推出的结论当作有用知识前，先检验前提是否有模型。逻辑有效性本身不回答这个不同问题。

**注意这个边界:** 不要只检查结论为真的赋值。反模型必须令全部前提真、结论假。

## 谓词、量词与作用域

### 01 / 从一个故事开始

每位学徒都有导师，与有一位导师指导所有学徒，不是同一句话。第一句允许不同学徒选择不同导师，第二句要求同一人胜任。要判断真假，必须说明讨论哪些对象，以及指导关系具体有哪些。符号能帮助我们保留这些容易被日常语言隐藏的差别。

### 02 / 理解原理

谓词逻辑让变量在明确的非空论域中取对象。∀ 表示每个对象，∃ 表示存在见证。“所有 A 都是 B”写为 ∀x(A(x)→B(x))；“有些 A 是 B”写为 ∃x(A(x)∧B(x))。不同量词的顺序决定后面的见证是否可依赖前面的对象。否定量词时交换 ∀ 与 ∃，并否定其内部公式。

量词有作用域，作用域外的同名变量不因此被约束。自由变量需要额外赋值。跨公式移动量词须检查该变量是否在另一部分自由出现；必要时先重命名约束变量，避免捕获。

### 03 / 逐项读懂公式

```text
∀x∃y M(x,y) 与 ∃y∀x M(x,y)
¬∀x F ≡ ∃x ¬F;  ¬∃x F ≡ ∀x ¬F
```

M(x,y) 表示 y 指导 x。x、y 在同一指定论域内取值。∀x∃y 允许 y 随 x 改变；∃y∀x 要求同一个 y 对所有 x 有效。F 是量词的内部公式，可能含 x。否定规则不改变其他自由变量。括号明确量词覆盖范围。

### 04 / 先看一个完整例子

论域为 Ada 与 Ben，且只有两条关系：Ada 指导 Ben，Ben 指导 Ada。每个人都有导师，所以 ∀x∃y M(x,y) 真；无人指导自己，所以不存在指导所有人的同一个导师，∃y∀x M(x,y) 假。

第一句的否定为 ∃x∀y¬M(x,y)，即有人完全没有导师。“并非每位学徒都获认证”是 ∃x(Apprentice(x)∧¬Certified(x))；仅写 ∃x¬Certified(x) 可能找到了非学徒。

### 先认识这些词

- **论域:** 变量可以指向的非空对象集合。

- **见证:** 使存在陈述为真的对象。

- **作用域:** 受某个量词或联结词管辖的公式部分。

### 一步步想清楚

**∀x∃y 的见证可不同吗？**

可以，每次选定 x 后，合适 y 可依赖它。

**怎样否定 ∃xP(x)？**

写为 ∀x¬P(x)，每个候选对象都不满足性质。

**所有 A 都是 B 为何用蕴含？**

只要求 A 对象通过 B 检查，非 A 对象不受此要求。

**能交换这两个量词而不改变命题吗？**

一般不能。给定关系让“全称—存在”为真、“存在—全称”为假，是二者等价这一主张的反模型。

### 会改变的见证

论域 {1,2,3}，R(x,y) 表示 x≠y。求 ∀x∃yR(x,y) 与 ∃y∀xR(x,y) 的真假。

**先选择方法**

第一式给每个 x 找见证，第二式用全部 x 检验固定 y。

1. x=1 选 y=2；x=2 选 y=1；x=3 选 y=1。每个 x 都有不同伙伴。

2. 对任何固定 y，全称 x 都包括 x=y。

3. x=y 时 R 假，故没有一个 y 能通过全部三个 x 检查。

**解释最终答案**

第一式真，第二式假，交换不同种类量词会改变意义。

**检验推理**

不等有序对有六个，三个对角对缺失；每行有见证，每列有失败。

### 否定全称类别规则

学生为 {A,B,C}，Pass(A) 真、Pass(B) 假、Pass(C) 真。翻译并判断“并非每位学生通过”。假设论域只有学生。

**先选择方法**

否定全称量词，再找具体失败学生。

1. 每位学生通过是 ∀xPass(x)，论域已将 x 限制为学生。

2. 否定得到 ¬∀xPass(x)≡∃x¬Pass(x)。

3. 选 x=B，Pass(B) 假，故 ¬Pass(B) 真，B 是所需见证。

**解释最终答案**

陈述为真，表示至少一人失败，不表示所有人都失败。

**检验推理**

A、C 通过，故更强的 ∀x¬Pass(x) 为假。

### 否定并检验量词命题

使用代码中的三名学生、两名导师。否定“每个学生都有导师”，再判断删除 (Bo,Noah) 后否定命题是否成立。

**先选择方法**

把否定依次推进各量词，再寻找具体见证。

1. ¬∀x∃yR(x,y) 变成 ∃x¬∃yR(x,y)。

2. ¬∃y 变成 ∀y¬，得到 ∃x∀y¬R(x,y)。

3. 删除后，R(Bo,Ivy)、R(Bo,Noah) 都为假，选择 x=Bo。

**解释最终答案**

删除后否定命题为真，Bo 是见证。

**检验推理**

删除前每个学生的见证列表非空，因此否定命题为假。

<a id="lab-predicate-logic-finite-witness-search"></a>

### 在有限模型中寻找见证与反例

社团的每个学生都有导师。米娜听完，以为存在一位导师指导所有学生。一个小表就推翻了这个想法：Ana、Cy 跟 Ivy，Bo 跟 Noah。每个学生都有人指导，却没有一个导师覆盖三人。米娜用嵌套循环把两个量词的顺序具体展示出来。

```python
students = ["Ana", "Bo", "Cy"]
mentors = ["Ivy", "Noah"]
relation = {("Ana", "Ivy"), ("Bo", "Noah"), ("Cy", "Ivy")}

def inspect(students, mentors, relation):
    witnesses = {x: [y for y in mentors if (x, y) in relation] for x in students}
    every_has_someone = all(witnesses[x] for x in students)
    shared = [y for y in mentors if all((x, y) in relation for x in students)]
    uncovered = [x for x in students if all((x, y) not in relation for y in mentors)]
    assert bool(uncovered) == (not every_has_someone)
    return witnesses, every_has_someone, shared, uncovered

witnesses, every, shared, uncovered = inspect(students, mentors, relation)
print("witnesses:", witnesses)
print("every student has a mentor:", every)
print("one mentor for everybody:", bool(shared))
assert every and not shared
broken = relation - {("Bo", "Noah")}
print("counterexample after removal:", inspect(students, mentors, broken)[3])
assert inspect([], mentors, relation)[1] is True
assert inspect(students, [], relation)[1] is False
```

**在本地运行**

```sh
python predicate-logic-finite-witness-search.py
```

**预期输出**

```text
witnesses: {'Ana': ['Ivy'], 'Bo': ['Noah'], 'Cy': ['Ivy']}
every student has a mentor: True
one mentor for everybody: False
counterexample after removal: ['Bo']
```

**按执行顺序理解**

1. 为每位学生建立见证列表；内层存在量词可以为不同外层学生选择不同导师。

2. 寻找共同导师时反过来：先选一个导师，再要求他覆盖每位学生。

3. 若某学生对所有候选导师都不满足关系，他就是未被覆盖者；这会构造否定命题的见证，而不只是打印 False。

4. 检查空集合情形。没有学生时全称命题为真；有学生却没有导师时，原命题为假。

**逐步读懂代码**

设 S 为学生集合、M 为导师集合，R(x,y) 表示 y 指导 x。第一个命题是“对每个 x∈S，存在 y∈M，使 R(x,y)”；第二个是“存在 y∈M，对每个 x∈S 都有 R(x,y)”。共同见证能证明第二个，进而证明第一个；各自的见证只能证明第一个。

否定第一个命题得到：“存在 x∈S，使每个 y∈M 都不满足 R(x,y)”。删掉 Bo–Noah 后，Bo 就成为这个反例。|S| 名学生、|M| 名导师的直接检查需要 O(|S||M|) 次关系查询，这里假定集合查询平均 O(1)。

程序检查的是一个指定的有限解释。在一张表上成立，并不证明公式在所有解释中都有效，也不能解决任意一阶逻辑有效性。论域假设应写在题目中，不能遇到不想要的结果后再临时改变空集规则。

## 英语与量词公式的互译

### 01 / 从一个故事开始

Iris 在为学校的储物间写使用规则，Leon 负责校对。Iris 写道：“每个学生都有一个储物柜。”Leon 问：你是说每个学生都有自己的储物柜，还是说存在一个所有学生共用的储物柜？在英语里，同一句话两种读法都说得通，可管理员必须按其中一种去执行。谓词逻辑用量词的顺序把这个选择摆到明处。从左往右读，每个量词都是依次做出的一次选择，后面的选择可以依赖前面的选择。

反过来翻译是同一种本领。Leon 把公式当作一个按顺序讲的小故事来读：“任选一个学生。那么有一个储物柜是这个学生拥有的。”按这个顺序慢慢读，再拿一个只有两个学生、两个储物柜的小模型去检验这个故事，大多数错误都能查出来。

### 02 / 理解原理

把一句话翻译成逻辑，分四步。第一步，确定论域：x 可以是哪一类东西？第二步，给谓词起名，例如 Student(x) 和 Has(x, y)。第三步，按出现的顺序列出量词词语：每个、有些、没有、至少、恰好。第四步，确定每个量词的范围。像“每个学生”这样的限定，在 ∀ 后面变成蕴含；“有些学生”则在 ∃ 后面变成合取。公式框里的模式涵盖了常见的句子，包括“没有”“并非每个”“只有”“至多一个”和“恰好一个”。

把公式翻译回英语时，从左到右读出量词，并给每个变量安排角色：“对每个 x，存在 y，使得 ……”。然后把字母换成名词。再用一个小模型检验结果：造一个让这句话为真的模型，再造一个让它为假的模型。如果你的英语读法分不出这两个模型，读法就是错的。

同类量词可以交换：∀x∀y 与 ∀y∀x 含义相同，∃x∃y 与 ∃y∃x 含义相同。不同类的量词则不能交换。在 ∀x∃y φ 中，见证 y 可以依赖 x。在 ∃y∀x φ 中，必须有同一个 y 对所有 x 都成立。所以 ∃y∀x φ 总能推出 ∀x∃y φ，因为那个唯一的 y 对每个 x 都适用，但反过来可能不成立。

量词提取是把量词从公式的一部分里移到外面。只有当该变量在另一部分中不是自由出现时，才允许这样做。如果是自由出现的，就先给约束变量改名。公式框里的规则在论域至少有一个对象时成立，这是通常的假设。要留意蕴含的前件：∀ 一旦从那里移出，就变成 ∃，∃ 则变成 ∀。还要留意合并的陷阱：∀ 对 ∧ 可以分配，对 ∨ 却不行；∃ 对 ∨ 可以分配，对 ∧ 却不行。

### 03 / 逐项读懂公式

```text
每个 A 都是 B         ∀x (A(x) → B(x))
有些 A 是 B           ∃x (A(x) ∧ B(x))
没有 A 是 B           ∀x (A(x) → ¬B(x))      ≡   ¬∃x (A(x) ∧ B(x))
并非每个 A 都是 B     ∃x (A(x) ∧ ¬B(x))
只有 A 才是 B         ∀x (B(x) → A(x))
至多有一个 A          ∀x ∀y ((A(x) ∧ A(y)) → x = y)
恰好有一个 A          ∃x (A(x) ∧ ∀y (A(y) → y = x))

同类量词可交换：      ∀x∀y φ ≡ ∀y∀x φ            ∃x∃y φ ≡ ∃y∃x φ
不同类量词，单向成立： ∃y∀x φ ⊨ ∀x∃y φ           （反方向不成立）

量词提取（x 在 R 中不自由，且论域非空）：
  (∀x P) ∧ R ≡ ∀x (P ∧ R)       (∃x P) ∧ R ≡ ∃x (P ∧ R)
  (∀x P) ∨ R ≡ ∀x (P ∨ R)       (∃x P) ∨ R ≡ ∃x (P ∨ R)
  (∀x P) → R ≡ ∃x (P → R)       (∃x P) → R ≡ ∀x (P → R)
  R → (∀x P) ≡ ∀x (R → P)       R → (∃x P) ≡ ∃x (R → P)
不能合并：            (∀x P) ∨ (∀x Q) ≢ ∀x (P ∨ Q)       (∃x P) ∧ (∃x Q) ≢ ∃x (P ∧ Q)
```

A(x) 和 B(x) 是谓词，也就是一个对象要么具有、要么不具有的性质。P 和 Q 也是谓词，R 是 x 不自由出现的公式，例如 TripOn 这样的一个简单命题。φ 代表任意公式。符号 = 表示两个对象是同一个，≠ 表示不是同一个。符号 ≡ 表示“在每个模型中真值都相同”。符号 ⊨ 表示“凡是使左边为真的模型也使右边为真”。符号 ≢ 表示“不等价”。

论域是变量取值的对象集合。如果周围没有量词捕获某个变量，它就是自由的，否则是约束的。提取规则要求 R 里没有自由的 x，这样移出去的量词才不会把属于 R 的 x 捕获进来。

### 04 / 先看一个完整例子

取一个有四个人的模型：Leon、Mia、Emma 和 Jack。关系 Admires(x, y) 恰好对四对成立：(Leon, Mia)、(Mia, Emma)、(Emma, Mia) 和 (Jack, Mia)。翻译并判断五个句子。“每个人都敬佩某个人”是 ∀x∃y Admires(x, y)。它为真，而且见证在变：Leon 对应 Mia，Mia 对应 Emma，Emma 对应 Mia，Jack 对应 Mia。“有一个人被所有人敬佩”是 ∃y∀x Admires(x, y)。它为假：Mia 被 Leon、Emma 和 Jack 敬佩，却不被她自己敬佩。“有一个人被其他所有人敬佩”是 ∃y∀x (x ≠ y → Admires(x, y))。取 y = Mia 时为真。“没有人敬佩自己”是 ∀x ¬Admires(x, x)，为真。“恰好有一个人敬佩 Emma”是 ∃x (Admires(x, Emma) ∧ ∀z (Admires(z, Emma) → z = x))，取 x = Mia 时为真。

再把一个公式读回英语。∃x∀y ¬Admires(y, x) 的意思是：有一个人没有被任何人敬佩。它为真，因为没有人敬佩 Leon。它也是 ∀x∃y Admires(y, x)，即“每个人都被某个人敬佩”的否定。

接下来看一次提取。“如果每个人都付了款，旅行就成行”是 (∀x Paid(x)) → TripOn。TripOn 里没有 x，所以规则给出 ∃x (Paid(x) → TripOn)。读出来是：存在某个人，如果这个人付了款，旅行就成行。听起来奇怪，但它恰好在“有人没付款或者旅行成行”时为真，这正是原句的意思。前件里的 ∀ 变成了 ∃。

相反的句子是“如果有人付了款，旅行就成行”。它是 (∃x Paid(x)) → TripOn，等价于 ∀x (Paid(x) → TripOn)：每一个付款的人单独就够了。两种情况下量词都发生翻转，是因为蕴含的前件处于否定的位置。

### 先认识这些词

- **见证:** 使 ∃ 命题为真的那个对象。在 ∀x∃y 中，y 的见证可以随 x 变化。

- **量词提取:** 把量词从公式某个部分的内部移到最前面，而不改变含义。

- **自由变量:** 周围没有量词捕获的变量，它的取值必须从外部给定。

- **反模型:** 一个小模型，其中一个公式为真而另一个为假，说明二者不等价。

- **前束范式:** 所有量词都在最前面，其余部分不再含有量词的公式。

### 一步步想清楚

**为什么“每个 A 都是 B”用 → 而不用 ∧？**

这句话只涉及属于 A 的东西。对于不属于 A 的东西，蕴含为真，不会造成妨碍。如果用 ∧，公式就变成了“所有东西既是 A 又是 B”。

**“没有 A 是 B”有哪两种写法？**

写成 ∀x (A(x) → ¬B(x))，即每个 A 都不是 B；或者写成 ¬∃x (A(x) ∧ B(x))，即不存在既是 A 又是 B 的东西。二者等价。

**为什么从 (∀x P(x)) ∧ Q(x) 提取之前必须先改名？**

Q(x) 里的 x 是自由的。把 ∀x 移到 Q(x) 外面会捕获它，改变含义。先把约束变量改名为 z：∀z (P(z) ∧ Q(x))。

**为什么 ∃y∀x φ 总能推出 ∀x∃y φ？**

如果有同一个 y 对每个 x 都成立，那么每个 x 都可以用这个 y 作见证。反过来不行，因为不同的 x 可能需要不同的 y。

### 翻译三个句子并在模型上检验

论域包含学生 Mia、Jack、Iris 和储物柜 L1、L2。Student 和 Locker 是谓词，Has(x, y) 对 (Mia, L1)、(Jack, L2)、(Iris, L2) 成立。请翻译并判断：(a) 每个学生都有一个储物柜；(b) 有某个储物柜被两个不同的学生共用；(c) 没有哪个储物柜被所有学生使用。

**先选择方法**

按英语词语的顺序写量词，用对应的谓词限定每个量词，并寻找明确的见证或反例。

1. (a) ∀x (Student(x) → ∃y (Locker(y) ∧ Has(x, y)))。见证：Mia 用 L1，Jack 用 L2，Iris 用 L2。三个学生都满足，所以 (a) 为真。

2. (b) ∃y (Locker(y) ∧ ∃x ∃z (x ≠ z ∧ Student(x) ∧ Student(z) ∧ Has(x, y) ∧ Has(z, y)))。取 y = L2，x = Jack，z = Iris。他们是两个不同的学生，都拥有 L2，所以 (b) 为真。

3. (c) ∀y (Locker(y) → ¬∀x (Student(x) → Has(x, y)))。对 L1，Jack 没有它。对 L2，Mia 没有它。所以两个储物柜都不被所有学生拥有，(c) 为真。

4. “每个学生都有一个储物柜”的共用读法 ∃y (Locker(y) ∧ ∀x (Student(x) → Has(x, y))) 正好与 (c) 相反，所以在这个模型里为假。这个模型把两种读法区分开了。

**解释最终答案**

在这个模型里，翻译后的三个句子都为真，而“每个学生都有一个储物柜”的共用读法为假。

**检验推理**

如果 Jack 和 Iris 也都拥有 L1，那么 L1 就被三个学生全部拥有，(c) 就会变成假。

### 把公式读出声，并比较两种嵌套顺序

设 F = ∀x (Cat(x) → ∃y (Mouse(y) ∧ Chases(x, y)))，G = ∃y (Mouse(y) ∧ ∀x (Cat(x) → Chases(x, y)))。论域有猫 Tom、Kit 和老鼠 m1、m2，Chases 对 (Tom, m1) 和 (Kit, m2) 成立。请用英语读出二者，判断真假，并证明 G 蕴含 F。

**先选择方法**

按顺序读每个量词。对 G，逐只检验每只老鼠。要证明蕴含，就取 G 的任一模型，构造出 F 所要求的见证。

1. F 读作：每只猫都追某只老鼠。G 读作：有一只老鼠被每只猫追。

2. F 为真：Tom 追 m1，Kit 追 m2。

3. G 为假：m1 没有被 Kit 追，m2 没有被 Tom 追。没有哪只老鼠同时被两只猫追。

4. G 蕴含 F：在 G 为真的任何模型中，取那只被每只猫追的老鼠 y。于是每只猫都有一只自己追的老鼠，就是 y，所以 F 成立。反过来不成立，上面的模型就是例子。

**解释最终答案**

在这个模型里，F 为真，G 为假，所以二者不等价。G 总能推出 F，但 F 推不出 G。

**检验推理**

如果 Kit 也追 m1，那么 m1 被两只猫都追，G 就变成真。

### 一步步提取量词并检验结果

把量词提到最前面。(a) (∀x P(x)) ∧ (∃x Q(x))。(b) (∀x P(x)) → (∃y Q(y))。然后在论域 {1, 2} 上检验 (b)，其中 P 只对 1 成立，Q 对任何对象都不成立。

**先选择方法**

先确认该变量在另一部分中不是自由的，必要时改名。一次只用一条规则，从前件移出时要把 ∀ 翻转为 ∃。

1. (a) 两个 x 是不同的约束变量。把第二个改名：(∀x P(x)) ∧ (∃y Q(y))。

2. 先移出 ∀x：(∃y Q(y)) 中没有自由的 x，规则给出 ∀x (P(x) ∧ ∃y Q(y))。再移出 ∃y：P(x) 中没有自由的 y，规则给出 ∀x ∃y (P(x) ∧ Q(y))。

3. (b) 把 ∀x 从前件移出，它翻转：∃x (P(x) → ∃y Q(y))。再把 ∃y 从后件移出，它保持不变：∃x ∃y (P(x) → Q(y))。

4. 检验 (b)。在论域 {1, 2} 上，P 只对 1 成立，Q 对任何对象都不成立：原式的前件为假，因为 P(2) 不成立，所以原式为真。在结果式中取 x = 2：P(2) 为假，所以对任何 y，蕴含都为真。二者都为真。

**解释最终答案**

(a) 变成 ∀x ∃y (P(x) ∧ Q(y))。(b) 变成 ∃x ∃y (P(x) → Q(y))。在检验模型中，(b) 的两边都为真。

**检验推理**

若 P 对 1 和 2 都成立而 Q 对任何对象都不成立，原式是“真蕴含假”，为假。结果式中每一对都是 P(x) 为真、Q(y) 为假，每个蕴含都为假。二者都为假。

### 在小模型上检验翻译与提取规则

Jack 想在相信自己的翻译之前先检验一下。他在 Python 里保存了一个小模型：一个人名列表和一个有序对集合。Python 的 all 和 any 分别扮演 ∀ 和 ∃。前半部分在例子中的“敬佩”模型上检验五个英语句子。后半部分在所有只有 1 到 3 个对象的模型以及空模型上检验提取规则。

```python
from itertools import product

# Part 1. English sentences checked on one small model.
people = ["Leon", "Mia", "Emma", "Jack"]
pairs = {("Leon", "Mia"), ("Mia", "Emma"), ("Emma", "Mia"), ("Jack", "Mia")}


def admires(x, y):
    return (x, y) in pairs


sentences = [
    ("Everyone admires someone", all(any(admires(x, y) for y in people) for x in people)),
    ("Someone is admired by everyone", any(all(admires(x, y) for x in people) for y in people)),
    ("Someone is admired by everyone else",
     any(all(admires(x, y) for x in people if x != y) for y in people)),
    ("Nobody admires themselves", all(not admires(x, x) for x in people)),
    ("Exactly one person admires Emma",
     any(admires(x, "Emma") and all(x == z for z in people if admires(z, "Emma"))
         for x in people)),
]
for text, value in sentences:
    print(f"{text}: {value}")

# Part 2. Test quantifier-extraction rules on every model with 0 to 3 objects.
# A model is a subset for P, a subset for Q and a truth value for R.
rules = [
    ("(all x P) and R  =  all x (P and R)",
     lambda D, P, Q, R: (all(P[x] for x in D) and R) == all(P[x] and R for x in D)),
    ("(exists x P) or R  =  exists x (P or R)",
     lambda D, P, Q, R: (any(P[x] for x in D) or R) == any(P[x] or R for x in D)),
    ("(all x P) -> R  =  exists x (P -> R)",
     lambda D, P, Q, R: ((not all(P[x] for x in D)) or R) == any((not P[x]) or R for x in D)),
    ("(exists x P) -> R  =  all x (P -> R)",
     lambda D, P, Q, R: ((not any(P[x] for x in D)) or R) == all((not P[x]) or R for x in D)),
    ("(all x P) or (all x Q)  =  all x (P or Q)",
     lambda D, P, Q, R: (all(P[x] for x in D) or all(Q[x] for x in D)) == all(P[x] or Q[x] for x in D)),
    ("(exists x P) and (exists x Q)  =  exists x (P and Q)",
     lambda D, P, Q, R: (any(P[x] for x in D) and any(Q[x] for x in D)) == any(P[x] and Q[x] for x in D)),
]
for label, rule in rules:
    verdict = "holds on every model with 1-3 objects"
    for size in (1, 2, 3):
        D = range(size)
        for p, q, r in product(product([False, True], repeat=size),
                               product([False, True], repeat=size), [False, True]):
            if not rule(D, p, q, r):
                verdict = f"fails: {size} objects, P={list(p)}, Q={list(q)}, R={r}"
                break
        if verdict.startswith("fails"):
            break
    empty = "" if rule(range(0), (), (), False) and rule(range(0), (), (), True) else "  (fails on 0 objects)"
    print(f"{label}: {verdict}{empty}")
```

**按执行顺序理解**

1. people 和 pairs 就是整个模型：一个论域和一个关系。admires(x, y) 判断这一对是否在关系中。

2. 每个句子都写成嵌套的 all 和 any，顺序与量词的顺序一致。生成器里的条件“if x != y”扮演 ∀ 后面的蕴含 x ≠ y → ……。

3. 每条规则是一个函数，在一个模型上计算等式两边。一个模型由两个真值列表 P 和 Q（每个对象一个）以及一个真值 R 组成。

4. 循环遍历所有含 1、2、3 个对象的模型。两边第一次不同的模型被当作反例打印出来。

5. 最后的检查问：这条规则在没有任何对象时是否也成立。Python 里对空集合做 all 得到 True，做 any 得到 False，正如 ∀ 和 ∃ 在空论域上的表现。

**逐步读懂代码**

前五行与例子一致。看第三个句子：去掉条件 x != y，就得到第二个句子，而它为假，因为没有人敬佩自己。正是这个限定把“所有人”变成了“其他所有人”。

测试的六条规则中，四条在所有小模型上都成立，两条立刻失败。两条合并规则在含两个对象的模型上失败：P 对一个对象成立，Q 对另一个对象成立。这时每个对象都满足 P 或 Q，可是 P 和 Q 都不是对所有对象成立。在同一个模型里，P 和 Q 各自都有见证，但没有哪一个对象同时满足二者。

其中有三条规则在没有对象时也不成立，所以逻辑课通常假设至少有一个对象。通过了最多三个对象的所有模型，只是证据，不是证明。失败则是真正的反例，而通过只是提醒你去找证明。提取规则本身是通过对任意论域进行推理来证明的。

### Leon 的进一步思考

**用能区分两种读法的模型检验翻译**

造一个小到可以手算的模型，让一种读法为真、另一种为假。对储物柜规则，取学生 Mia 和 Jack，储物柜 1 和 2，Mia 拥有 1，Jack 拥有 2。“每个学生各有一个储物柜”为真，“有一个储物柜被所有学生拥有”为假。如果两种读法在某个模型里结果一样，说明这个模型没有起到检验作用。

**提取是改写，所以要逐条规则连着写并标明名称**

一次只用一条规则，把过程写出来。对 (∀x P(x)) → (∃y Q(y))：先把 ∀x 从前件移出，它翻转，得到 ∃x (P(x) → ∃y Q(y))；再把 ∃y 从后件移出，它保持不变，得到 ∃x ∃y (P(x) → Q(y))。要保持量词原来出现的顺序。这个例子里两个量词的先后其实无关紧要，因为 P(x) 和 Q(y) 没有共用变量；但只要有 Admires(x, y) 这样的公式把它们联系起来，顺序就会影响含义。

**论域非空这个假设确实在起作用**

有三条提取规则在没有任何对象的论域上不成立。没有对象时，(∀x P) ∧ R 就等于 R，而 ∀x (P ∧ R) 为真。当 R 为假时，二者不同。后面的程序会演示这一点。逻辑课通常假设至少有一个对象，以保证这些规则成立。如果题目允许空论域，就要把每条规则重新检查一遍。

**注意这个边界:** 把量词从蕴含的前件中移出来，却没有翻转。(∃x Paid(x)) → TripOn 并不等于 ∃x (Paid(x) → TripOn)。前者说只要有人付了款，旅行就成行。后者只要有一个人没付款就为真，哪怕旅行取消了。正确的提取结果是 ∀x (Paid(x) → TripOn)。
